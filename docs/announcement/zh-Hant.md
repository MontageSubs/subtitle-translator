# 提醒：請將 Web App 更新至 v1.4.0 或更新版本

**若你使用的 Web App 版本早於 v1.4.0，將無法使用翻譯功能。**

v1.4.0 是一次大版本更新。後端升級到 v1.3，採用了新的連線握手與更完善的濫用防護機制，並且不再接受舊版 Web App 的請求。前後端必須同時更新，看到這則提醒後請盡快更新。

**如何更新：**
請查看頁面右下角的版本號。若版本早於 **v1.4.0**，可以用以下方式更新：
* 點擊右下角的版本號，強制觸發更新。
* 清除瀏覽器快取後重新整理頁面。

若頁面已開啟好幾天，請先完成或下載手邊的工作，再重新整理頁面。

**本次更新內容：**
* **依原格式下載：** 單一字幕預設以上傳時的格式下載，SRT 仍是 SRT。批次上傳時，ZIP 內每個檔案保留各自的原始格式，點擊切換格式後才會統一。會保留原有的資料夾結構，同名檔案會像作業系統一樣自動加上序號後綴，例如 `name (1).srt`。
* **上傳更快、更可靠：** 頁面尚未載入完成時選擇或拖入的檔案不再遺失，上傳後立即出現進度提示，MKV 影片與雙語字幕亦同。
* **更安全的歷史記錄：** 「歷史記錄已滿」的提醒會等到最近一次翻譯下載之後才出現，不會再誤清除尚未儲存的結果；彈窗也會始終顯示在你正在檢視的區域中央。
* **更穩健的後端：** 更輕量、更快的請求處理，以及更完善的信譽評分與濫用防護，無需你做任何額外操作。
* **細節打磨：** 窄螢幕下歷史記錄更寬鬆，狀態標籤大小一致，部分選項的文案更清楚，並改善了位址輸入有誤時的處理。
* **搶先體驗：** 現在點擊頁面左下角的 ❤️ 符號 5 次，即可進入 Beta 版本搶先測試新功能！
