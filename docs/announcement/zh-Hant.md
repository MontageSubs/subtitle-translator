# 提醒：請將 Web App 更新至 v1.4.0 或更新版本

**若你使用的 Web App 版本早於 v1.4.0，將無法使用翻譯功能。**

v1.4.0 是一次大版本更新。後端升級到 v1.4.0，採用了新的連線握手與更完善的濫用防護機制，並且不再接受舊版 Web App 的請求。前後端必須同時更新，看到這則提醒後請盡快更新。

**如何更新：**
請查看頁面右下角的版本號。若版本早於 **v1.4.0**，可以用以下方式更新：
* 點擊右下角的版本號，強制觸發更新。
* 清除瀏覽器快取後重新整理頁面。
