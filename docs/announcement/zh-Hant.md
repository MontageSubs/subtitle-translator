# 提醒：請將 Web App 更新至 v1.1.27 或更新版本

**若你使用的 Web App 版本早於 v1.1.27，將無法使用翻譯功能。**

我們更新了後端介面 (API)，以確保與即將推出的 v1.2 版本完全相容。這次更新為後續的功能升級奠定了基礎，特別是在 v1.2 版本中，我們將正式支援本地模型，用以優化翻譯前的字幕預處理流程。

**如何更新：**
請查看頁面右下角的版本號。若版本早於 **v1.1.27**，可以用以下方式更新：
* 點擊右下角的版本號，強制觸發更新。
* 清除瀏覽器快取後重新整理頁面。

**本次更新內容：**
* 更新後端介面，確保與 v1.2 版本的相容性。
* 為 v1.2 版本的本地模型支援做準備，旨在優化翻譯前的字幕預處理。
* **搶先體驗：** 現在點擊頁面左下角的 ❤️ 符號 5 次，即可進入 Beta 版本搶先測試新功能！
