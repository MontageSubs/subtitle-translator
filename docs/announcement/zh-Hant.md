# 提醒：請將 Web App 更新至 v1.1.8 或更新版本

**若你使用的 Web App 版本早於 v1.1.8，將無法使用翻譯功能。**

我們調整了後端資料結構，改善中日韓語言與拉丁字母語言互譯的品質，也讓翻譯速度稍微快一些。由於這項變更，舊版 Web App 已不再相容；如果你無法翻譯，請先更新 Web App。

**如何更新：**
請查看頁面右下角的版本號。若版本早於 **v1.1.8**，可以用以下方式更新：
* 點擊右下角的版本號，強制觸發更新。
* 清除瀏覽器快取後重新整理頁面。

**本次更新內容：**
* 改善中日韓語言與拉丁字母語言互譯的準確度。
* 調整中文和日文字幕排版，使其更符合當地閱讀習慣。
* 改善前後端的資料傳輸方式，讓回應速度更快。
