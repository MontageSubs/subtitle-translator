# Heads up: Web App update required (v1.1.27+)

**If you're running a version older than v1.1.27, translation will stop working.**

We've updated the backend API to ensure full compatibility with the upcoming v1.2 release. This update is essential for the app to continue functioning correctly and to pave the way for significant improvements in how subtitles are processed.

**How to update:**
Check the version number in the bottom right. If you're below **v1.1.27**, you can either:
* Click the version number to force an update.
* Clear your cache and refresh the page.

**What's new:**
* Updated backend API for improved stability and v1.2 compatibility.
* Foundation laid for v1.2, which will officially support local models to optimize pre-processing before translation.
* **Beta Access:** Want a sneak peek? Click the ❤️ symbol in the bottom left 5 times to enter the beta version and test new features early!
