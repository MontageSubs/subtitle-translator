# Heads up: Web App update required (v1.4.0+)

**If you're running a version older than v1.4.0, translation will stop working.**

v1.4.0 is a major update. The backend has moved to v1.3 with a new connection handshake and a stronger abuse-protection system, and it no longer accepts older versions of the Web App. The two sides must be updated together, so please update as soon as you see this notice.

**How to update:**
Check the version number in the bottom right. If you're below **v1.4.0**, you can either:
* Click the version number to force an update.
* Clear your cache and refresh the page.

If you keep the page open for days, finish or download your current work first, then refresh.

**What's new:**
* **Download in the original format:** a single subtitle is downloaded in the format you uploaded, so SRT stays SRT. In a batch, every file inside the ZIP keeps its own format, and switching the format unifies them. Folder structure is kept, and files with the same name get a numbered suffix such as `name (1).srt`, just like your operating system does.
* **Faster, more reliable uploads:** files picked or dropped while the page is still loading are no longer lost, and a progress indicator appears immediately, including for MKV videos and bilingual subtitles.
* **Safer history:** the "history is full" reminder now waits until your latest translation has been downloaded, so it can no longer clear a result you haven't saved. It also stays centered in the part of the page you are looking at.
* **A more resilient backend:** a lighter, faster request path and a more robust reputation system for abuse protection, with no extra steps for you.
* **Polish:** a roomier history list on narrow screens, consistent status badges, clearer wording for several options, and smarter handling of mistyped addresses.
* **Beta Access:** Want a sneak peek? Click the ❤️ symbol in the bottom left 5 times to enter the beta version and test new features early!
