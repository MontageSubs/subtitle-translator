# Heads up: Web App update required (v1.1.8+)

**If you're running a version older than v1.1.8, translation will stop working.**

We've overhauled the backend data structure to squeeze out better translation quality for CJK/Latin pairs and speed things up a bit. The trade-off is that older versions of the web app are no longer compatible—so you'll need to update to get things running again.

**How to update:**
Check the version number in the bottom right. If you're below **v1.1.8**, you can either:
* Click the version number to force an update.
* Clear your cache and refresh the page.

**What's new:**
* Better accuracy for CJK <-> Latin translations.
* Fixed typography and layout for Chinese and Japanese to feel more natural.
* Faster response times thanks to a leaner data payload.
