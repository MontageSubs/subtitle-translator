# 【重要】Web App 兼容性提醒 (v1.1.8+)

**若你的 Web App 版本低于 v1.1.8，翻译功能将无法正常运行。**

我们重构了后端的数据结构，以提升中日韩 (CJK) 与拉丁语系互译的质量并提高响应速度。这也意味着旧版 Web App 不再兼容，请及时更新。

**如何更新：**
请检查右下角的版本号。若低于 **v1.1.8**，可通过以下方式更新：
* 点击右下角版本号，强制触发更新。
* 清除浏览器缓存并刷新页面。

**更新內容：**
* 优化 CJK ↔ 拉丁语系互译的准确度。
* 调整中日文排版，使其更符合当地习惯。
* 精简数据传输结构，提高响应速度。
