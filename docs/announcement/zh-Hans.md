# 【重要】Web App 兼容性提醒 (v1.4.0+)

**若你的 Web App 版本低于 v1.4.0，翻译功能将无法正常运行。**

v1.4.0 是一次大版本更新。后端升级到 v1.3，采用了新的连接握手与更完善的滥用防护机制，并且不再接受旧版 Web App 的请求。前后端必须同时更新，看到本提醒后请尽快更新。

**如何更新：**
请检查右下角的版本号。若低于 **v1.4.0**，可通过以下方式更新：
* 点击右下角版本号，强制触发更新。
* 清除浏览器缓存并刷新页面。

如果页面已经开了好几天，请先完成或下载手头的工作，再刷新页面。

**更新内容：**
* **按原格式下载：** 单个字幕默认以上传时的格式下载，SRT 仍是 SRT。批量上传时，ZIP 内每个文件保留各自的原始格式，点击切换格式后才会统一。会保留原有的目录结构，重名文件会像操作系统一样自动添加序号后缀，例如 `name (1).srt`。
* **上传更快、更可靠：** 页面尚未加载完成时选择或拖入的文件不再丢失，上传后立刻出现进度提示，MKV 视频与双语字幕同样如此。
* **更安全的历史记录：** “历史记录已满”的提醒会等到最近一次翻译下载之后才出现，不会再误清除尚未保存的结果；弹窗也会始终显示在你正在查看的区域中央。
* **更稳健的后端：** 更轻量、更快的请求处理，以及更完善的信誉评分与滥用防护，无需你做任何额外操作。
* **细节打磨：** 窄屏下历史记录更宽松，状态标签大小统一，若干选项的文案更清晰，并优化了地址输入有误时的处理。
* **抢鲜体验：** 现在点击页面左下角的 ❤️ 符号 5 次，即可进入 Beta 版本提前测试新功能！
