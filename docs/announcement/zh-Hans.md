# 【重要】Web App 兼容性提醒 (v1.4.0+)

**若你的 Web App 版本低于 v1.4.0，翻译功能将无法正常运行。**

v1.4.0 是一次大版本更新。后端升级到 v1.3，采用了新的连接握手与更完善的滥用防护机制，并且不再接受旧版 Web App 的请求。前后端必须同时更新，看到本提醒后请尽快更新。

**如何更新：**
请检查右下角的版本号。若低于 **v1.4.0**，可通过以下方式更新：
* 点击右下角版本号，强制触发更新。
* 清除浏览器缓存并刷新页面。
