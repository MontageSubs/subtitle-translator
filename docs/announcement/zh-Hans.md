# 【重要】Web App 兼容性提醒 (v1.1.27+)

**若你的 Web App 版本低于 v1.1.27，翻译功能将无法正常运行。**

我们更新了后端接口，以确保与即将发布的 v1.2 版本完全兼容。此次更新为后续的功能升级奠定了基础，特别是将在 v1.2 中正式引入的本地模型支持，旨在优化翻译前的字幕预处理流程。

**如何更新：**
请检查右下角的版本号。若低于 **v1.1.27**，可通过以下方式更新：
* 点击右下角版本号，强制触发更新。
* 清除浏览器缓存并刷新页面。

**更新内容：**
* 更新后端接口，确保与 v1.2 版本的兼容性。
* 为 v1.2 版本的本地模型支持做准备，以优化字幕翻译前的预处理。
* **抢鲜体验：** 现在点击页面左下角的 ❤️ 符号 5 次，即可进入 Beta 版本提前测试新功能！
