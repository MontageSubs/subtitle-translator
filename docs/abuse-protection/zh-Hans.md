# 人机验证与合理使用

本工具免费提供，并运行在共享的翻译引擎上。为了让所有人都能持续使用，我们启用了轻量的反滥用保护。因此你偶尔会被要求完成人机验证，或者翻译会暂停一段时间。

## 为什么会要求验证

- 你的网络在短时间内发送了大量请求，或与大量自动化流量共用同一个地址。
- 你近期的使用量接近了当前小时或当天的合理使用额度。
- 某个请求看起来格式异常或像是自动化行为。

通常完成验证后即可继续使用。

## 翻译何时会暂停

如果使用量持续超出额度，或短时间内反复触发验证，翻译会暂停，页面会显示可以继续使用的时间。不会丢失任何内容：文件和设置都保存在你的浏览器里，暂停到期后自动解除。

## 如果你被误伤

共享网络（学校、公司、VPN）可能让并没有做错任何事的人触发这些限制。如果你遇到了这种情况，请[反馈问题](../report-issue/)，并大致说明发生的时间，我们会据此调整限制。
