# 人機驗證與合理使用

感謝你使用蒙太奇字幕翻譯器！

蒙太奇字幕翻譯器是一項免費、開放原始碼的社群服務，不需要註冊帳號。我們希望讓大家在大多數情況下都能直接使用，不必動不動就遇到人機驗證。

### 為什麼會需要人機驗證？

免費服務並不代表不需要成本。每次翻譯請求都會消耗實際的運算資源，而我們每天能提供的請求額度有限，也會依照整體使用狀況，動態調整每位使用者的合理使用額度。

我們希望這些資源能讓更多字幕愛好者使用，而不是在短時間內就被大量請求耗盡。

因此，當系統偵測到配額消耗速度異常時，可能會要求你完成人機驗證，以確認請求是由真人發出，而非機器人或自動化程式。

這只是為了維持服務正常運作所採取的保護措施，並不代表你有任何違規或不當使用的情形。

### 完成人機驗證後，還會受到使用限制嗎？

一般情況下，通過驗證後就可以繼續使用服務。

如果你只是在短時間內使用了較多額度，我們也會盡可能提供額外的臨時額度，讓你能順利完成手邊的字幕翻譯工作。

不過，人機驗證通常也代表目前的可用配額較為吃緊，或你的使用量已經接近甚至超出合理使用範圍。也希望大家在使用時，能替其他使用者保留一些資源。

如果配額仍持續快速消耗，我們可能會暫時限制你的服務使用權限。

限制時間沒有固定標準，會依照目前的平均可用配額、你過去的配額使用情況，以及整體資源的恢復狀況彈性調整。可能幾個小時後就能恢復，也可能需要一天或更久。

只要是針對正常使用者所採取的配額限制，都只是暫時性的。等可用資源恢復後，就能再次使用服務。

但如果確認有透過機器人或自動化程式大量消耗資源、濫用服務的情形，我們保留永久停止相關存取權限的權利。

### 需要更多配額嗎？

如果你有合理的大量使用需求，例如需要翻譯大量字幕，歡迎加入我們的[社群](../community/zh-Hant.md)，和大家聊聊你的需求。

也請避免使用自動化程式大量消耗翻譯配額。這項服務是由社群共同維護的公共資源，我們希望每位字幕愛好者都有機會使用。

更多使用規範，請參閱[服務條款](../terms/zh-Hant.md)。

如果你認為自己遇到了不合理的使用限制，或是在完成人機驗證時遇到問題，也歡迎透過[意見回饋](../feedback/zh-Hant.md)告訴我們。
