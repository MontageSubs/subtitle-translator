## 關於翻譯結果的問題

翻譯結果不理想，通常有兩種情況。

**一種是「翻譯品質不理想」**

例如用詞不精準、語法不自然等。這通常與翻譯引擎本身，以及引擎所接收到的上下文有關。你可以試著使用以下功能，改善翻譯結果：

- **術語表功能**：預先指定特定詞彙的譯法，確保專有名詞與術語在全文中保持一致。我們也針對不同翻譯引擎的特性進行了相應調整，讓這項功能在不同環境下都能穩定運作。
- **自動識別術語**：針對支援的語言，利用內建模型自動擷取人名並建立術語表，讓人物譯名在全文中保持一致。（註：拉丁字母語言之間的翻譯通常不需要轉換人名，因此這項功能不適用於此類翻譯。）你可以利用這項功能，快速找出整部影片中需要統一譯名的人物名稱。
- **背景說明**：向翻譯引擎補充場景背景或對話主題，協助引擎理解上下文。例如：「這是一個關於母愛和救援的故事，瑞秋為了拯救兒子付出了艱苦的努力。」請注意，這裡的目的是提供場景背景，而不是輸入 AI 提示詞，因此請避免填寫「翻譯得自然一些」之類的指令。
- **場景間隔（場景級翻譯）**：為了改善翻譯引擎處理長篇文字時可能出現的注意力下降問題，我們採用了場景級翻譯機制，透過設定場景間隔（預設為 30 秒），讓引擎能在適當的上下文範圍內進行翻譯，改善譯文的連貫性。對於對話數少於 500 條的劇集，將間隔縮短至 15 秒通常會有較好的效果。手動設定範圍為 0～99999 秒：設為 0 秒代表每句字幕都會獨立翻譯，較難維持上下文連貫性；間隔過長則可能讓引擎接收過多上下文，反而影響翻譯品質。
- **更換翻譯引擎**：不同引擎在處理特定語言或文風時，表現可能有所不同。

**另一種是「翻譯出錯」**

例如譯文中混入原文、出現異常標點，或部分句子完全沒有被翻譯。這類問題可能出在我們的處理邏輯上。

為了改善翻譯品質，程式會先將零散的字幕合併成完整、自然的句子，翻譯完成後，再拆分回原本的字幕片段。這個過程涉及複雜的判斷，即使訂定了詳細規則，面對不同的句子結構與字幕格式時，仍可能出現預期之外的錯誤。

由於我們不會在伺服器上儲存使用者的字幕檔案或翻譯內容，沒有原始字幕檔就很難重現問題。為了方便我們快速找出問題，回報時請盡可能提供以下資訊：

- 原始字幕檔
- 目標翻譯語言及介面設定截圖
- 下載按鈕下方顯示的翻譯日誌
- 出錯的字幕條目，以及你預期的翻譯結果

特別提醒：翻譯過程中的日誌區域會顯示這次翻譯任務的診斷資訊。基於隱私考量，這些日誌只會從翻譯引擎傳送至你的瀏覽器，開發者無法直接查看。因此，如果你在回報問題時一併提供日誌，就能大幅提高我們排查問題的效率。

另外請注意，重新整理頁面或開始新的翻譯任務後，原本的日誌就會消失，而且不會另外儲存。建議在回報問題前，先將日誌複製或保存下來。

此外，針對部分內容未被翻譯的情況，還有一點需要特別說明：

如果原始字幕包含多種語言，翻譯引擎可能無法正確辨識輸入內容的語言，因而跳過部分文字。

例如，一段同時包含英語和西班牙語的對話，如果要翻譯成法語，即使使用「自動偵測（連網）」，也不一定能準確辨識並區分兩種語言。翻譯引擎可能只理解其中一種語言，導致另一種語言的內容遭到遺漏。

雖然我們已經嘗試透過不同方式改善這個問題，但當字幕中的語言頻繁切換時，仍然很難完全避免。你可以試著縮短場景間隔，並搭配「自動偵測（連網）」使用，以減少這類情況。不過，場景間隔太短也可能影響上下文的連貫性，需要依照實際內容調整。

**使用技巧：** 一般來說，部分英語翻譯引擎對其他語言的理解能力有限，但支援其他語言的引擎往往也能理解英語。因此，如果字幕內容是「英語＋另一種語言」（例如英語＋西班牙語），可以試著將輸入語言指定為其中的外語（例如西班牙語）。利用該語言引擎對英語的理解能力，有時反而能得到更好的翻譯結果。

**關於簡繁轉換的特別說明**

簡體中文與繁體中文之間的轉換，看似只是文字形式的差異，但實際上還涉及詞彙、用語及語境上的不同。由於大多數翻譯引擎並未針對這類轉換進行專門訓練，因此轉換結果往往不夠理想。

我們計劃在未來導入專門的本地端模型處理簡繁轉換，並另外開發獨立的簡繁轉換工具。

目前，如果你需要較高品質的簡繁轉換，建議使用 OpenCC 或繁化姬等專門工具。

## 關於服務連線問題

我們收到一些使用者回報，表示無法正常連線或使用服務。經過排查，這類問題通常可以歸納為以下兩種情況：

首先是網路連線問題。部分使用者可能會遇到連線逾時，或無法連上後端伺服器的情況。雖然我們已盡可能減少資料傳輸量並降低連線延遲，但受到部分地區網路環境的限制，仍可能出現無法順利連線的情況。

其次是攔截工具造成的影響。部分廣告攔截器或 DNS 過濾工具，可能會誤將後端伺服器使用的次網域判定為需要封鎖的對象，導致服務無法正常連線。

如果遇到這類問題，可以參考以下說明進行排查：[無法連線到服務？可能是 DNS 過濾規則的影響](../service-access/zh-Hant.md)。

## 關於介面與功能

如果你覺得介面不好用，或發現某個按鈕沒有反應，都歡迎回報。

字幕預覽介面是一個在瀏覽器中執行的小型字幕編輯器，需要即時處理各種字幕格式轉換與相容性問題。如果發現介面異常，可以先點擊右下角的版本號，檢查並更新至最新版，因為相關問題可能已在新版本中修復。如果更新後問題仍然存在，回報時請附上目前的版本號。

## 關於安全漏洞

我們非常重視安全與隱私，但程式碼仍可能存在漏洞。

如果你發現安全漏洞或可能造成嚴重影響的邏輯錯誤，請透過私訊直接聯絡專案的核心開發者，避免在 GitHub Issues 或其他公開社群平台上揭露。這樣我們就能先確認並修復問題，避免其他使用者在漏洞修復完成前受到影響。詳細流程請參考 [安全漏洞回報指南]。

## 在哪裡回報？

**建議使用 GitHub Issues**

如果你有 GitHub 帳號，可以透過 [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues/) 提交問題。集中整理的回報更方便追蹤處理進度，也能讓其他遇到相同問題的人找到相關資訊。

**其他方式：社群平台**

如果你沒有 GitHub 帳號，也可以透過官方社群（Telegram、IRC、Discord）與大家交流。無論是使用時遇到問題，還是有新的想法或功能建議，都歡迎加入討論。

**關於討論區**

本站的討論區使用 [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions/)，主要用來分享使用經驗、交流想法及討論新功能。為了方便追蹤 Bug 的修復進度，請將問題回報提交至 GitHub Issues，讓討論區繼續專注於經驗分享與想法交流。

參與社群交流前，也歡迎閱讀 [貢獻者公約](../code-of-conduct/zh-Hnat.md)，一起維護開放、友善、彼此尊重的交流環境。
