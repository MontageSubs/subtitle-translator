# 關於問題回報與建議

蒙太奇字幕翻譯器的持續改進，離不開每位使用者的回饋。當你發現 Bug 並回報時，就能幫助我們找出問題、改善工具，讓其他使用者也能受益。每一則回報都是對專案的貢獻，謝謝你願意參與。

為了讓問題更容易重現、定位與修復，回報之前，可以先看看以下說明。

---

### 關於翻譯結果的問題

翻譯結果不理想，通常有兩種情況。

**一種是「翻譯品質不理想」**

例如用詞不精準、語法不自然等。這通常與翻譯引擎本身及其接收到的上下文有關，超出了我們能直接控制的範圍。你可以試著透過以下方式改善翻譯結果：

1. 更換翻譯引擎：不同引擎在處理特定語言或文風時，表現可能有所不同。
2. 使用術語表：指定特定詞彙的譯法，讓專有名詞和術語保持一致。
3. 提供背景說明：幫助引擎理解劇情發展或人物關係（如果引擎支援）。
4. 調整場景間隔：改變每次送交引擎翻譯的文本範圍，有時能改善譯文的連貫性。

**另一種是「翻譯出錯」**

例如譯文中混入原文、出現異常標點，或部分句子完全沒有被翻譯。這類問題可能出在我們的處理邏輯上。

為了改善翻譯品質，程式會先將零散的字幕合併成完整、自然的句子，翻譯完成後，再拆分回原本的字幕片段。這個過程涉及複雜的判斷，即使訂定了詳細規則，面對不同的句子結構與字幕格式時，仍可能出現預期之外的錯誤。

由於我們不會在伺服器上儲存使用者的字幕檔案或翻譯內容，沒有原始字幕檔就很難重現問題。因此，回報這類問題時，請附上原始字幕檔、目標翻譯語言、介面設定截圖，以及下載按鈕下方顯示的翻譯日誌。

如果能進一步指出出錯的字幕條目，並說明預期的結果，也會有助於確認問題。

### 關於時間軸的問題

為了避免翻譯引擎修改時間軸，時間軸不會送交引擎處理，而是在取得譯文後，再由程式重新拼接回去。

這樣可以避免引擎直接改動時間軸，但我們自己的拼接邏輯在極少數特殊情況下仍可能出錯。如果發現時間軸異常，歡迎回報，並附上原始字幕檔，方便重現和排查問題。

### 關於介面與功能

如果你覺得介面不好用，或發現某個按鈕沒有反應，都歡迎回報。

字幕預覽介面是一個在瀏覽器中執行的小型字幕編輯器，需要即時處理各種字幕格式轉換與相容性問題。如果發現介面異常，可以先點擊右下角的版本號，檢查並更新至最新版，因為相關問題可能已在新版本中修復。如果更新後問題仍然存在，回報時請附上目前的版本號。

### 關於安全漏洞

我們非常重視安全與隱私，但程式碼仍可能存在漏洞。

如果你發現安全漏洞或可能造成嚴重影響的邏輯錯誤，請透過私訊告知，避免直接在 GitHub Issues 或其他公開社群管道揭露。這樣可以先確認並修復問題，避免其他使用者在修復完成前受到影響。詳細流程請參考 [安全漏洞回報指南]。

### 在哪裡回報？

**建議使用 GitHub Issues**

如果你有 GitHub 帳號，可以透過 [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues/) 提交問題。集中整理的回報更方便追蹤處理進度，也能讓其他遇到相同問題的人找到相關資訊。

**其他方式：社群平台**

如果你沒有 GitHub 帳號，也可以透過官方社群（Telegram、IRC、Discord）與大家交流。

**關於討論區**

本站的討論區使用 [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions/)，主要用來分享使用經驗、交流想法及討論新功能。為了方便追蹤 Bug 的修復進度，請將問題回報提交至 GitHub Issues，讓討論區繼續專注於經驗分享與想法交流。

參與社群交流前，也歡迎閱讀 [社群準則]，一起維護開放、友善、彼此尊重的交流環境。
