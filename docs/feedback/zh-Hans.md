为了让问题更容易复现和定位，提交反馈前，可以先看看下面的说明。

## 关于翻译结果的问题

翻译结果不理想，通常有两种情况。

**一种是「翻译得不好」**

例如用词不准确、语法不自然等。这通常与翻译引擎本身及其接收到的上下文有关。可以尝试以下方法改善结果：

1. 更换翻译引擎：不同引擎在处理特定语种或文风时，表现可能有所不同。
2. 使用术语表：指定特定词汇的译法，让专有名词和术语保持一致。
3. 提供背景说明：帮助引擎理解剧情发展或人物关系（如果引擎支持）。
4. 调整场景间隔：改变每次送交引擎翻译的文本范围，有时能改善译文的连贯性。

**另一种是「翻译出错」**

例如译文中混入原文、出现异常标点，或部分句子完全没有被翻译。这类问题可能出在字幕处理逻辑上。

为了改善翻译质量，程序会先将零散的字幕合并成完整、自然的句子，再将译文拆分回原来的字幕片段。这个过程涉及复杂的判断，即使制定了详细的规则，面对不同的句子结构和字幕格式时，仍然可能出现意料之外的错误。

由于服务器不会存储用户的字幕文件或翻译内容，没有原始字幕文件就很难复现问题。因此，反馈这类问题时，请附上原始字幕文件、目标语言、界面设置截图，以及下载按钮下方显示的翻译日志。

如果能进一步指出出错的字幕条目，并说明预期的结果，也会有助于确认问题。

## 关于时间轴的问题

为了避免翻译引擎修改时间轴，时间轴不会发送给引擎，而是在收到译文后，由程序重新拼接回去。

这种方式可以避免引擎直接改动时间轴，但拼接逻辑在极少数情况下仍可能出错。如果发现时间轴异常，欢迎反馈，并附上原始字幕文件，方便复现和排查问题。

## 关于界面与功能

如果界面操作不符合预期，或者某个按钮没有反应，都欢迎反馈。

字幕预览界面是一个在浏览器中运行的小型字幕编辑器，需要实时处理各种字幕格式转换与兼容性问题。遇到异常时，可以先点击右下角的版本号，检查并更新至最新版，因为相关问题可能已经在新版本中修复。如果更新后问题仍然存在，请在反馈时附上当前版本号。

## 关于安全漏洞

我们非常重视安全与隐私，但再完善的设计也无法保证代码绝对没有漏洞。

如果发现安全漏洞或可能造成严重影响的逻辑错误，请通过私信告知，避免直接在 GitHub Issues 或其他公开渠道披露。这样可以先调查并修复问题，再公开相关细节，避免其他使用者在修复完成前受到影响。具体流程请参考 [安全披露指南]。

## 在哪里反馈？

**推荐方式：GitHub Issues**

如果有 GitHub 账号，可以通过 [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues/) 提交问题。集中整理的反馈更容易追踪处理进度，也方便其他遇到相同问题的人查找相关信息。

**其他方式：社区平台**

如果没有 GitHub 账号，也可以通过官方社区（Telegram、IRC、Discord）交流。无论是使用时遇到问题，还是对工具有新的想法，都欢迎参与讨论。

**关于讨论区**

本站的讨论区使用 [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions/)，主要用于分享使用经验、交流想法和讨论新功能。为了方便追踪 Bug 的修复进度，请将问题反馈提交至 GitHub Issues，把讨论区留给经验分享与想法交流。

参与社区交流前，也欢迎阅读 [社区准则]，一起维护开放、友善、彼此尊重的交流环境。
