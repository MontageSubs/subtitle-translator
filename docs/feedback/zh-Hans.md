## 关于翻译结果的问题

翻译结果不理想，通常有两种情况。

**一种是「翻译得不好」**

例如用词不准确、语法不自然等。这通常与翻译引擎本身及其接收到的上下文有关。你可以尝试使用以下功能来改善结果：

- **术语表功能**：通过提前锁定特定词汇的译法，确保翻译的一致性。我们针对不同引擎的特性进行了适配，以确保该功能在各种环境下均能稳定可用。
- **自动识别术语**：在受支持的语言中，利用内置模型自动提取人名并构建术语表，从而保证全篇译名统一（注：拉丁字母语言之间翻译通常不改变人名，因此模型不适用于此类翻译）。你可以利用此功能快速找出全片需要保持一致的名称。
- **背景说明**：向引擎阐述场景或对话的主题（例如：“这是一个关于母爱和救援的故事，瑞秋为了拯救儿子付出了艰苦的努力”）。请注意，此处旨在提供场景上下文而非输入 AI 提示词，请避免填写如“翻译得自然一些”等指令。
- **场景间隔（场景级翻译）**：为了解决翻译引擎在处理长文本时可能出现的注意力下降问题，我们采用了场景级翻译方案。该功能通过定义场景界限（默认 30 秒）来优化译文的连贯性。对于对话数少于 500 条的剧集，将间隔缩短至 15 秒通常会有较好效果。手动设置支持 0-99999 秒：0 秒意味着每句独立翻译（缺乏连贯性），过高则可能导致上下文过多而影响质量。
- **更换翻译引擎**：不同引擎在处理特定语种或文风时，表现可能有所不同。

**另一种是「翻译出错」**

例如译文中混入原文、出现异常标点，或部分句子完全没有被翻译。这类问题可能出在字幕处理逻辑上。

为了改善翻译质量，程序会先将零散的字幕合并成完整、自然的句子，再将译文拆分回原来的字幕片段。这个过程涉及复杂的判断，即使制定了详细的规则，面对不同的句子结构和字幕格式时，仍然可能出现意料之外的错误。

由于服务器不会存储用户的字幕文件或翻译内容，没有原始字幕文件就很难复现问题。为了高效定位问题，请在反馈时提供以下信息：

- 原始字幕文件
- 目标语言与界面设置截图
- 下载按钮下方的翻译日志
- 出错的具体条目及预期结果

特别提示：工具翻译时的日志区域提供了本次任务的诊断数据。出于隐私考虑，该日志仅从翻译引擎转发至你的浏览器，对开发者不可见。在反馈问题时提供该日志将极大提高诊断效率。请注意，日志在刷新页面或开始新任务后会丢失，不会持久保存。

此外，关于部分内容未被翻译的情况：

当原始字幕包含多种语言时，翻译引擎可能会因无法准确识别输入语言而产生困惑，导致部分内容被跳过。例如，一段英西双语对话翻译至法语时，即使使用自动检测（联网），也难以完美剥离每种语言，引擎可能会倾向于只理解其中一种，从而遗漏另一种语言的内容。

虽然我们尝试通过多种方案解决，但面对高频的语言切换仍难以完全避免。降低场景间隔并配合“自动检测（联网）”可以缓解该问题，但过低的间隔可能会牺牲上下文连贯性。

技巧分享：通常英语引擎难以理解外语，但其他语言的引擎往往能理解英语。如果你的内容是“英语 + 另一种语言”（如英语 + 西班牙语），尝试将输入语言指定为该外语（如西班牙语），往往能利用该引擎对英语的兼容能力实现更好的翻译效果。

**关于简繁转换的特别说明**

针对简体中文与繁体中文之间的互转，由于大多数翻译引擎并未针对此类转换进行专业训练，其结果往往不尽如人意。我们计划在未来引入专用的本地模型来处理此类转换，并独立开发简繁转换工具。在当前阶段，如果你需要高质量的简繁互转服务，我们建议你使用 OpenCC 或 繁化姬 等专业工具。

## 关于服务连接问题

我们收到部分用户反馈无法正常使用服务。经过诊断，主要原因通常分为以下两类：

首先是网络连接问题。部分用户可能会遇到连接超时或无法访问后端服务器的情况。尽管我们已尽力优化数据传输量并降低延迟，但在部分地区的网络物理环境下，仍存在一些客观的连接限制。

其次是拦截工具的影响。部分广告拦截器或 DNS 过滤器可能会误拦截我们后端服务器使用的二级域名。具体排查方案请参阅：[无法连接服务？可能是 DNS 过滤规则的影响](../service-access/zh-Hans.md)。

## 关于界面与功能

如果界面操作不符合预期，或者某个按钮没有反应，都欢迎反馈。

字幕预览界面是一个在浏览器中运行的小型字幕编辑器，需要实时处理各种字幕格式转换与兼容性问题。遇到异常时，可以先点击右下角的版本号，检查并更新至最新版，因为相关问题可能已经在新版本中修复。如果更新后问题仍然存在，请在反馈时附上当前版本号。

## 关于安全漏洞

我们非常重视安全与隐私，但再完善的设计也无法保证代码绝对没有漏洞。

如果发现安全漏洞或可能造成严重影响的逻辑错误，请通过私信告知项目核心开发者，避免直接在 GitHub Issues 或其他公开渠道披露。这样可以先调查并修复问题，再公开相关细节，避免其他使用者在修复完成前受到影响。具体流程请参考[安全披露指南](../security/zh-Hans.md)。

## 在哪里反馈？

**推荐方式：GitHub Issues**

本站的讨论区使用 [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions/)，主要用于分享使用经验、交流想法和讨论新功能。为了方便追踪 Bug 的修复进度，请将问题反馈提交至 GitHub Issues，把讨论区留给经验分享与想法交流。
