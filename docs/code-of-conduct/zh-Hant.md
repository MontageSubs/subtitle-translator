# 貢獻者公約

## 我們的承諾

我們承諾讓社群對所有人都友善、安全且公平。

我們致力於營造尊重並促進每個人尊嚴、權利與貢獻的環境，不因其種族、族裔、種姓、膚色、年齡、身體特徵、神經多樣性、身心障礙、生理性別或社會性別、性別認同或表達、性傾向、語言、哲學或宗教信仰、國籍或社會出身、社經地位、教育程度或其他身分條件而有所差別。凡本於善意參與並遵守本公約的人，皆享有平等的參與權利。

## 值得鼓勵的行為

我們理解不同社會規範可能有所差異，但大家都努力符合社群對正向行為的期待。我們也明白，文化、背景或母語不同，可能使他人對我們言行的解讀與我們原本的用意有所出入。

因此，我們同意用心對待彼此，並以以下共同價值為行為準則：

1. 尊重社群的**宗旨**、各項活動及聚會方式。
2. 以**友善且誠實**的態度與他人互動。
3. 尊重**不同的觀點與經驗**。
4. 對自己的言行及貢獻**負起責任**。
5. 得體地提出並接受**建設性回饋**。
6. 承諾在造成傷害時**設法修復**。
7. 以其他有助於促進並維護**社群福祉**的方式行事。

## 受限制的行為

我們同意在社群中限制以下行為。實際從事、威脅從事或鼓吹這些行為，均屬違反本行為準則。

1. **騷擾。** 逾越他人明確表達的界線，或在對方明確要求停止後，仍持續對其作出不必要的個人關注。
2. **人身攻擊。** 對社群成員或群體發表侮辱、貶抑或輕蔑的言論。
3. **刻板印象或歧視。** 根據他人無法改變的身分或特徵，評斷其個性或行為。
4. **性化對待。** 做出在社群情境或宗旨下通常會被視為不恰當的親密行為。
5. **違反保密。** 未經他人同意，分享或利用其個人或隱私資訊。
6. **危害他人安全。** 對任何個人或群體施加、煽動或威脅施加暴力或其他傷害。
7. 以其他方式**威脅社群福祉**。

### 其他限制行為

1. **冒用身分。** 基於任何理由冒充他人，或假扮他人以規避處置措施。
2. **未正確標示來源。** 未適當標示所貢獻內容的來源。
3. **宣傳內容。** 以不符合社群規範的方式分享行銷或其他商業內容。
4. **不負責任的傳播。** 未以負責任的方式呈現包含、連結至或描述其他受限制行為的內容。

## 通報事件

即使社群成員都盡力合作，彼此之間仍可能發生摩擦。並非所有衝突都代表違反行為準則；本行為準則旨在強化值得鼓勵的行為與規範，協助預防衝突並將傷害降至最低。

事件發生時，及時通報非常重要。若要通報疑似違規行為，請透過 **[注意：請在此填寫通報方式。]**

社群管理員會嚴肅看待違規通報，並盡力及時回應。所有違反行為準則的通報都會接受調查，調查方式包括檢視訊息、紀錄及錄音，或訪談目擊者及其他相關人士。在優先保障安全與保密的前提下，社群管理員會盡可能讓調查與處置過程保持透明。為維護這些原則，處置會在相關人士的私人空間中進行；若各方同意，也可以將事件告知整個社群，作為解決方式的一部分。

## 處理與修復傷害

**[注意：以下處理方式與修復措施，是根據行為準則執行方面的最佳實務所提出的建議。若社群已有既定的執行程序，請修改本節，說明社群自身的政策。]**

若社群管理員經調查確認有人違反本行為準則，將依事件對相關人士及整個社群造成的影響，參考以下分級處置機制，判斷最適當的傷害修復方式。視違規情節的嚴重程度，可以跳過較低級別的處置。

1) 警告  
   1) **適用情況**：單次或一連串違規行為。  
   2) **處置方式**：社群管理員以私人訊息發出書面警告。  
   3) **修復方式**：例如私下以書面道歉、承認自己應負的責任，或主動確認往後應如何行事才能符合社群期待。

2) 暫時限制活動  
   1) **適用情況**：重複發生先前已受警告的違規行為，或首次發生情節較嚴重的違規行為。  
   2) **處置方式**：以私人訊息發出書面警告，並設定一段有期限的冷靜期，以凸顯事態的嚴重性，並讓受影響的社群成員有時間消化及處理事件。冷靜期可能限制當事人使用特定交流管道，或與特定社群成員互動。  
   3) **修復方式**：例如道歉、利用冷靜期反省自身行為及其影響，並充分了解冷靜期結束後如何重新參與社群。

3) 暫時停權  
   1) **適用情況**：多次受社群管理員警告後仍持續違規，或發生一次嚴重違規行為。  
   2) **處置方式**：以私人訊息發出書面警告，並說明恢復權限須符合的條件。暫時停權通常是為了讓當事人有時間反省自身行為，並思考可能的改正方式。  
   3) **修復方式**：包括尊重停權的目的、符合指定的恢復權限條件，並充分了解停權解除後如何重新融入社群。

4) 永久封禁  
   1) **適用情況**：一再違反行為準則，且其他分級處置均未能解決問題；或違規情節嚴重到社群管理員認定，若該成員繼續留在社群中，便無法保障社群安全。  
   2) **處置方式**：撤銷當事人使用所有社群空間、工具及交流管道的權限。一般而言，永久封禁應極少使用，必須有充分且有力的理由，並且只應在其他修復方式未能促使行為改變時，作為最後手段。  
   3) **修復方式**：情節嚴重至此時，已沒有可行的修復方式。

本分級處置機制旨在提供指引，不限制社群管理者為了社群的最大利益，運用其裁量權與判斷力。

## 適用範圍

本行為準則適用於所有社群空間；個人在公開或其他場合正式代表社群時，也適用本行為準則。代表社群的情況包括但不限於：使用官方電子郵件地址、透過官方社群媒體帳號發布內容，或受指派代表社群參加線上或實體活動。
