# About Montage Subtitle Translator

Montage Subtitle Translator is an open-source subtitle translation tool built by [MontageSubs](https://github.com/MontageSubs), a community of fansub enthusiasts.

It combines Google's neural machine translation with a glossary mechanism and subtitle-specific formatting logic to produce bilingual or monolingual subtitles that read more naturally than raw machine translation, without changing the timing of the original file.

The project is fully open source under the MIT license. Contributions, bug reports, and translation improvements are welcome on [GitHub](https://github.com/MontageSubs/subtitle-translator).
