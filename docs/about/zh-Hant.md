# 關於蒙太奇字幕翻譯器

蒙太奇字幕翻譯器是蒙太奇字幕社群（MontageSubs）製作的免費開源字幕翻譯工具，支援 SRT、VTT、ASS，可在 200 多種語言之間互譯。不用註冊、沒有廣告，也不會追蹤你。

## 我們是誰

蒙太奇字幕社群裡有影視愛好者、字幕組成員，也有開發者。核心的字幕組堅持純手工製作，不論是用字遣詞、時間軸，還是特效排版，都很講究。

講究就得花時間，一部作品常常要好幾個星期，許多想做的片子只好割捨。觀眾不是乾等，就是勉強看著生硬的機器翻譯。

## 為什麼做這個工具

它原本只是我們自己用的幾支小程式，在人工翻譯進行時，先產出一份參考稿。後來整理成工具，開放給大家使用。目標是快速拿到一份讀得順、格式也整齊的初稿。它無法取代字幕組的人工精翻，也不打算取代。

## 它有什麼不一樣

光靠翻譯引擎，翻不出像樣的字幕。我們的心力多半花在引擎的前後。

- **場景級翻譯。** 不是逐行送出，而是先把字幕合併成完整的句子，再依場景整段翻譯，引擎讀到的是前後連貫的對白。
- **詞彙表說了算。** 你設定的人名與用語會被強制套用到譯文裡，即使引擎本身不支援詞彙表也一樣。
- **在本機辨識人名。** 像英翻中、日翻中這類人名寫法會改變的語言組合，瀏覽器裡的小型模型會先找出人名並建好詞彙表，讓全片譯名一致。
- **譯文回到原本的時間軸。** 翻好的長句會再拆回原本的字幕條目，中日韓這類詞與詞之間沒有空格的語言也不例外。
- **懂字幕的功能。** 可以直接從 MKV 讀出字幕，也能選擇移除 SDH 聽障標註、讓歌詞維持原文，並支援雙語輸出與 ASS 樣式。
- **下載前先檢查。** 內建編輯器與對照檢視，漏譯、殘留原文、單行過長、語速過快的字幕都會標出來。

想知道這些是怎麼搭配運作的，可以看看[翻譯引擎與模型支援](../model-access/zh-Hant.md)。

## 免費，也希望一直免費

目前支援 200 多種語言。不同語言組合的品質有高有低，我們會依據大家的回饋持續調整。

常有人問，為什麼不用大型語言模型（LLM）。LLM 的翻譯確實更好，但一份字幕檔平均約 1,500 行，每個人都走 LLM，對免費的社群服務來說成本太高，品質的提升也未必划算。所以我們選了 NMT（神經機器翻譯），再用場景級處理盡量發揮它的實力。等 LLM 的成本降下來，我們很樂意導入。如果你能提供 API 額度或其他資源，歡迎看看[如何貢獻](../contribute/zh-Hant.md)。

## 隱私

不用帳號、沒有廣告、不做使用者剖析，也不使用 Cookie。字幕只是經過伺服器轉送給翻譯引擎，不會被保存。更完整的說明請見[隱私權政策](../privacy/zh-Hant.md)。

## 需要說明的幾件事

服務由社群志工利用業餘時間維護。我們會盡力維持穩定，但無法保證 100% 不中斷，詳情請見[服務條款](../terms/zh-Hant.md)。

機器翻譯難免出錯，複雜的 ASS 特效排版也可能需要手動調整。分享之前，請先把成品看過一遍。

## 一起參與

寫程式、回報問題、提出想法、翻譯介面，或是跟朋友推薦一下，都是很大的幫忙。不一定要貢獻什麼，隨時來打聲招呼就好。
