# 關於蒙太奇字幕翻譯器

這是一個由 **蒙太奇字幕社群 (MontageSubs)** 打造並維護的 [開源項目](https://github.com/MontageSubs/subtitle-translator)。

## 我們是誰
**蒙太奇字幕社群** 其實就是一群超級愛看片、也愛弄字幕的夥伴。我們對字幕的品質有點「強迫症」，不管是翻譯的精準度還是特效的細節，都希望追求到極致。

在社群裡，我們有蒙太奇字幕組，堅持純手工慢慢磨每一部作品。但說實話，這種對品質的執著，導致產出速度真的慢得驚人，一部作品可能要花好幾個禮拜才能出爐。這導致很多很棒的作品，因為人力跟時間不夠，我們只能忍痛跳過。我們不希望好作品因為語言隔閡被遺忘，但同樣地，我們也沒辦法讓大家去忍受那種毫無靈魂、支離破碎的劣質機翻。

## 為什麼要做這個工具
這就是我們開發這個工具的初衷。我們想給所有愛好者提供一個簡單、快速的自翻譯方案。當你不想在複雜的設定或昂貴的付費牆前浪費時間，或者單純就是急著想看懂內容、需要一份結構專業且準確度尚可的譯本來「救急」時，它可以幫你快速填補這個空窗期。

## 技術上的小堅持
很多翻譯工具只是死板地把字幕一行一行丟給引擎，結果譯文往往斷章取義，完全沒有上下文，甚至會出現詞不達意或時間軸亂掉的情況。

為了改善這個問題，我們嘗試了一套不同的做法。我們不再發送碎片化的單行字幕，而是把整個場景的內容重新組合，將被拆分的句子合併成完整的自然語言文本，再交給翻譯引擎。這樣引擎才能「感覺」到對話的連貫性，翻出來的語氣才會自然很多。

最麻煩的是後續的「還原」過程，也就是要把翻譯好的句子，精準地對齊回原有的時間軸片段中。特別是在中日韓這種沒有明顯詞界線的語言裡，我們寫了大量代碼來實現語義切分，盡量確保翻譯後的字幕結構依然維持專業水準。

## 關於語言支持與限制
目前工具支持 **200 多種語言** 互譯。但得老實說，支持的語言多，並不代表每種都完美，有些特殊場景可能還沒來得及優化。作為一個開源項目，我們希望在更多人的使用與貢獻下，能一點一點把各種語種的適用性磨得更好。

很多人會問，為什麼不用現在流行的 AI (LLM)？不可否認，AI 翻譯確實比我們採用的 NMT（神經機器翻譯）強很多，但成本真的太驚人了。一個字幕文件平均有 1,500 行，如果全部走 AI，每天處理這種量級的費用會高得離譜，而實際上的品質提升可能不到 10%。

為了讓每個人都能免費使用，我們選擇了 **CP 值更高** 的 NMT 方案。現在的翻譯引擎已經吸收了很多 AI 的優勢，在保證速度與低成本的同時，大幅解決了傳統機翻的生硬感。此外，我們還透過重新組織自然語言和場景級翻譯，盡量把 NMT 的品質發揮到極限。在 AI 成本大幅下降之前，這應該是最能持續走下去的方案。當然，如果是有能力的朋友願意提供 AI 支持，我們非常歡迎。

## 如何參與
這是一個純粹的社群項目，我們歡迎任何形式的參與。

無論你是能貢獻代碼、回報 bug、提供新點子，還是願意幫忙翻譯界面、提供 API 配額，甚至只是幫我們宣傳和給予反饋，每一份幫助都會讓這個工具變得更好。[[了解如何貢獻]](../contribute/zh-Hant.md)

## 純淨與隱私
我們堅持非營利模式，沒有商業廣告，不追蹤用戶，也不需要註冊帳號。

在設計之初，隱私就是我們的優先考量。我們不記錄翻譯內容，字幕僅在經過伺服器後直接轉發給翻譯引擎。我們透過禁用 cookie、不追蹤用戶等手段，盡量抹除個人可識別資訊，確保這裡是一個純粹的、用愛驅動的開源公共服務。[[詳見隱私政策]](../privacy/zh-Hant.md)

## 幾句真心話
這個項目是由社群貢獻者在業餘時間維護的。我們會盡全力維持服務穩定，但因為是純粹的非營利貢獻，沒辦法承諾 100% 無故障。如果遇到日常維護、上游供應商調整或維護者精力波動，服務可能會出現短暫中斷，還請大家見諒。[[參見服務條款]](../terms/zh-Hant.md)

最後要說明的是，這個工具無法替代人工精譯的「信達雅」。它的目標很簡單，就是在絕大多數場景下，讓你在幾十秒內獲得一份結構完整、盡量準確且可用的字幕。
