# 關於蒙太奇字幕翻譯器

蒙太奇字幕翻譯器是由蒙太奇字幕社群（MontageSubs）開發及維護的開源、免費字幕翻譯工具，支援 SRT、VTT、ASS 字幕在 200 多種語言之間互譯，也能直接讀取 MKV 影片中的字幕。使用時無須註冊，沒有廣告，也不會追蹤使用者。

## 我們是誰

蒙太奇字幕社群是由影視愛好者、字幕製作者與開發者共同組成的非營利社群。我們在意字幕的每一個細節，包括譯文品質、時間軸是否準確，以及專業的排版。

社群底下的蒙太奇字幕組，堅持以純手工方式製作字幕。這樣的工作細緻而耗時，一部作品往往需要數週才能完成，不少作品因人力有限而只能割捨，觀眾只能選擇等待，或是接受品質不佳的機器翻譯。

## 為什麼開發字幕翻譯器

我們希望在這兩者之間，提供另一種選擇：一個快速又簡單的工具，讓每個人都能取得可讀、結構完整的譯文，不需要繁瑣的設定，也不必跨過付費門檻。

這項工具最初只是我們內部使用的程式腳本，用來在人工翻譯的同時先產出參考初稿。由於源自實際的字幕製作，它也具備字幕製作者需要的功能，例如讀取影片中的字幕、處理聽障輔助字幕，以及檢查字幕語速。後來我們持續完善，並開放給所有人使用。

## 字幕翻譯是如何運作的

多數翻譯工具會把字幕逐行交給翻譯引擎。這樣做會失去前後文，跨越多條字幕的句子被拆成片段翻譯，譯文也就容易出現語氣不自然、用語不一致或措辭不當的情況。

我們的做法是先把相關的字幕合併成完整的句子，再依場景分組，將每個場景以連續文字的形式交給翻譯引擎，時間軸與樣式不會出現在請求中。如此一來，引擎便能參考整段對話來理解語境。

更困難的是還原：把翻好的句子重新拆開，放回原本每一條字幕與其時間軸中。對於中文、日文這類沒有明確詞彙邊界的語言，這項工作尤其複雜。我們為此投入了大量開發心力，希望各種語言組合的時間軸與結構都能維持完整。

## 專為字幕製作設計的功能

- **場景級翻譯。** 引擎收到的是整個場景，而不是零散的單行字幕。可透過滑桿調整場景的切分粗細，以配合不同類型的影視內容。
- **強制詞彙表。** 你設定的人名與用語會在全片中保持一致，即使引擎本身不支援詞彙表也同樣有效。
- **本機人名辨識。** 對於人名寫法會改變的語言組合，例如英文翻中文，瀏覽器中執行的小型模型會辨識人名並建立詞彙表，供你確認。
- **時間軸還原與自動修復。** 譯文會對齊回原本的字幕條目，引擎產生的缺漏、損壞等錯誤也會被自動偵測並修正。
- **字幕專用工具。** 可直接讀取 MKV 影片中的字幕、移除 SDH 標註、讓歌詞維持原文，並支援匯出雙語字幕與帶有樣式的 ASS 檔案。
- **內建校對。** 附有對照檢視的編輯器，會標出漏譯、殘留原文、過長的行與過快的語速。
- **本機資料。** 翻譯記錄與下載的模型都保存在瀏覽器中，介面也提供多種語言。

想進一步了解這些功能背後的技術，請參閱[翻譯引擎與模型支援](../model-access/zh-Hant.md)。

## 語言支援與選擇 NMT 的原因

目前工具支援 200 多種語言。涵蓋範圍廣，並不代表每個語言組合的品質都一樣好，部分情境仍有待改進，我們會依據社群的回饋持續調整。

常有人問我們為什麼不使用大型語言模型（LLM）。LLM 的整體翻譯品質確實較好，這一點我們不迴避。但一份字幕檔平均約 1,500 行，要為每位使用者處理這樣的量，對免費的社群服務而言成本過高，而品質上的提升也不足以抵銷這筆開銷。

因此我們選擇了神經網路機器翻譯（NMT），並在它周邊投入大量工作。目前的 NMT 引擎已吸收了 LLM 的不少優點，回應快、成本低，也大幅減輕了傳統機器翻譯的生硬感。問題出在字幕的處理方式：傳統的機器翻譯字幕服務缺乏前後文，往往逐行翻譯，譯文常常詞不達意。我們以場景級翻譯來解決這個問題，並搭配強制詞彙表、人名辨識、時間軸還原與自動修復。這些是本專案絕大部分程式碼之所在，也讓我們得以把 NMT 的翻譯品質盡可能推向極限。如果 LLM 的成本大幅下降，我們很樂意導入；若你能提供 API 額度或其他資源，也非常歡迎，詳見[如何貢獻](../contribute/zh-Hant.md)。

## 隱私與透明

使用本工具無須帳號，沒有廣告，不做使用者剖析，也不追蹤使用者，我們不使用 Cookie。字幕僅會經過伺服器轉送給翻譯引擎，不會被保存。

專案原始碼完全公開，網站由 GitHub Actions 直接部署，任何人都能查證它的運作方式。詳情請見[隱私權政策](../privacy/zh-Hant.md)。

## 限制與服務穩定性

本專案由社群貢獻者利用業餘時間維護。我們會盡力維持服務穩定，但作為非營利的投入，無法保證不間斷運作。日常維護、上游供應商的調整，或維護者時間有限，都可能造成服務短暫中斷，還請見諒。詳情請見[服務條款](../terms/zh-Hant.md)。

需要說明的是，這個工具無法取代人工精譯所追求的「信達雅」。它的目標很單純：讓每個人都能用上盡可能高品質的字幕翻譯，在絕大多數情況下，幾十秒內就能取得一份結構完整、盡量準確又能直接使用的字幕。機器翻譯仍可能出錯，複雜的 ASS 特效排版也可能需要手動調整，發布前請自行檢查。
