# 關於蒙太奇字幕翻譯器

這是一個由 **蒙太奇字幕社群 (MontageSubs)** 開發與維護的[開源專案](https://github.com/MontageSubs/subtitle-translator)。

## 我們是誰
**蒙太奇字幕社群** 是一群熱愛影視作品、也熱衷於製作字幕的夥伴所組成的社群。我們對字幕品質有點「強迫症」，無論是翻譯的精準度，還是特效字幕的細節，都希望能做到最好。

社群旗下的蒙太奇字幕組，堅持以純人工的方式，仔細打磨每一部作品。但說實話，正因為我們對品質有著近乎執著的堅持，製作速度往往慢得驚人，一部作品可能就得花上好幾個星期才能完成。這也導致許多優秀的作品，即使我們很想製作，最後還是會因為人力與時間有限而不得不忍痛放棄。我們不希望好作品因為語言隔閡而被埋沒，但也不希望大家只能將就於生硬、破碎、缺乏語境的劣質機器翻譯。

## 為什麼要做這個工具
這就是我們開發這個工具的初衷：為所有影視愛好者提供一個簡單、快速的字幕自動翻譯方案。當你不想花時間研究繁瑣的設定，也不想被付費牆擋住，或只是急著想看懂一部作品，需要一份格式完整、翻譯品質尚可的字幕來應急時，這個工具就能派上用場，幫你快速跨越語言的障礙。

## 技術上的堅持
許多翻譯工具只是機械式地將字幕逐行送進翻譯引擎，卻忽略了前後文的關聯。結果譯文往往斷章取義，不僅容易出現用詞不當、語意不清的問題，還可能造成字幕與時間軸對不上的情況。

為了改善這些問題，我們嘗試採用不同的處理方式。我們不再將零碎的單行字幕直接送進翻譯引擎，而是先重新整理整個場景的字幕內容，將被拆開的句子合併成完整、連貫的自然語言，再交由翻譯引擎處理。如此一來，引擎就能掌握更多上下文資訊，讓譯文的語意與對話語氣更加自然。

真正棘手的，是接下來的「還原」步驟：如何將翻譯完成的句子，準確地對應回原本的字幕片段與時間軸。尤其是中文、日文、韓文等沒有明顯空白字元作為詞語分界的語言，要將完整句子重新切分並對應到原有的字幕片段，並不是一件容易的事。為此，我們撰寫了大量程式碼來處理語意切分與字幕對齊，盡可能在改善翻譯品質的同時，維持字幕原有的結構與時間軸精度。

## 語言支援與限制
目前，本工具支援 **200 多種語言的互相翻譯**。不過，我們也必須坦白說，支援的語言再多，也不代表每一種語言組合都能有同樣理想的翻譯品質；部分特殊情境仍有待持續調整與改善。作為一個開源專案，我們希望透過更多使用者的實際使用與社群貢獻，逐步提升不同語言組合的翻譯品質與適用性。

很多人可能會問：既然現在大型語言模型（LLM）這麼流行，為什麼不直接使用 AI 翻譯？不可否認，使用大型語言模型進行翻譯，在某些情境下確實能帶來更好的品質，但成本也是我們不得不考量的因素。一份字幕檔平均約有 1,500 行。如果每次翻譯都使用大型語言模型，當每天累積大量使用者與字幕檔時，所需的運算與 API 費用可能會高得難以負擔，而實際的品質提升幅度未必與成本相稱。

為了讓每個人都能免費使用這項服務，我們選擇了 **成本效益更高的神經機器翻譯（NMT）方案**。目前的神經機器翻譯技術已經相當成熟，搭配我們的場景級處理方式，不僅能兼顧翻譯速度與成本，也能在一定程度上改善傳統機器翻譯生硬、不夠連貫的問題。此外，我們也透過重新組織字幕內容、保留場景上下文等方式，盡可能發揮 NMT 的翻譯品質。在大型語言模型的使用成本進一步降低之前，我們認為，這是目前兼顧翻譯品質、處理速度與長期維運成本的可行方案。當然，如果有社群夥伴願意提供 AI 服務的 API 額度或其他資源，協助我們導入大型語言模型，我們也非常歡迎。

## 純粹的服務，重視你的隱私
我們堅持非營利的運作方式，不刊登商業廣告、不追蹤使用者，也不要求註冊帳號。隱私從設計之初就是我們重視的核心原則。字幕資料只會經過伺服器轉送至翻譯引擎，不會留存在本服務的資料庫裡。我們也透過停用 Cookie、避免追蹤使用者等方式，盡可能減少個人可識別資訊的蒐集與留存。我們希望打造一個單純、透明、由社群熱情所支持的開源公共服務，讓每個人都能安心使用。[[查看隱私權政策]](../privacy/zh-Hant.md)
