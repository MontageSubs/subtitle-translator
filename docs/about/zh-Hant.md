# 關於蒙太奇字幕翻譯器

蒙太奇字幕翻譯器是蒙太奇字幕社群（MontageSubs）製作的免費開源字幕翻譯工具，支援 SRT、VTT、ASS 字幕在 200 多種語言之間互譯，也能直接讀取 MKV 影片裡的字幕。不用註冊、沒有廣告，也不會追蹤你。

## 我們是誰

蒙太奇字幕社群是一群影視愛好者與開發者的聚集地。我們不只愛看片，更著迷於製作字幕：用字推敲得夠不夠、時間軸準不準、字幕在畫面上好不好看，都是我們會認真計較的事。

社群底下設有蒙太奇字幕組，至今仍堅持純手工打磨，對品質有種近乎偏執的堅持。但堅持品質的代價就是慢，一部作品常常要好幾個星期。

於是不少好片因為人力不足，只能無奈割捨。觀眾不是乾等，就是勉強看著毫無靈魂的機器翻譯，這兩種我們都不喜歡。我們不希望好作品因為語言隔閡被遺忘。

## 為什麼做這個工具

所以我們想給大家一個折衷的辦法：一套快速、簡單的自助翻譯，不必折騰複雜的設定，也不會被付費牆擋在門外。

它最早只是我們自己用的幾支小程式，在人工翻譯的同時先產出一份參考稿。因為出身於真實的字幕製作，它長出了不少字幕人真正需要的功能，例如直接讀取影片裡的字幕、清理聽障輔助字幕、檢查字幕語速。用起來順手，就整理出來，開放給所有人。

今晚就想看懂一部片的觀眾、想先拿到初稿再慢慢潤飾的字幕愛好者，或是單純想知道畫面上在說什麼的任何人，它都是為你們準備的。

## 換一種做法

很多翻譯工具只是把字幕一行一行丟給引擎，給什麼就收什麼。結果一句話被攔腰截斷，前後文消失，譯文生硬、前後不一，甚至詞不達意。

我們換了個思路：不再送出零碎的片段，而是把相關的字幕合併成完整、自然的句子，再依場景整段交給引擎，讓它像觀眾一樣順著對話讀下去。

真正棘手的是回程：把翻好的句子重新精準地放回原本的時間軸。我們在這上面花了很長的時間，尤其是中日韓這類詞與詞之間沒有明顯邊界的語言，就是為了讓各種語言組合之間，時間與結構都不走樣。

## 你能用到什麼

- **場景級翻譯。** 引擎讀到的是整場戲，而不是孤零零的一行行，滑桿可以調整場景切得多細。
- **詞彙表說了算。** 你設定的人名與用語會被強制套用到譯文裡，即使引擎本身不支援詞彙表也一樣。
- **在本機辨識人名。** 像英翻中、日翻中這類人名寫法會改變的語言組合，瀏覽器裡的小型模型會先找出人名並建好詞彙表，讓全片譯名一致。
- **回得去，也修得好。** 譯文會依標點對齊拆回原本的字幕條目，引擎中途弄壞的地方會被自動偵測並修復。
- **懂字幕的功能。** 可以直接從 MKV 讀出字幕，也能選擇移除 SDH 聽障標註、讓歌詞維持原文，並支援雙語輸出與 ASS 樣式。
- **下載前先檢查。** 內建編輯器與對照檢視，漏譯、殘留原文、單行過長、語速過快的字幕都會標出來。
- **資料留在你手上。** 記錄與下載的模型都存放在瀏覽器裡，介面也提供多種語言。

想知道這些是怎麼搭配運作的，可以看看[翻譯引擎與模型支援](../model-access/zh-Hant.md)。

## 免費，也希望一直免費

目前支援 200 多種語言互譯。不過支援得多，不代表每個語言組合都完美，部分特殊情境還沒優化到位。我們會靠大家的使用與回饋，一點一點把各個語言磨得更好。

很多人問，為什麼不用大型語言模型（LLM）。LLM 的翻譯確實更強，這一點我們不迴避。但一份字幕檔平均約 1,500 行，每個人都走 LLM，對免費的社群服務來說成本實在太高，換來的品質提升卻未必對得上這筆帳。

所以我們把力氣花在 NMT（神經機器翻譯）上。現在的 NMT 引擎已經吸收了 LLM 不少長處，回應快、成本低，但它們終究是逐行翻譯，看不到整場戲。剩下的功夫我們自己補：場景級的前後文、引擎無法忽視的詞彙表、本機辨識人名、把譯文放回原本的時間軸，還有會自己修復錯誤的流程。專案裡大部分程式碼就花在這上面，這也是我們能比直接呼叫翻譯引擎多擠出一截品質的原因。等 LLM 的成本降下來，我們很樂意導入；如果你能提供 API 額度或其他資源，歡迎看看[如何貢獻](../contribute/zh-Hant.md)。

## 隱私與透明

我們堅持非營利，不放廣告，不追蹤使用者，也不需要帳號。我們不使用 Cookie，字幕只是經過伺服器轉送給翻譯引擎，不會被保存。我們希望這裡一直是個乾淨的、用愛驅動的公共服務。

不必只聽我們說。原始碼完全公開，網站由 GitHub Actions 直接部署，任何人都可以去核對我們說的是不是真的。詳見[隱私權政策](../privacy/zh-Hant.md)。

## 需要說明的幾件事

本專案由社群貢獻者在業餘時間維護。我們會盡力維持服務穩定，但畢竟是純粹的非營利投入，無法承諾 100% 不出狀況。日常維護、上游供應商調整，或是維護者精力不濟，都可能讓服務短暫中斷，還請多多包涵。詳情請見[服務條款](../terms/zh-Hant.md)。

最後要說清楚：這個工具取代不了人工精譯的「信達雅」。它的目標很單純，就是讓每個人都能用上盡可能高品質的字幕翻譯：在絕大多數情況下，幾十秒內拿到一份結構完整、盡量準確、拿來就能用的字幕。機器翻譯難免出錯，複雜的 ASS 特效排版也可能需要手動調整，分享之前請先把成品看過一遍。
