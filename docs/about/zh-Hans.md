# 关于蒙太奇字幕翻译器

蒙太奇字幕翻译器是蒙太奇字幕社区（MontageSubs）做的免费开源字幕翻译工具，支持 SRT、VTT、ASS 字幕在 200 多种语言之间互译，还能直接读取 MKV 视频里的字幕。不用注册，没有广告，也不追踪你。

## 我们是谁

蒙太奇字幕社区是一群影视爱好者和开发者的聚集地。我们不光爱看片，更痴迷做字幕：措辞推敲得够不够，时间轴准不准，字幕在画面上好不好看，都是我们会较真的事。

社区下设蒙太奇字幕组，至今坚持纯手工打磨，对质量有一种近乎偏执的追求。可死磕的代价就是慢，一部片子动辄几周。

于是不少好作品因为人力不够，只能无奈跳过。观众要么干等，要么忍着看毫无灵魂的机翻，这两种我们都不喜欢。我们不希望好作品因为语言壁垒被遗忘。

## 为什么做这个工具

所以我们想给大家一个折中的办法：一套快速、简单的自助翻译，不用折腾复杂的配置，也不会撞上付费墙。

它最早只是我们自己用的几个脚本，在手工翻译的同时先出一版参考稿。因为出身于真实的字幕制作，它长出了不少字幕人真正需要的功能，比如直接读取视频里的字幕、清理听障辅助字幕、检查字幕语速。用着顺手，就整理出来，开放给所有人。

今晚就想看懂一部片子的观众，想要一版初稿再慢慢润色的字幕爱好者，或者只是想弄明白画面上在说什么的任何人，它都是为你们准备的。

## 换一种做法

很多翻译工具只是把字幕一行一行丢给引擎，给什么要什么。结果一句话被拦腰截断，上下文荡然无存，译文生硬、前后不一，甚至词不达意。

我们换了个思路：不再发送碎片，而是把相关的字幕合并成完整、自然的句子，再按场景成段交给引擎，让它像观众一样顺着对话往下读。

真正棘手的是回程：把翻好的句子重新精准地放回原来的时间轴。我们在这上面花了很长时间，尤其是中日韩这种词与词之间没有明显边界的语言，就是为了让各种语言对之间，时间和结构都不走样。

## 你能用到什么

- **场景级翻译。** 引擎读到的是整场戏，不是孤零零的一行行，滑块可以调场景切得多细。
- **术语表说了算。** 你定的人名和术语会被强制落实到译文里，引擎本身不支持术语表也一样。
- **本机识别人名。** 英译中、日译中这类人名写法会变的语言对，浏览器里的小模型会先把人名找出来，帮你建好术语表，全片译名统一。
- **回得去，也修得好。** 译文按标点对齐拆回原来的字幕条目，引擎中途弄坏的地方会被自动检出并修复。
- **懂字幕的功能。** 能直接从 MKV 里读出字幕，可以选择去掉 SDH 听障标注，歌词原样保留，还支持双语输出和 ASS 样式。
- **下载前先检查。** 内置编辑器和对照视图，漏译、残留原文、单行过长、语速过快的字幕都会标出来。
- **数据留在你手里。** 历史记录和下载的模型都存在浏览器里，界面也有多种语言可选。

想了解这些是怎么配合的，可以看[翻译引擎与模型支持](../model-access/zh-Hans.md)。

## 免费，也想一直免费

目前支持 200 多种语言互译。不过支持得多，不等于每个语言对都完美，部分特殊场景还没优化到位。我们会靠大家的使用和反馈，一点点把各个语言磨得更好。

很多人问，为什么不用大模型（LLM）。LLM 翻得确实更强，这一点不必回避。但一个字幕文件平均约 1,500 行，每个人都走 LLM，对一个免费的社区服务来说成本高得离谱，换来的质量提升却未必对得上这笔账。

所以我们把力气花在了 NMT（神经机器翻译）上。现在的 NMT 引擎已经吸收了 LLM 的不少长处，响应快、成本低，可它们终究是逐行翻译，看不到整场戏。剩下的功夫我们自己补：场景级的上下文、引擎没法无视的术语表、本机识别人名、把译文放回原时间轴，还有会自己修复错误的流程。项目里大部分代码就花在这上面，这也是我们能比直接调用翻译引擎多榨出一截质量的原因。等 LLM 的成本降下来，我们很乐意接入；如果你能提供 API 额度或其他资源，欢迎看看[如何贡献](../contribute/zh-Hans.md)。

## 隐私与透明

我们坚持非营利，不接广告，不追踪用户，也不需要账号。我们不用 cookie，字幕只是经过服务器转发给翻译引擎，不会被保存。我们希望这里一直是个干净的、用爱驱动的公共服务。

不必只听我们说。源代码完全公开，网站由 GitHub Actions 直接部署，谁都可以去核对我们说的是不是真的。详见[隐私政策](../privacy/zh-Hans.md)。

## 需要说明的几点

本项目由社区贡献者在业余时间维护。我们会尽力保持服务稳定，但毕竟是纯粹的非营利投入，没办法承诺 100% 不出故障。日常维护、上游供应商调整，或者维护者精力不济，都可能让服务短暂中断，还请多包涵。具体见[服务条款](../terms/zh-Hans.md)。

最后要说清楚：这个工具替代不了人工精译的“信达雅”。它的目标很简单，就是让每个人都能用上尽可能高质量的字幕翻译：在绝大多数场景下，几十秒内拿到一份结构完整、尽量准确、拿来就能用的字幕。机器翻译难免出错，复杂的 ASS 特效排版也可能需要手动调整，分享之前请先过一遍成品。
