# 关于蒙太奇字幕翻译器

蒙太奇字幕翻译器是蒙太奇字幕社区（MontageSubs）做的一个免费开源的字幕翻译工具，支持 SRT、VTT、ASS，可以在 200 多种语言之间互译。不用注册，没有广告，也不追踪你。

## 我们是谁

蒙太奇字幕社区里有影视爱好者、字幕组成员，也有开发者。核心的字幕组坚持纯手工制作，对措辞、时间轴和特效排版都很挑剔。

手工活儿就是慢，一部片子动辄几周，不少想做的作品只能放下。观众要么干等，要么忍着看生硬的机翻。

## 为什么做这个工具

它最早是我们自己用的几个脚本，在手工翻译进行的时候，先出一版参考稿。后来整理成工具，开放给所有人。目标是又快、又能读、格式也规整的初稿。它替代不了字幕组的人工精翻，也没打算替代。

## 它有什么不一样

只靠翻译引擎，做不出像样的字幕。我们的功夫大多花在引擎前后。

- **场景级翻译。** 不逐行发给引擎，而是先把字幕合并成完整的句子，再按场景成段翻译，引擎读到的是一段连贯的对白。
- **术语表说了算。** 你定的人名和术语会被强制落实到译文里，引擎本身不支持术语表也一样。
- **本机识别人名。** 英译中、日译中这类人名写法会变的语言对，浏览器里的小模型会先把人名找出来，帮你建好术语表，全片译名统一。
- **译文回到原时间轴。** 译好的长句再拆回原来的字幕条目，中日韩这种词与词之间没有空格的语言也一样。
- **懂字幕的功能。** 能直接从 MKV 里读出字幕，可以选择去掉 SDH 听障标注，歌词原样保留，还支持双语输出和 ASS 样式。
- **下载前先检查。** 内置编辑器和对照视图，漏译、残留原文、单行过长、语速过快的字幕都会标出来。

想了解这些是怎么配合的，可以看[翻译引擎与模型支持](../model-access/zh-Hans.md)。

## 免费，也想一直免费

目前支持 200 多种语言。不同语言对的质量有高有低，我们会根据大家的反馈继续打磨。

常有人问，为什么不用大模型（LLM）。LLM 翻得确实更好，但一个字幕文件平均约 1,500 行，每个人都走 LLM，对一个免费的社区服务来说成本太高，质量提升却未必成比例。所以我们选了 NMT（神经机器翻译），再用场景级处理把它的效果尽量榨足。等 LLM 的成本降下来，我们很乐意接入。如果你能提供 API 额度或其他资源，欢迎看看[如何贡献](../contribute/zh-Hans.md)。

## 隐私

不用账号，没有广告，不做用户画像，也不用 cookie。字幕只是经过服务器转给翻译引擎，不会被保存。更详细的说明见[隐私政策](../privacy/zh-Hans.md)。

## 需要说明的几点

服务由社区志愿者利用业余时间维护。我们会尽力保持稳定，但没法承诺 100% 不中断，具体见[服务条款](../terms/zh-Hans.md)。

机器翻译难免出错，复杂的 ASS 特效排版也可能需要手动调整。分享之前，请先过一遍成品。
