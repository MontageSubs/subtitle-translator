# 关于蒙太奇字幕翻译器

蒙太奇字幕翻译器是由蒙太奇字幕社区（MontageSubs）开发、维护的开源免费字幕翻译工具，支持 SRT、VTT、ASS 字幕在 200 多种语言之间互译，也可以直接读取 MKV 视频中的字幕。使用无需注册，没有广告，也不追踪用户。

## 我们是谁

蒙太奇字幕社区是一个由影视爱好者、字幕制作者和开发者组成的非营利社区。我们在意字幕的每一处细节：译文质量、时间轴的准确，以及专业的排版。

社区下设蒙太奇字幕组，坚持纯手工制作字幕。这样的工作细致而缓慢，一部作品往往需要数周才能完成，不少作品因人力有限只能放弃。观众要么等待，要么只能接受质量不佳的机器翻译。

## 为什么开发字幕翻译器

我们希望在这两者之间提供另一种选择：一个快速、简单的工具，让每个人都能获得可读、结构规范的译文，不需要复杂的配置，也不必跨过付费门槛。

这个工具最初只是我们内部使用的脚本，用来在手工翻译的同时生成参考初稿。由于来自真实的字幕制作，它包含了字幕制作者需要的功能，比如读取视频中的字幕、处理听障辅助字幕、检查字幕语速。后来我们对它加以完善，向所有人开放。

## 字幕翻译是如何实现的

多数翻译工具会把字幕逐行交给翻译引擎。这样做会丢失上下文，跨越多条字幕的句子被拆成片段翻译，译文因此容易出现语气不自然、术语不一致、措辞不当等问题。

我们的做法是，先把相关的字幕合并成完整的句子，再按场景分组，把每个场景作为一段连续文本交给翻译引擎，时间轴和样式不会进入请求。这样引擎就能结合整段对话来理解语境。

更困难的是还原：把译好的句子重新拆分，放回原来每条字幕及其时间轴中。对于中文、日文这类没有明显词边界的语言，这项工作尤其复杂。我们为此投入了大量开发精力，力求各种语言对之间的时间轴与结构依然完整。

## 面向字幕制作的功能

- **场景级翻译。** 引擎接收的是整个场景，而不是孤立的单行。可以通过滑块调节场景的划分粒度，以适应不同类型的影视内容。
- **强制术语表。** 你设定的人名和术语会在全片中保持一致，即使引擎本身不支持术语表也同样生效。
- **本机人名识别。** 对于人名写法会变化的语言对，例如英文译中文，浏览器中运行的小型模型会识别人名并生成术语表，供你确认。
- **时间轴还原与自动修复。** 译文会对齐回原字幕条目，引擎产生的缺失、损坏等错误会被自动检测并修正。
- **字幕专用工具。** 可直接读取 MKV 视频中的字幕，去除 SDH 标注，保留歌词原文，并支持导出双语字幕和带样式的 ASS 文件。
- **内置校对。** 带对照视图的编辑器会标出漏译、残留原文、过长的行和过快的语速。
- **本地数据。** 翻译历史和下载的模型都保存在浏览器中，界面也提供多种语言。

关于这些功能背后的技术，请参阅[翻译引擎与模型支持](../model-access/zh-Hans.md)。

## 语言支持与选择 NMT 的原因

目前工具支持 200 多种语言。覆盖广并不意味着每个语言对的质量都一样，部分场景仍有待改进，我们会根据社区的反馈持续优化。

常有人问我们为什么不使用大语言模型（LLM）。LLM 的整体翻译质量更好，这一点我们不回避。但一个字幕文件平均约 1,500 行，为每位用户处理这样的量，对一项免费的社区服务而言成本过高，而质量上的提升并不足以抵消这笔开销。

因此我们选择了神经网络机器翻译（NMT），并在它周围投入了大量工作。当前的 NMT 引擎已经吸收了 LLM 的不少优势，但依然是逐行翻译，看不到整个场景。场景级上下文、强制术语表、人名识别、时间轴还原与自动修复，都是我们自己实现的，也构成了本项目的大部分代码。它们让我们能从同一个引擎中得到比直接请求更好的结果。如果 LLM 的成本大幅下降，我们很乐意接入；如果你能提供 API 额度或其他资源，也非常欢迎，详见[如何贡献](../contribute/zh-Hans.md)。

## 隐私与透明

使用本工具无需账号，没有广告，不做用户画像，也不追踪用户，我们不使用 cookie。字幕仅经过服务器转发给翻译引擎，不会被保存。

项目源代码完全公开，网站由 GitHub Actions 直接部署，任何人都可以核实它的工作方式。详见[隐私政策](../privacy/zh-Hans.md)。

## 局限与服务可用性

本项目由社区贡献者利用业余时间维护。我们会尽力保持服务稳定，但作为非营利投入，无法保证不间断运行。日常维护、上游供应商的调整，或维护者精力有限，都可能造成服务短暂中断，敬请谅解。详见[服务条款](../terms/zh-Hans.md)。

需要明确的是，这个工具无法替代人工精译的“信达雅”。它的目标很简单：让每个人都能用上尽可能高质量的字幕翻译，在绝大多数场景下，几十秒内获得一份结构完整、尽量准确且可用的字幕。机器翻译仍可能出错，复杂的 ASS 特效排版也可能需要手动调整，发布前请自行检查。
