# 关于蒙太奇字幕翻译器

这是一个由 **蒙太奇字幕社区 (MontageSubs)** 开发并维护的 [开源项目](https://github.com/MontageSubs/subtitle-translator)。

## 我们是谁
**蒙太奇字幕社区** 是一群影视爱好者和开发者的聚集地。我们不仅热爱看片，更痴迷于制作字幕。作为极其“挑剔”的观众，我们对翻译质量和特效细节有一种近乎偏执的追求。

社区下设有蒙太奇字幕组，主打纯手工打磨。但这种“死磕”质量的方式导致产出极慢，很多作品得花好几周才能出炉，这就意味着大量优秀的作品因为人力不足而被我们无奈跳过。我们不希望好作品因为语言壁垒被遗忘，但同样不希望大家只能忍受那种毫无灵魂的劣质机翻。

## 为什么做这个工具
这就是我们开发这个工具的初衷，旨在给所有爱好者提供一套快速、简单的自翻译方案。当你不想在复杂的配置和各种付费墙前浪费时间，或者急需一份结构专业、准确度尚可的译本来“救急”时，它可以帮你快速填补空白。

## 技术实现
很多翻译工具只是机械地把字幕逐行交给引擎，结果译文往往断章取义，缺乏上下文，甚至会出现词不达意或时间轴错乱的情况。

为了解决这个问题，我们尝试了一套不同的逻辑。我们不再发送碎片化的单行字幕，而是将整个场景的内容进行重组，把被拆分的句子合并成完整的自然语言文本，并加上标记发送给翻译引擎。这样引擎能“感知”到场景的连贯性，翻译出来的语气会自然很多。

最棘手的是所谓的“还原”过程，也就是要将翻译后的句子重新精准地分发回原有的时间轴片段中。尤其是在中日韩这种没有明显词边界的语言里，我们编写了大量代码来实现语义切分，尽可能保证翻译后的字幕结构依然专业。

## 语言支持与局限
目前工具支持 **200 多种语言** 互译。但得说实话，支持得多并不意味着每种语言都完美，部分特殊场景可能还没优化到位。作为一个开源项目，我们希望在更多人的使用和贡献下，逐步把各种语种的适用性磨得更好。

很多人问为什么不用现在流行的 AI (LLM)。不可否认，AI 翻译确实比我们采用的 NMT（神经机器翻译）方案要强，但投入产出比并不理想。一个字幕文件平均 1,500 行，如果全部走 AI，每天处理这种量级的成本会高得离谱，而实际质量的提升可能不到 10%。

为了让每个人都能免费使用，我们选择了性价比更高的 NMT 方案。目前的神经机器翻译引擎已经吸收了很多 LLM 的优势，在保证响应速度和低成本的同时，极大地缓解了传统机翻的生硬感。此外，我们通过对自然语言的重新组织和场景级翻译，尽可能压榨 NMT 的翻译质量极限。在 AI 成本大幅下降之前，这可能是目前最可持续的方案。当然，如果是有能力的朋友愿意提供 AI 支持，我们非常欢迎。

## 如何贡献
这是一个纯粹的社区项目，我们欢迎任何形式的参与。

无论你是能贡献代码、报告 bug、提供新点子，还是愿意参与社区任务、翻译界面、提供 API 配额，甚至只是帮我们推广和反馈，每一份帮助都会让这个工具变得更好。[[了解如何贡献]](../contribute/zh-Hans.md)

## 纯净与隐私
我们坚持非营利模式，不接入商业广告，不追踪用户，也不需要建立账号。

在设计之初，隐私就是我们的优先级。我们不记录翻译内容，字幕仅在经过服务器转发给翻译引擎。我们通过禁用 cookie、不追踪用户等手段，尽可能抹除个人可识别信息，确保这里是一个纯粹的、用爱驱动的开源公共服务。[[详见隐私政策]](../privacy/zh-Hans.md)

## 几句真心话
本项目由社区贡献者在业余时间维护。我们会尽力维持服务的稳定性，但因为是纯粹的非营利贡献，没办法承诺 100% 无故障。如果遇到日常维护、上游供应商调整或维护者精力波动，服务可能会出现短暂中断，还请见谅。[[参见服务条款]](../terms/zh-Hans.md)

最后要明确的是，这个工具无法替代人工精译的“信达雅”。它的目标很简单，就是在绝大多数场景下，让你在几十秒内获得一份结构完整、尽量准确且可用的字幕。
