# 無法連線到服務？可能是 DNS 過濾規則的影響

蒙太奇字幕翻譯器的後端運行在 Cloudflare Workers 上。我們使用免費的二級網域 `sub.qzz.io` 作為服務入口，並在這個網域上設定防火牆規則，保護服務不被濫用。選擇免費網域，是因為我們希望把開支降到最低，讓這個公益專案盡可能長久地運行下去。

不過，一些 DNS 過濾器（例如 AdGuard、Pi-hole 訂閱的 “HaGeZi's Badware Hoster Blocklist” 等規則）會把 `qzz.io` 整體視為風險網域。這是可以理解的：任何人都可以註冊這個網域下的二級網域，其中確實可能有人託管惡意內容。我們不會託管這類內容，原始碼也是公開的，歡迎任何人查驗。

## 如果你被引導到了這裡

這很可能表示你的 DNS 攔截了 `sub.qzz.io`，也就是我們為你提供服務所使用的網域。如果方便，請把 `sub.qzz.io` 加入白名單。你不需要放行整個 `qzz.io`：我們不會使用其他人的二級網域，也無法為他人託管的內容做擔保。

## 如果你沒有使用 DNS 過濾器

也可能是網路服務商或連線中的其他環節攔截了它。歡迎透過頁面底部的連結加入我們的社群，告訴我們你遇到的情況。社群裡的朋友很樂意一起協助排查，你的回報也能幫助我們了解問題的影響範圍。

造成不便，我們深表歉意，感謝你的理解。
