# 无法连接服务？可能是 DNS 过滤规则的影响

蒙太奇字幕翻译器的后端运行在 Cloudflare Workers 上。我们使用免费的二级域名 `sub.qzz.io` 作为服务入口，并在这个域名上配置防火墙规则，保护服务不被滥用。选择免费域名，是因为我们希望把开支降到最低，让这个公益项目尽可能长久地运行下去。

不过，一些 DNS 过滤器（例如 AdGuard、Pi-hole 订阅的 “HaGeZi's Badware Hoster Blocklist” 等规则）会把 `qzz.io` 整体视为风险域名。这可以理解：任何人都可以注册这个域名下的二级域名，其中确实可能有人托管恶意内容。我们不会托管这类内容，源代码也是公开的，欢迎任何人查验。

## 如果你被引导到了这里

这很可能意味着你的 DNS 拦截了 `sub.qzz.io`，也就是我们为你提供服务所使用的域名。如果方便，请把 `sub.qzz.io` 加入白名单。你不需要放行整个 `qzz.io`：我们不会使用其他人的二级域名，也无法为他人托管的内容做担保。

## 如果你没有使用 DNS 过滤器

也可能是网络服务商或连接中的其他环节拦截了它。欢迎通过页面底部的链接加入我们的社群，告诉我们你遇到的情况。社群里的朋友很乐意一起帮你排查，你的反馈也能帮助我们了解问题的影响范围。

给你带来不便，我们深表歉意，感谢你的理解。
