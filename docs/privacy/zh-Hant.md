# 隱私權政策

本隱私權政策適用於 **蒙太奇字幕翻譯器**，不適用於蒙太奇字幕社群（MontageSubs）的其他服務或整體社群。不過，我們秉持相同的核心原則：**隱私優先、資訊公開透明**。

## 我們如何看待隱私

我們是一個以熱情與社群貢獻為動力的開源字幕社群。本翻譯工具由社群成員利用業餘時間，投入技術、時間與資源共同維護，希望為所有熱愛字幕的人提供實用的翻譯服務。

從設計之初，我們就將隱私保護列為首要考量：**不要求使用者註冊帳號、不建立使用者輪廓，也不留存字幕內容**。我們希望在提供高品質翻譯服務的同時，盡可能降低對使用者隱私的影響。

## 我們如何處理你的資料

### 1. 一般情況：只處理翻譯所需的資料

我們致力於為所有使用者提供最高標準的隱私保護。**除非異常活動觸發下述自動防護機制，並因此被系統標記，否則我們的資料庫不會留下任何可與你連結的紀錄。**

具體而言：

- **無須註冊或登入**：使用本服務不需要建立帳號，也不必登入。我們不會蒐集你的電子郵件地址、姓名或其他類似資料。
- **不建立使用者輪廓**：我們是非營利組織，沒有透過建立使用者輪廓或分析使用行為來獲利的動機。
- **不刊登商業廣告**：商業廣告可能帶來隱私風險，因此我們不導入任何形式的商業廣告，從源頭避免廣告追蹤所造成的隱私疑慮。
- **不使用 Cookie**：Cookie 是儲存在瀏覽器中的小型資料，常用於維持登入狀態或追蹤使用者在不同網站上的活動。本服務不依賴 Cookie；由於我們不要求使用者登入、不建立使用者輪廓，也不刊登廣告，因此無須使用 Cookie。
- **不留存字幕內容**：你提交的字幕會經由我們的伺服器轉送給上游服務供應商，**不會寫入我們的資料庫**。翻譯完成後，結果就會傳回給你。我們只會統計當天完成的翻譯次數，不會記錄實際翻譯的內容。
- **翻譯紀錄由你自行管理**：你的翻譯紀錄只會儲存在瀏覽器的本機儲存空間，使用的技術包括 IndexedDB 和 localStorage。這些紀錄不會同步至雲端或我們的伺服器，你也可以隨時自行清除。

**在上述原則下，只有少量必要資料會經過我們的伺服器：**
- **你提交翻譯的字幕**：字幕會經由我們的伺服器轉送給上游服務供應商，處理完成後再傳回給你；我們不會留存字幕內容。
- **瀏覽器類型（User-Agent）**：這項資訊可能會轉送給翻譯服務供應商，以協助維持服務正常運作。
- **防濫用識別碼**：只有在系統偵測到異常請求時，才會將此識別碼存入資料庫，以協助維持服務正常運作。相關機制詳見下文。

### 2. 自動防護機制如何維持服務正常運作

為了讓這項服務能持續免費提供給所有字幕愛好者，我們必須防止服務遭到惡意濫用。

許多服務會直接利用 IP 位址識別使用者，並據此限制存取。我們認為，這種做法本身就可能帶來隱私風險，因此不採用這種方式。

我們不會在資料庫中以明文形式儲存 IP 位址，而是將 IP 位址與一段字串共同運算，產生一組**防濫用識別碼**。這組識別碼很難反向推算出原始 IP 位址；即使資料庫外洩，也很難從中還原出你的真實 IP 位址。

為了盡可能降低對隱私的影響，我們設計了一套依特定條件啟動的防護流程。當你發起翻譯請求時，瀏覽器會先在本機執行一次簡單的數學驗證。**如果驗證通過，我們的資料庫就不會儲存任何防濫用識別碼，也不會留下任何可與你連結的紀錄。** 只有在系統偵測到請求頻率異常，或初步驗證遭到疑似惡意的反覆呼叫時，才會啟用由 Cloudflare Turnstile 提供的人機驗證。

**只有在啟用人機驗證，或請求被判定為異常時，系統才會將防濫用識別碼存入資料庫**，以便執行必要的請求頻率限制或自動封鎖。這組識別碼不會公開，並會由系統自動刪除；最遲會在與該識別碼相關的最後一次異常活動發生後 40 天內清除。

**簡單來說，只要你的使用行為未被判定為惡意濫用，我們的資料庫就不會儲存你的存取紀錄。**

### 3. 技術日誌的記錄方式

本工具由兩個彼此獨立的 Cloudflare Worker 組成，兩者採用不同的日誌記錄方式：

- **翻譯服務**：預設不記錄詳細的請求日誌。只有在排查系統錯誤，或處理無法透過其他方式防範的惡意濫用行為時，我們才會暫時啟用觀測日誌功能。啟用期間，日誌可能包含 IP 位址、瀏覽器資訊等技術中繼資料。這些日誌僅限獲授權的維護者存取，不會對外揭露，並會在問題排除後立即停止記錄。
- **狀態服務**：此服務僅供內部產生狀態資料，再將資料同步至靜態頁面。由於這不是公開功能，訪客無法直接與其互動，因此相關日誌會持續啟用，僅用於監控針對管理端點的異常探測行為，不會記錄任何訪客資訊。

## 第三方如何處理你的資料

本工具使用下列平台提供服務。各平台都有自己的日誌記錄方式與隱私權政策。由於這些平台的基礎設施分布於全球各地，資料可能會傳輸至美國、英國、歐盟等地區。

### 1. 基礎設施平台

- **GitHub**：負責託管網頁及部署程式碼。[隱私權政策（英文）](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- **Cloudflare**：負責執行翻譯中繼服務，並提供請求頻率限制、部分 CDN 服務、狀態資訊及人機驗證。此外，Cloudflare 也會透過 D1 資料庫儲存防濫用識別碼，但僅限於異常存取的情況；這些識別碼不會傳送給其他平台。[隱私權政策（繁體中文）](https://www.cloudflare.com/zh-tw/privacypolicy/)
- **Turso**：只儲存翻譯次數及錯誤類型的統計數據，不包含任何個人資訊。

### 2. 翻譯服務供應商

本工具採用中繼架構：你的字幕會先傳送至我們的伺服器，再由伺服器轉送給翻譯服務供應商。供應商收到的是來自我們伺服器的請求，因此不會直接看到你的 IP 位址。

我們會將字幕內容、目標語言、術語表及背景說明原樣轉送給下列供應商：

- **相關服務及其隱私權政策**：[Google（繁體中文）](https://policies.google.com/privacy?hl=zh-TW)、[DeepL（英文）](https://www.deepl.com/en/privacy)、[Microsoft（繁體中文）](https://www.microsoft.com/zh-tw/privacy/privacystatement)。
- **重要風險提醒**：字幕交由供應商處理後，相關資料的處理方式便由該供應商自己的政策規範。部分供應商可能會將提交的資料用於模型訓練或改善服務。**請勿提交含有敏感個人資訊、商業機密或高度私密內容的字幕**，因為資料一旦提交，其後續處理方式便不再由我們掌控。

## 使用者權利與相關規定

- **資料查詢與刪除**：由於我們不建立使用者帳號，因此不會建立個人檔案。如果你認為自己的存取行為遭到誤判，被系統標記為異常並產生「防濫用識別碼」，可以透過下方的聯絡管道提供你的 IP 位址，我們會立即刪除該識別碼。
- **本機資料管理**：你可以隨時透過瀏覽器設定，或工具內的歷史紀錄頁面，刪除儲存在本機的翻譯紀錄。
- **未成年人保護**：本服務並非以未滿 13 歲的兒童為對象；若適用法律規定的年齡門檻較高，則以該較高年齡為準。如果家長或監護人發現兒童曾提交個人資訊，請儘速透過下方的聯絡管道與我們聯繫。
- **關於追蹤訊號**：我們一向對所有使用者採取最高標準的隱私保護措施，因此，「請勿追蹤」（Do Not Track，DNT）及「全球隱私控制」（Global Privacy Control，GPC）訊號不會改變本服務的運作方式，因為我們本來就不會追蹤使用者。

## 資訊公開與透明

我們相信，信任應該建立在可供查證的事實上，而不只是口頭承諾。

因此，本工具的[原始碼](https://github.com/MontageSubs/subtitle-translator)完全公開，並透過 GitHub Actions 直接部署。你可以自行檢視程式碼，確認我們的隱私設計是否符合這份政策所述的原則。

本專案規模不大，由志願者利用業餘時間共同維護。我們優先透過社群平台直接溝通，一方面可以減少垃圾郵件的干擾，另一方面也能讓問題更有效率地轉交給適合處理的貢獻者。
