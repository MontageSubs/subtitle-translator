# 隐私政策

本隐私政策适用于 **蒙太奇字幕翻译器**。它并非蒙太奇字幕社区（MontageSubs）的整体隐私政策，但我们遵循相同的核心理念：**隐私优先、公开透明**。

## 本工具的隐私哲学

我们是一个用爱发电的开源字幕社区，本翻译工具由社区贡献者投入时间、技术与资源维护，旨在服务于热爱字幕的每一个人。

我们将“隐私优先”作为设计的首要前提：**不建立账号、不刻画用户画像、不留存字幕内容**。我们的目标是在提供高质量翻译服务的同时，最大限度保护你的隐私。

## 我们如何处理你的数据

### 1. 默认状态：只经手翻译所必需的信息

我们致力于为所有用户提供最高标准的隐私保护。**除触发异常而被自动防护机制标记外，我们的数据库中不会留下任何与你关联的记录。**

具体实践如下：

- **无需注册/登录**：服务完全免登录、无需注册，我们不收集你的电子邮箱、姓名等信息。
- **无用户画像**：我们是非营利组织，没有动力通过刻画用户画像或分析行为数据来牟利。
- **无商业广告**：任何形式的商业广告都会带来隐私风险。我们不接入任何形式的商业广告，从根源上杜绝由广告追踪带来的隐私风险。
- **不使用 Cookie**：Cookie 是保存在浏览器里的一小段持久数据，常用于维持登录状态或进行跨站追踪。我们的翻译服务不依赖 Cookie，因为免登录、无画像、无广告的承诺，已经让它变得没有必要。
- **字幕不留存**：字幕经过我们的服务器转发给上游服务提供商，**从不写入数据库**，处理完就还给你。我们只知道今天完成了多少次翻译，但不知道翻译了什么。
- **你掌握字幕的历史**：翻译历史仅保存在你浏览器的本地存储中（基于 IndexedDB 和 localStorage 技术），且不会同步至云端或我们的服务器。你也可以随时清除这些记录。

**在上述承诺之下，只有极少数必要信息会经过服务器：**
- **你翻译的字幕本身**：但我们不留存。它经服务器转发给上游服务提供商，处理完成后即返还给你。
- **浏览器类型 (User-Agent)**：可能会被转发到翻译服务提供商，用于保障服务可用性。
- **防御性标识**：仅在系统检测到异常请求时才会被保存到数据库，用于保障服务可用性（详见下文）。

### 2. 保持服务可用的自动防护

为了让这项服务能持续免费提供给所有热爱字幕的朋友，我们需要防止它被恶意滥用。

多数服务会直接用 IP 地址识别和限制用户，我们认为这本身就是一种隐私风险，所以没有这样做。我们的数据库里不存储明文 IP 地址本身，取而代之的是一个由 IP 地址与一个字符串共同计算出的**防滥用编号**。该编号很难被反推回原始 IP，即便数据库泄露，也很难有人从中还原出你的真实地址。

为了将隐私影响降到最低，我们建立了一套触发式防护流程：当你发起翻译请求时，浏览器会先在本地完成一次轻量级的数学校验。**如果校验通过，我们的数据库不会存储任何防滥用编号或者留下任何与你关联的记录。** 只有当系统检测到请求频率异常，或初步校验被频繁恶意调用时，才会触发由 Cloudflare Turnstile 提供的人机验证。

**只有在触发人机验证或被判定为异常请求时，系统才会将防滥用编号记录在数据库中**，用于执行必要的限速或自动封禁。该编号从不公开，并会自动删除，最迟在最后一次异常活动 40 天后清除。

**简单来说：只要你的行为不被判定为恶意滥用，你的访问记录不会存储在我们的数据库中。**

### 3. 技术日志的使用状态

本工具由两个独立的 Cloudflare Worker 构成，其日志策略如下：

- **翻译服务**：默认不记录详细请求日志。仅在排查系统错误或应对无法预防的恶意滥用时，我们会临时开启观测日志（期间可能包含 IP 地址、浏览器信息等技术元数据）。相关日志仅限授权维护者访问且不对外披露，在问题解决后将立即关闭。
- **状态服务**：该服务仅用于内部生成状态数据并同步至静态页面。作为非公开功能，访客无法与其直接交互，因此其日志常年开启仅用于监控针对管理端的异常探测行为，不会记录任何访客信息。

## 第三方如何处理你的数据

这个工具运行在下列平台上，它们各自有自己的日志和政策。请注意，这些平台遍布全球，数据可能被传输至美国、英国、欧盟等地。

### 1. 基础设施平台

- **GitHub**：托管网页、部署代码。[隐私政策](https://docs.github.com/zh/site-policy/privacy-policies/github-general-privacy-statement)
- **Cloudflare**：运行翻译中继，提供限流、部分 CDN、状态信息与人机验证，并通过 D1 数据库保存（仅针对异常访问的）防滥用编号（该编号不会传递给其他平台）。[隐私政策](https://www.cloudflare.com/zh-cn/privacypolicy/)
- **Turso**：只保存翻译次数和错误类型的计数，不含任何个人信息。

### 2. 翻译服务提供商

我们采用中继架构：你的字幕由我们的服务器转发给服务提供商，他们只看到我们服务器的请求，看不到你的 IP 地址。我们将字幕、目标语言、术语表及背景说明原样转发至以下提供商：

- **支持服务及隐私政策**：[Google](https://policies.google.com/privacy?hl=zh-CN)、[DeepL](https://www.deepl.com/zh/privacy)、[Microsoft](https://www.microsoft.com/zh-cn/privacy/privacystatement)。
- **重要风险提示**：字幕内容交给提供商后，其处理方式由该服务提供商的政策决定。部分服务提供商可能会将数据用于模型训练或服务改进。**请勿提交包含敏感个人信息、商业机密或高度私密的字幕内容**，因为一旦提交，该数据将超出我们的控制范围。

## 用户权利与法律合规

- **访问与删除权**：由于我们不建立用户账户，因此不存在个人档案。如果你认为自己的访问被误判为异常并生成了“防滥用编号”，可通过下述联系方式提供你的 IP 地址，我们将立即予以删除。
- **本地数据控制**：你可以通过浏览器设置或工具内的历史页面，随时删除本地存储的翻译记录。
- **未成年人保护**：本服务不面向 13 岁以下儿童（或当地法定更高年龄）。若监护人发现孩子提交了个人信息，请及时通过下方渠道联系我们。
- **关于追踪信号**：由于我们始终对所有用户采取最高隐私标准，因此“请勿追踪”（Do Not Track）或全球隐私控制（GPC）信号不会改变服务方式，因为我们本身就不追踪。

## 透明度

信任应当可以被验证，而非只是承诺：我们主张透明度，因此本工具的[源代码](https://github.com/MontageSubs/subtitle-translator)完全公开，并由 GitHub Actions 直接部署。你可以通过代码自行验证我们的隐私设计，确保我们的承诺真实可靠。

## 联系方式

- **问题反馈**：请提交 [GitHub 议题（Issue）](https://github.com/MontageSubs/subtitle-translator/issues)。
- **隐私联系**：一般性问题请提交 GitHub 议题；涉及你的 IP 地址等敏感信息，请在社群平台私信管理员，这代表你同意我们使用该信息来处理你的请求（例如删除对应编号）。

社群平台：[GitHub 讨论区](https://github.com/MontageSubs/subtitle-translator/discussions)、Telegram、Discord、IRC（Libera Chat）、Matrix。

**为什么没有公开邮箱？**
作为一个由志愿者维护的小型开源项目，我们优先采用社群内直接沟通的方式，这样既能避开垃圾邮件干扰，也能让问题被高效分流给合适的贡献者。如果未来设立组织邮箱，会在此更新。
