# 加入社区

蒙太奇字幕翻译器是一群热爱字幕、翻译和影视的朋友在公开协作中完成的项目。无论你想提问、分享想法，还是只想了解我们在做什么，都欢迎加入。你不需要为项目做出任何贡献，也可以是社区的一员，只是看看大家的讨论同样很好。

## 在哪里找到我们

- [Telegram](https://t.me/+8x4oY25znpQ0NTMx)
- [Discord](https://discord.com/invite/UuQ8tFpMYy)
- [IRC](https://web.libera.chat/#MontageSubs)（Libera.Chat，`#MontageSubs`）
- [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions)
- [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues)

Telegram、Discord 和 IRC 是日常交流的地方，欢迎来打个招呼、提出问题，或者先看看大家在聊什么。GitHub Discussions 适合讨论值得留给后来者参考的问题和想法，GitHub Issues 则用于提交 Bug。如果不确定该在哪里发言，可以直接在聊天群里问，我们会帮你指路。提交 Bug 时需要附上哪些信息，可以参考[关于反馈与建议](../feedback/zh-Hans.md)。

## 联系维护者

项目的核心维护者和社区管理员都在这些地方，欢迎随时联系。想私下沟通的话，请加入上面任意一个聊天群，直接私信即可。

安全问题是例外：请不要在公开渠道发布细节，而是私信维护者，并参考[安全漏洞报告指南](../security/zh-Hans.md)。

## 让这里一直友好

我们希望这里始终友好、有耐心，尤其是对刚加入、还在了解项目的朋友。所有参与者都需要遵守[行为准则](../code-of-conduct/zh-Hans.md)，其中也说明了遇到问题时如何举报。

## 想多做一点？

如果你想更深入地参与，[如何贡献](../contribute/zh-Hans.md)介绍了从代码到翻译的多种参与方式，不要求你是专家。
