# 加入社区

蒙太奇字幕翻译器是一群爱字幕、爱翻译、爱看片的人在公开协作中做出来的，随时欢迎新朋友。想问个问题、提个点子，或者只是好奇我们在折腾什么，都来坐坐。不用非得做点什么才算社区的一员，潜水围观也算。

## 在哪里找到我们

- [Telegram](https://t.me/+8x4oY25znpQ0NTMx)
- [Discord](https://discord.com/invite/UuQ8tFpMYy)
- [IRC](https://web.libera.chat/#MontageSubs)（Libera.Chat，`#MontageSubs`）
- [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions)
- [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues)

Telegram、Discord 和 IRC 是日常聊天的地方，进来打个招呼、随便问点什么，或者先潜水看看都行。GitHub Discussions 适合讨论值得留给后来人看的问题和想法，GitHub Issues 用来提 bug。不确定该发在哪儿，直接在群里问，我们会帮你指路。提 bug 时该附上哪些信息，可以看[关于反馈与建议](../feedback/zh-Hans.md)。

## 联系维护者

项目的核心维护者和社区管理员都在这些地方，有事尽管找。想私下聊，加入上面任意一个聊天群，直接私信就行。

安全问题是个例外：请别在公开渠道贴细节，私信维护者，并参考[安全漏洞报告指南](../security/zh-Hans.md)。

## 让这里一直友好

我们希望这里始终友好、有耐心，尤其对刚来、还在摸索的新朋友。大家都要遵守[行为准则](../code-of-conduct/zh-Hans.md)，里面也写了遇到问题怎么举报。

## 想多做一点？

聊着聊着想上手了？[如何贡献](../contribute/zh-Hans.md)里有很多参与方式，从写代码到翻译都有，不要求你是高手。
