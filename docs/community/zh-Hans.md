# 加入社区

蒙太奇字幕翻译器由一群热爱字幕、翻译和影视的人公开协作、共同维护。无论你想提问、分享想法，还是只想看看大家在做什么，都欢迎加入。你不需要做出任何贡献，也可以成为社区的一员。

## 在哪里找到我们

- [Telegram](https://t.me/+8x4oY25znpQ0NTMx)
- [Discord](https://discord.com/invite/UuQ8tFpMYy)
- [IRC](https://web.libera.chat/#MontageSubs)（Libera.Chat，`#MontageSubs`）
- [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions)
- [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues)

Telegram、Discord 和 IRC 用于日常交流；GitHub Discussions 适合提问和分享想法，方便其他人日后搜索到；GitHub Issues 用于反馈问题。反馈时需要提供哪些信息，请参考[关于反馈与建议](../feedback/zh-Hans.md)。

## 联系维护者

项目核心维护者和社区管理员负责维护这些空间。如需私下联系，请加入上面任意一个聊天群，并向他们发送私信。

涉及安全问题时，请不要公开发布细节，请私信维护者，并参考[安全披露指南](../security/zh-Hans.md)。

## 共同维护友善的社区

我们希望这些空间始终友善、彼此尊重。所有参与者都应遵守我们的[行为准则](../code-of-conduct/zh-Hans.md)，其中也说明了如何举报问题。

## 更多参与方式

如果你不只想聊天，欢迎查看[如何贡献](../contribute/zh-Hans.md)。
