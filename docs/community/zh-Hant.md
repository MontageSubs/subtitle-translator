# 加入社群

蒙太奇字幕翻譯器是一群熱愛字幕、翻譯與影視的人，在公開協作中一起做出來的，隨時歡迎新朋友加入。想問問題、分享想法，或只是好奇我們在忙些什麼，都歡迎來聊聊。不需要做出任何貢獻，也一樣是社群的一份子，在一旁默默看看也很歡迎。

## 在哪裡找到我們

- [Telegram](https://t.me/+8x4oY25znpQ0NTMx)
- [Discord](https://discord.com/invite/UuQ8tFpMYy)
- [IRC](https://web.libera.chat/#MontageSubs)（Libera.Chat，`#MontageSubs`）
- [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions)
- [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues)

Telegram、Discord 與 IRC 是日常聊天的地方，歡迎進來打聲招呼、隨意發問，或先在旁邊看看大家怎麼聊。GitHub Discussions 適合討論值得留給後來者參考的問題與想法，GitHub Issues 則用來回報問題。如果不確定該在哪裡發言，直接在群組裡問就好，我們會幫你指路。回報問題時該附上哪些資訊，請參考[關於問題回報與建議](../feedback/zh-Hant.md)。

## 聯絡維護者

專案的核心維護者與社群管理員都在這些地方，有任何需要都可以找我們。想私下聯絡的話，請加入上述任一聊天群組，直接傳私訊即可。

涉及安全問題時是例外，請不要在公開場合貼出細節，改以私訊聯絡維護者，並參考[安全漏洞回報指南](../security/zh-Hant.md)。

## 讓這裡一直友善

我們希望這裡一直保持友善、有耐心，尤其對剛加入、還在摸索的新朋友。所有參與者都需遵守[行為準則](../code-of-conduct/zh-Hant.md)，裡面也說明了遇到問題該如何通報。

## 想多做一點嗎？

聊著聊著，想動手試試嗎？[如何貢獻](../contribute/zh-Hant.md)裡有許多參與方式，從寫程式到翻譯都有，不需要是高手也沒問題。
