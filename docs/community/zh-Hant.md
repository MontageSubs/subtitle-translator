# 加入社群

蒙太奇字幕翻譯器是一群熱愛字幕、翻譯與影視的朋友，在公開協作中一起完成的專案。無論你想提問、交流想法，或只是想看看我們在做什麼，都歡迎加入。你不需要為專案做出任何貢獻，也一樣是社群的一份子，單純看看大家的討論同樣很好。

## 在哪裡找到我們

- [Telegram](https://t.me/+8x4oY25znpQ0NTMx)
- [Discord](https://discord.com/invite/UuQ8tFpMYy)
- [IRC](https://web.libera.chat/#MontageSubs)（Libera.Chat，`#MontageSubs`）
- [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions)
- [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues)

Telegram、Discord 與 IRC 是日常交流的地方，歡迎來打聲招呼、提出問題，或先看看大家都在聊些什麼。GitHub Discussions 適合討論值得留給後來者參考的問題與想法，GitHub Issues 則用來回報問題。如果不確定該在哪裡發言，直接在聊天群組裡問就可以，我們會幫你指路。回報問題時需要附上哪些資訊，請參考[關於問題回報與建議](../feedback/zh-Hant.md)。

## 聯絡維護者

專案的核心維護者與社群管理員都在這些地方，歡迎隨時聯絡。想私下聯絡的話，請加入上述任一聊天群組，直接傳私訊即可。

涉及安全問題時是例外，請不要在公開場合貼出細節，改以私訊聯絡維護者，並參考[安全漏洞回報指南](../security/zh-Hant.md)。

## 讓這裡一直友善

我們希望這裡一直保持友善、有耐心，尤其是對剛加入、還在摸索的新朋友。所有參與者都需遵守[行為準則](../code-of-conduct/zh-Hant.md)，裡面也說明了遇到問題該如何通報。

## 想多做一點嗎？

如果你想更深入地參與，[如何貢獻](../contribute/zh-Hant.md)介紹了從寫程式到翻譯的多種參與方式，不需要是專家也沒問題。
