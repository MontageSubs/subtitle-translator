# 加入社群

蒙太奇字幕翻譯器由一群熱愛字幕、翻譯與影視的人公開協作、共同維護。無論你想提問、分享想法，或只是想看看大家在做什麼，都歡迎加入。你不需要做出任何貢獻，也能成為社群的一員。

## 在哪裡找到我們

- [Telegram](https://t.me/+8x4oY25znpQ0NTMx)
- [Discord](https://discord.com/invite/UuQ8tFpMYy)
- [IRC](https://web.libera.chat/#MontageSubs)（Libera.Chat，`#MontageSubs`）
- [GitHub Discussions](https://github.com/MontageSubs/subtitle-translator/discussions)
- [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues)

Telegram、Discord 與 IRC 用於日常交流；GitHub Discussions 適合提問與分享想法，方便其他人日後搜尋；GitHub Issues 則用於回報問題。回報時需要提供哪些資訊，請參考[關於問題回報與建議](../feedback/zh-Hant.md)。

## 聯絡維護者

專案核心維護者與社群管理員負責維護這些空間。如需私下聯絡，請加入上述任一聊天群組，並向他們傳送私訊。

涉及安全問題時，請不要公開發布細節，請私訊維護者，並參考[安全漏洞回報指南](../security/zh-Hant.md)。

## 共同維護友善的社群

我們希望這些空間始終友善、彼此尊重。所有參與者都應遵守我們的[行為準則](../code-of-conduct/zh-Hant.md)，其中也說明了如何通報問題。

## 更多參與方式

如果你不只想聊天，歡迎查看[如何貢獻](../contribute/zh-Hant.md)。
