# 無障礙聲明

我們打造蒙太奇字幕翻譯器，是希望更多人都能用自己看得懂的語言欣賞影視作品。如果工具本身有人無法使用，這個心願就無從實現。這份文件會說明我們在無障礙上做了哪些努力、還有哪些地方能做得更好，以及遇到障礙時該如何讓我們知道。

## 我們的態度

我們希望這個工具對每個人都好用，不論你使用什麼裝置上網、以什麼方式操作頁面。這包括使用鍵盤瀏覽、使用螢幕閱讀器、需要放大文字或減少動畫、閱讀由右至左書寫語言的使用者，也包括裝置與網路條件有限的使用者。

整個專案也是同一個出發點：不用註冊、沒有廣告、不收費，不讓金錢或帳號成為一個人與一份字幕之間的門檻。字幕本身就是一種無障礙技術，它幫助聽不到聲音的人，幫助不懂原語言的人，也幫助那些看文字比聽對白更容易跟上劇情的人。

我們把無障礙問題視為需要修正的錯誤，而不是可有可無的功能需求。

## 我們做了什麼

- **鍵盤操作。** 翻譯頁、字幕編輯器（預覽與編輯）與文件都以可純靠鍵盤操作為目標來設計。有焦點指示，對話框開啟時焦點會留在框內，背後的頁面對輔助技術隱藏，關閉後焦點回到原本的位置。
- **跳轉連結。** 每個頁面的第一站都是「跳至主要內容」。
- **語意與 ARIA。** 頁面使用規範的地標與標題。自訂控制項遵循標準模式：語言選擇器是 combobox 加 listbox，選項群組是 radio group，分頁是支援方向鍵、Home、End 的 tab list，進度則是 progress bar。
- **狀態播報。** 不重新整理頁面就發生的變化，例如偵測到的來源語言，或目標語言被自動切換，會透過 live region 播報。
- **編輯器快速鍵。** 在字幕編輯器裡，Ctrl 或 Cmd 加 F 是尋找，加 H 是尋找與取代，加 Z、Y 則是復原與重做。完整列表請見[字幕編輯器使用指南](../subtitle-editor/zh-Hant.md)。
- **全文檢視。** 「原文」「譯文」「對照」三個分頁會完整呈現每一條字幕，螢幕閱讀器可以從頭讀到尾。
- **可選取的一般文字。** 介面裡絕大部分內容都是一般文字，可以輕鬆選取、複製與朗讀。文件與說明類頁面是預先渲染的，沒有 JavaScript 也能閱讀。翻譯功能本身需要 JavaScript，無法使用時會明確提示。
- **介面語言。** 介面提供多種語言，數量還在增加。每個頁面都會設定語言與文字方向，版面採用與方向相關的樣式，阿拉伯文、波斯文、希伯來文、烏爾都文這類由右至左的語言會正確鏡射。
- **動態效果與配色。** 系統要求減少動態效果時，動畫會跟著減少；淺色或深色外觀則跟隨系統設定。
- **清楚的錯誤訊息。** 檔案或翻譯出了問題，會在出問題的地方用平實的語言說明，並建議下一步該怎麼做。

## 字幕本身就是無障礙

這個工具圍繞字幕製作而生，有幾個選項與無障礙特別相關：

- **SDH 與聽障輔助字幕。** 聲音描述與說話者標註對聽不到聲音的人很有幫助，卻容易干擾機器翻譯。移除它們的選項，在支援的語言下預設是開啟的。如果你需要這些描述，翻譯前請先關閉「移除 SDH / 聽障輔助字幕」。
- **雙語輸出。** 原文與譯文並排顯示，方便語言學習者，也方便想對照對白檢查譯文的人。
- **可讀性檢查。** 字幕編輯器會標出過長的行與過快的語速，門檻依語言而異，因為難讀的字幕本身就是一種閱讀障礙。
- **規範的排版。** 標點、空格、換行與雙向文字的處理都遵循各語言的習慣，這對使用阿拉伯文、希伯來文等文字的讀者特別重要。

## 支援的環境

我們使用標準的 HTML、CSS、JavaScript 與 WAI-ARIA，目標是支援桌面與行動裝置上主流瀏覽器的最新版本：Chrome、Edge、Firefox 與 Safari。遵循網頁標準的輔助技術應該都能使用，包括螢幕閱讀器、開關裝置、語音控制，以及瀏覽器的縮放與字級設定。

少數選用功能，例如本機人名辨識，需要瀏覽器具備相應的能力。沒有它們，工具依然可以完整使用。

## 仍待加強之處

網站尚未經過第三方稽核，因此我們不宣稱符合 WCAG，只是以 WCAG 2.2 AA 等級作為參照，持續朝這個方向努力。目前已知還有待加強的地方包括：

- **高對比模式。** 我們目前還沒有為 Windows 強制色彩模式與對比偏好另外設計樣式，所以這些模式下的顯示效果取決於瀏覽器。
- **第三方元件。** 人機驗證由 Cloudflare 提供，討論頁則透過 giscus 嵌入 GitHub Discussions。它們的無障礙表現不在我們的掌控範圍內，但如果其中某個元件妨礙了你的使用，我們很樂意協助。服務狀態頁是獨立的網站，也有它自己的限制。
- **社群共同參與。** 介面與文件都由社群貢獻者一起完成，也歡迎你加入，一起把它們做得更好。參與方式請見[如何貢獻](../contribute/zh-Hant.md)。
- **機器翻譯。** 譯文可能會有出入，原字幕的時間軸與樣式也不一定適合每個播放器，使用前建議先檢查成品。如果發現問題，歡迎告訴我們，做法請見[關於問題回報與建議](../feedback/zh-Hant.md)。

## 回報無障礙問題

只要工具裡有哪裡難用或用不了，都歡迎告訴我們，即使你不確定它算不算無障礙問題。

- **公開回報：** 在 [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues) 提交，說明你想做什麼、發生了什麼，以及使用的瀏覽器與輔助技術。
- **私下聯絡：** 不想公開發文的話，可以透過[加入社群](../community/zh-Hant.md)找到維護者。
- **提交修正：** 非常歡迎。請參考[如何貢獻](../contribute/zh-Hant.md)。

專案由志工維護，每一則回報我們都會認真閱讀，也很重視無障礙方面的問題。其他問題或建議，請參考[關於問題回報與建議](../feedback/zh-Hant.md)。
