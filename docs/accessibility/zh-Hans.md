# 无障碍声明

做蒙太奇字幕翻译器，是为了让更多人能用自己看得懂的语言欣赏影视作品。如果工具本身就有人用不了，这件事就无从谈起。这篇文档说明我们在无障碍上做了什么、还有哪些不足，以及遇到障碍时怎么告诉我们。

## 我们的承诺

我们希望这个工具对每个人都好用，不管你用什么设备上网、用什么方式操作页面。靠键盘导航的、用屏幕阅读器的、需要放大文字或减少动画的、阅读从右向左书写语言的，还有设备和网络都比较一般的朋友，都在其中。

整个项目也是同一个出发点：不用注册，没有广告，不收费，不让钱或者账号成为一个人和一份字幕之间的门槛。字幕本身就是一种无障碍技术，它帮听不到声音的人，帮不懂原语言的人，也帮那些看文字比听对白更容易跟上剧情的人。

我们把无障碍问题当作 bug 来修，而不是当作可有可无的功能需求。

## 我们做了什么

- **键盘操作。** 翻译页、校对窗口和文档都按可以纯键盘操作来设计。有焦点指示，对话框打开时焦点留在框内，背后的页面对辅助技术隐藏，关闭后焦点回到原来的位置。
- **跳转链接。** 每个页面的第一站都是“跳到主要内容”。
- **语义与 ARIA。** 页面使用规范的地标和标题。自定义控件遵循标准模式：语言选择器是 combobox 加 listbox，选项组是 radio group，分区是支持方向键、Home、End 的 tab list，进度是 progress bar。
- **状态播报。** 不刷新页面就发生的变化，比如识别出的源语言，或者目标语言被自动切换，会通过 live region 播报。
- **编辑器快捷键。** 在校对窗口里，Ctrl 或 Cmd 加 F 是查找，加 H 是查找替换，加 Z、Y 是撤销和重做。
- **全文视图。** “原文”“译文”“对照”三个标签页会完整渲染每一条字幕，屏幕阅读器可以从头读到尾。
- **朴素、可选中的文字。** 界面里的绝大部分内容都是普通文字，可以轻松选中、复制和朗读。文档和说明类页面是预渲染的，没有 JavaScript 也能看。翻译功能本身需要 JavaScript，不可用时会明确提示。
- **界面语言。** 界面提供多种语言，数量还在增加。每个页面都会设置语言和文字方向，布局使用与方向相关的样式，阿拉伯语、波斯语、希伯来语、乌尔都语这些从右向左的语言会正确镜像。
- **动效与配色。** 系统要求减少动态效果时，动画会相应减少；浅色或深色外观跟随系统设置。
- **说人话的错误提示。** 文件或翻译出了问题，会在出问题的地方用平实的语言说明，并给出下一步怎么办的建议。

## 字幕本身就是无障碍

这个工具围绕字幕制作而生，有几个选项和无障碍特别相关：

- **SDH 与听障辅助字幕。** 声音描述和说话人标注对听不到声音的人很有用，却容易干扰机器翻译。去除它们的选项，在支持的语言下默认是打开的。如果你需要这些描述，翻译前请关掉“去除 SDH / 听障辅助字幕”。
- **双语输出。** 原文和译文一起显示，方便语言学习者，也方便想对照对白检查译文的人。
- **可读性检查。** 校对窗口会标出过长的行和过快的语速，阈值按语言区分，因为难读的字幕本身就是一种阅读障碍。
- **规范的排版。** 标点、空格、换行和双向文字的处理都遵循各语言的习惯，这对使用阿拉伯文、希伯来文等文字的读者尤其重要。

## 支持的环境

我们使用标准的 HTML、CSS、JavaScript 和 WAI-ARIA，目标是支持桌面和移动端主流浏览器的当前版本：Chrome、Edge、Firefox 和 Safari。遵循网页标准的辅助技术应该都能用，包括屏幕阅读器、开关设备、语音控制，以及浏览器的缩放和字号设置。

少数可选功能，比如本机人名识别，依赖浏览器的能力。没有它们，工具照样能完整使用。

## 已知的不足

网站没有经过第三方审计，我们也不声称符合 WCAG。我们以 WCAG 2.2 AA 级为参照，朝它努力。目前已知的差距有：

- **高对比度模式。** 我们没有为 Windows 强制颜色模式和对比度偏好单独写样式，所以在这些模式下的显示效果取决于浏览器。
- **第三方组件。** 人机验证由 Cloudflare 提供，讨论页通过 giscus 嵌入 GitHub Discussions。它们的无障碍表现我们管不了，但如果哪一个挡住了你，我们很乐意帮忙。服务状态页是一个独立的站点，有它自己的局限。
- **文档语言。** 文档有英文、简体中文和繁体中文三种，其他界面语言下会显示英文。
- **社区翻译。** 界面翻译来自志愿者，各语言的措辞和质量可能参差不齐。
- **机器翻译。** 输出可能有错误，原字幕的时间轴或样式也未必适合每个播放器。用之前请先检查成品。

## 反馈无障碍问题

只要工具里有哪里难用或者用不了，请告诉我们，哪怕你不确定它算不算无障碍问题。

- **公开反馈：** 在 [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues) 提交，说明你想做什么、发生了什么，以及用的浏览器和辅助技术。
- **私下联系：** 不想公开发帖的话，可以通过[加入社区](../community/zh-Hans.md)找到维护者。
- **提交修复：** 非常欢迎。请看[如何贡献](../contribute/zh-Hans.md)。

项目由志愿者维护，没法承诺回复时间，但每条反馈我们都会看，无障碍相关的修复会排在最前面。其他问题或建议，请看[关于反馈与建议](../feedback/zh-Hans.md)。
