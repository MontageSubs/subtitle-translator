# Apps & Tools

A curated collection of open-source applications and subtitle productivity tools developed and recommended by the **MontageSubs** community.

---

## Featured Community Apps

### 1. Subtitle Translator
* **Overview**: A privacy-first browser tool for neural machine translation and bilingual subtitle formatting with zero server-side storage.
* **Key Features**: SRT subtitle translation, customizable glossary support, CPS reading speed checks, and compliance validation.
* **Repository**: [MontageSubs/subtitle-translator](https://github.com/MontageSubs/subtitle-translator)

### 2. Montage Subtitle Tools
* **Overview**: Batch subtitle processing, timing adjustment, and format conversion utilities.
* **Key Features**: ASS / SRT / VTT multi-format conversion, bilingual merging, style extraction, and timeline batch shifting.
