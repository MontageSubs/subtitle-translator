# 安全漏洞回報指南

蒙太奇字幕翻譯器會處理來自許多人的字幕檔案，因此我們非常重視安全。感謝每一位願意花時間找出問題，並以負責任的方式告知我們的人。本指南說明哪些問題需要回報、如何私下聯絡我們，以及回報之後會發生什麼。

## 哪些屬於安全問題

安全問題是指可能被用來損害使用者或服務的缺陷，例如：

- 取得他人的資料，或存取服務的內部系統。
- 繞過身分驗證、頻率限制或濫用防護，並可能損害共用的服務。
- 在頁面、字幕預覽或翻譯結果中注入指令碼或其他內容（例如跨站指令碼）。
- 洩露金鑰、權杖等機密資訊。
- 可能造成嚴重後果的邏輯錯誤。

如果你不確定某個問題算不算，也請透過下方的私下管道告訴我們。

## 私下回報漏洞

請不要在 GitHub Issues、GitHub Discussions 或公開的聊天頻道中回報安全問題，否則在修復完成前，任何人都看得到細節。

請[加入社群](../community/zh-Hant.md)，並向專案核心維護者或社群管理員傳送私訊。先簡單說明你有一份安全回報即可，待對方確認可以私下接收後，再提供詳細內容。

## 回報時應包含的內容

- 你發現了什麼，以及你認為它屬於安全問題的原因。
- 重現步驟。如果需要字幕檔案或請求，請使用你自己製作的內容，不要使用他人的內容。
- 受影響的版本（點選頁面右下角的版本號即可查看）與瀏覽器。
- 你對影響範圍的判斷。
- 希望如何署名，或是否希望匿名。

## 回報之後

本專案由志工維護，因此無法承諾固定的回應時間，但我們會盡力確認收到回報、調查問題、修復並發布，並在完成後告知你。過程中我們可能會向你詢問更多細節。在修復發布之前，請對相關細節保密。

## 揭露與致謝

修復發布後，我們可能會公開一段簡短說明。經你同意，我們會在其中致謝；未經本人同意，我們不會公開任何個人資訊。

## 測試時的注意事項

請將測試限制在確認問題所需的範圍內。請不要：

- 存取、修改或刪除他人的資料。
- 對我們的服務發起自動化掃描或大量請求，以免耗盡共用資源。
- 影響其他使用者的正常使用。
- 對維護者或社群成員進行社交工程攻擊。

如果不確定某項測試是否合適，請先私下詢問。

## 支援的版本

修復會發布在 Web App 與服務的最新版本中，我們不維護舊版本。請先在最新版本中確認問題，再提交回報。

## 不在範圍內的問題

- 我們所依賴的第三方服務（代管、翻譯引擎、社群平台等）本身的問題，請向相應的服務提供者回報。
- 自動化工具產生、且未證明實際影響的回報。
- 阻斷服務與大流量攻擊。
- 社交工程與實體手段的攻擊。
