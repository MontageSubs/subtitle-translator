# 安全漏洞回報指南

蒙太奇字幕翻譯器是一項免註冊、免登入，並以使用者隱私為核心的公共服務。由於人人都能使用，它所依賴的資源需要受到保護，才能讓所有人都公平地用上。我們為此運行著自己的防濫用機制，它會分級進行檢查，我們也認真看待它的安全。

我們由衷感謝每一位願意花時間發現潛在漏洞，並以負責任的方式向我們通報的人。每一份認真的回報，都有助於我們讓服務更加安全、穩定，也讓整個社群受益。上面提到的防濫用機制也在其中，它由我們自己設計，歡迎大家告訴我們它哪裡還不夠牢靠。

本指南將說明哪些問題值得回報、如何透過私下管道聯絡我們，以及提交回報後會有哪些後續處理。

## 哪些情況屬於安全問題

凡是可能危害使用者或服務本身的漏洞，都屬於安全問題。防濫用機制中的弱點尤其值得關注，因為它保護的是大家共用的資源。例如：

- 未經授權存取服務的內部系統。
- 繞過或削弱請求頻率限制與防濫用機制，例如用到超出公平份額的服務。
- 導致正常使用者被誤限制。
- 用較小的請求消耗不成比例的共享資源。
- 在網頁、字幕預覽或翻譯結果中注入指令碼或其他惡意內容（例如跨站指令碼攻擊，XSS）。
- 洩露 API 金鑰、存取權杖或其他敏感資訊。
- 可能導致嚴重安全後果的程式邏輯漏洞。

如果你不確定發現的問題是否屬於安全漏洞，也歡迎告訴我們。我們寧可多了解一個值得注意的問題，也不希望有人因為不確定而選擇不回報。請透過下方的私下管道與我們聯絡。

## 如何私下回報漏洞

請勿透過 GitHub Issues、GitHub Discussions 或公開聊天頻道回報安全問題。漏洞細節一旦公開，在修復完成之前，就可能被其他人利用。

請先[加入社群](../community/zh-Hant.md)，再透過私訊聯絡專案核心維護者或社群管理員，這是最快聯絡到我們的方式。剛開始不需要提供完整的漏洞細節，只要簡單告知對方你有安全問題想要回報即可。確認對方能夠私下接收相關資訊後，再進一步分享完整內容。

如果你不方便使用聊天工具，或是更習慣 GitHub，也可以使用 GitHub 的[私下漏洞回報](https://github.com/MontageSubs/subtitle-translator/security/advisories/new)。同時在聊天中告知我們一聲，我們就能更快注意到。

## 回報時應提供哪些資訊

為了讓我們更容易了解問題並進行調查，請盡可能提供以下資訊：

- **問題描述：** 你發現了什麼？為什麼認為這可能構成安全風險？
- **重現步驟：** 說明如何重現問題，並附上必要的範例。如果需要提供字幕檔案或請求內容，請使用自己建立的素材，不要使用他人的資料。
- **受影響的版本與環境：** 點選應用程式右下角的版本號即可查看目前版本。也請提供所使用的瀏覽器及其版本。
- **可能造成的影響：** 你認為攻擊者可能利用這個漏洞做些什麼？
- **署名方式：** 告訴我們希望如何署名，或是否希望保持匿名。

不必擔心資訊不夠完整。只要是你能提供的線索，都有助於我們了解和調查問題。

## 提交回報後會怎麼處理

本專案由社群共同維護，因此我們無法承諾固定的回應時間。不過，我們會盡力確認收到你的回報、調查問題，並設法盡快完成修復。修復完成並發布後，我們也會通知你。

在調查過程中，如果需要進一步了解情況或確認細節，我們可能會再與你聯絡。

在修復正式發布之前，請暫時不要公開漏洞資訊，以及任何可能讓他人辨識或重現問題的細節。

## 漏洞揭露與致謝

修復發布後，我們可能會公開一份簡短的漏洞說明，介紹問題及其修復方式。

如果你願意公開署名，我們很樂意在相關說明中向你致謝。當然，一切都會以你的意願為準；未經同意，我們絕不會公開你的個人資訊。

## 測試時請注意

請將測試範圍控制在確認問題所需的程度，避免影響其他使用者或服務的正常運作。

測試過程中，請勿進行以下行為：

- 對服務進行自動化掃描或發送大量請求，以免耗盡所有使用者共用的資源。如果測試防濫用機制似乎需要一定的請求量，請先說明你的做法，並與我們討論。
- 干擾服務運作，或影響其他使用者正常使用服務。
- 對維護者或其他社群成員使用社交工程手段。

如果不確定某項測試是否合適，請先透過私下管道詢問我們，再繼續進行。

## 支援的版本

安全修復只會發布在 Web App 與服務的最新版本中，我們不會持續維護舊版本。

提交回報前，請先更新至最新版本，確認問題仍然存在，再將相關資訊提供給我們。

## 不在回報範圍內的問題

以下問題不屬於本指南的處理範圍：

- 我們所使用的第三方服務本身存在的漏洞或問題，例如代管服務、翻譯引擎及社群平台。這類問題請直接向相應的服務提供者回報。
- 僅由自動化工具產生，卻無法證明存在實際安全影響的掃描結果或警告。
- 阻斷服務攻擊（DoS）、分散式阻斷服務攻擊（DDoS）及其他大量流量攻擊本身。若這類攻擊暴露出我們防護機制中的弱點，該弱點仍在回報範圍內。
- 社交工程與實體攻擊。
