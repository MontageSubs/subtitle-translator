# 安全漏洞报告指南

蒙太奇字幕翻译器是一项无需注册或登录、并以保护用户隐私为核心的公共服务。由于人人都能使用，它所依赖的资源需要得到保护，才能让所有人都公平地用上。我们为此运行着自己的防滥用机制，它会分级进行检查，我们也认真对待它的安全。

感谢每一位愿意花时间发现潜在漏洞，并以负责任的方式向我们报告的人。每一份认真提交的报告，都有助于我们让服务变得更加安全、可靠。上面提到的防滥用机制也在其中，它由我们自己设计，欢迎大家告诉我们它哪里还不够牢靠。本指南将介绍哪些问题值得报告、如何通过私下渠道联系我们，以及提交报告后会有哪些后续处理。

## 哪些问题属于安全漏洞

凡是可能危害用户或服务本身的安全缺陷，都值得向我们报告。防滥用机制中的弱点尤其值得关注，因为它保护的是大家共用的资源。例如：

- 未经授权访问服务的内部系统。
- 绕过或削弱请求频率限制与防滥用机制，例如用到超出公平份额的服务。
- 导致正常用户被误限制。
- 用较小的请求消耗不成比例的共享资源。
- 在网页、字幕预览或翻译结果中注入脚本或其他恶意内容（例如跨站脚本攻击，即 XSS）。
- 泄露 API 密钥、访问令牌或其他敏感信息。
- 可能造成严重安全后果的程序逻辑漏洞。

如果你不确定发现的问题是否属于安全漏洞，也欢迎告诉我们。我们宁愿多了解一个值得关注的问题，也不希望有人因为拿不准而选择不报告。请通过下方的私下渠道与我们联系。

## 如何私下报告漏洞

请不要通过 GitHub Issues、GitHub Discussions 或公开聊天频道报告安全漏洞。在问题修复之前，公开漏洞细节可能让其他人有机会利用这些问题，进而危及用户或服务的安全。

请先[加入社区](../community/zh-Hans.md)，然后通过私信联系项目核心维护者或社区管理员，这是最快联系到我们的方式。一开始不必提供完整的漏洞细节，只需简单说明你有安全问题需要报告即可。等对方确认可以私下接收相关信息后，再进一步提供详细内容。

如果你不方便使用聊天工具，或者更习惯 GitHub，也可以使用 GitHub 的[私下漏洞报告](https://github.com/MontageSubs/subtitle-translator/security/advisories/new)。同时在聊天里告知我们一声，我们就能更快注意到。

## 报告中应包含哪些信息

为了帮助我们更快了解和调查问题，请尽可能提供以下信息：

- **问题描述：** 你发现了什么？为什么认为这可能构成安全风险？
- **复现步骤：** 说明如何重现问题，并提供必要的示例。如果需要字幕文件或请求内容，请使用自己制作的素材，不要使用他人的数据。
- **受影响的版本和环境：** 点击应用右下角的版本号即可查看当前版本。也请提供所使用的浏览器及其版本。
- **潜在影响：** 你认为攻击者可能利用这个漏洞做什么？会对用户或服务造成哪些影响？
- **署名方式：** 告诉我们你希望如何署名，或者是否希望保持匿名。

不必担心信息不够完整。你能提供的任何线索，都有助于我们了解和调查问题。

## 提交报告后会怎样处理

本项目由社区共同维护，因此我们无法承诺固定的响应时间。不过，我们会尽力确认收到你的报告、调查问题，并尽快着手修复。修复完成并正式发布后，我们也会通知你处理结果。

在调查过程中，如果需要进一步了解情况或确认细节，我们可能会再次与你联系。

在修复正式发布之前，请暂时不要公开漏洞信息，以及任何可能帮助他人识别或复现问题的细节。

## 漏洞披露与致谢

修复发布后，我们可能会公开一份简短的说明，介绍漏洞及其修复方式。

如果你愿意公开署名，我们很乐意在相关说明中感谢你的贡献。当然，是否署名完全由你决定。未经你的同意，我们不会公开你的姓名或其他个人信息。

## 测试时请注意

请将测试范围控制在确认问题所必需的程度，避免影响其他用户或服务的正常运行。

测试过程中，请勿进行以下操作：

- 对我们的服务进行自动化扫描或发送大量请求，以免耗尽所有用户共用的资源。如果测试防滥用机制似乎需要一定的请求量，请先说明你的思路，并与我们沟通。
- 干扰服务运行，或影响其他用户正常使用。
- 对项目维护者或社区成员使用社会工程手段。

如果不确定某项测试是否合适，请先通过私下渠道向我们确认，再继续进行。

## 支持的版本

安全修复只会发布在 Web App 和服务的最新版本中，我们不再维护旧版本。

提交报告前，请先更新到最新版本，确认问题仍然存在后，再向我们提交相关信息。

## 不在报告范围内的问题

以下类型的问题不属于本指南的处理范围：

- 我们所使用的第三方服务本身存在的漏洞或问题，例如托管服务、翻译引擎和社区平台。这类问题请直接向相应的服务提供商报告。
- 仅由自动化工具扫描得出，却无法证明存在实际安全影响的结果。
- 拒绝服务攻击（DoS）、分布式拒绝服务攻击（DDoS）及其他大流量攻击本身。若这类攻击暴露出我们防护机制中的弱点，该弱点仍在报告范围内。
- 社会工程和物理攻击。
