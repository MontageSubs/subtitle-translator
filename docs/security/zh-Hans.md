# 安全披露指南

蒙太奇字幕翻译器会处理来自许多人的字幕文件，因此我们非常重视安全。感谢每一位花时间发现问题，并以负责任的方式告知我们的人。本指南说明哪些问题需要报告、如何私下联系我们，以及报告之后会发生什么。

## 哪些属于安全问题

安全问题是指可能被用来损害用户或服务的缺陷，例如：

- 获取他人的数据，或访问服务的内部系统。
- 绕过身份验证、频率限制或滥用防护，并可能损害共享服务。
- 在页面、字幕预览或翻译结果中注入脚本或其他内容（例如跨站脚本）。
- 暴露密钥、令牌等机密信息。
- 可能造成严重后果的逻辑错误。

如果你不确定某个问题算不算，也请通过下面的私下渠道告诉我们。

## 私下报告漏洞

请不要在 GitHub Issues、GitHub Discussions 或公开的聊天频道中报告安全问题，否则在修复完成前，任何人都能看到细节。

请[加入社区](../community/zh-Hans.md)，并向项目核心维护者或社区管理员发送私信。先简单说明你有一份安全报告即可，等对方确认可以私下接收后，再发送详细内容。

## 报告中应包含的内容

- 你发现了什么，以及你认为它属于安全问题的原因。
- 复现步骤。如果需要字幕文件或请求，请使用你自己制作的内容，不要使用他人的内容。
- 受影响的版本（点击页面右下角的版本号即可查看）和浏览器。
- 你对影响范围的判断。
- 希望如何署名，或是否希望匿名。

## 报告之后

本项目由志愿者维护，因此无法承诺固定的响应时间，但我们会尽力确认收到报告、调查问题、修复并发布，并在完成后告知你。过程中我们可能会向你询问更多细节。在修复发布之前，请对相关细节保密。

## 披露与致谢

修复发布后，我们可能会公开一段简短说明。经你同意，我们会在其中致谢；未经本人同意，我们不会公开任何个人信息。

## 测试时的注意事项

请将测试限制在确认问题所需的范围内。请不要：

- 访问、修改或删除他人的数据。
- 对我们的服务发起自动化扫描或大量请求，以免耗尽共享资源。
- 影响其他用户的正常使用。
- 对维护者或社区成员进行社会工程攻击。

如果不确定某项测试是否合适，请先私下询问。

## 支持的版本

修复会发布在 Web App 与服务的最新版本中，我们不维护旧版本。请先在最新版本中确认问题，再提交报告。

## 不在范围内的问题

- 我们所依赖的第三方服务（托管、翻译引擎、社区平台等）自身的问题，请向相应服务方报告。
- 自动化工具产生、且未证明实际影响的报告。
- 拒绝服务和大流量攻击。
- 社会工程和物理手段的攻击。
