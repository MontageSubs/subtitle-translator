# 如何貢獻

蒙太奇字幕翻譯器是由一群喜歡字幕與影視作品的人共同打造、維護的社群開源專案。如果你覺得這個工具對你有幫助，也歡迎一起參與，讓它持續進步。

## 關於捐款

我們目前不接受現金捐款。

開發這個專案，是因為我們喜歡字幕與影視作品，也希望更多人能看懂自己喜歡的作品。我們希望能一直保有這份熱情，自由地探索和嘗試，不讓金錢左右專案的方向。

我們也希望蒙太奇字幕翻譯器能持續免費開放給所有人使用。大家不需要付費、自己準備 API 額度，也不必花時間處理繁瑣的設定，就能透過這個工具跨越語言隔閡，看懂自己喜歡的作品。

如果你原本打算透過捐款支持我們，謝謝你的這份心意。雖然我們不接受現金捐款，但如果你選擇將這份心意用在其他非營利組織上，支持那些致力於改善人們的生活、消除貧困、促進教育、保障人權、保護環境或照顧其他生命的團體，我們同樣會由衷感謝。這些團體所做的事，也與我們認同的價值相通。

如果你仍希望直接支持專案，也歡迎提供我們實際需要的技術或其他資源。有哪些參與方式，以及專案目前需要哪些協助，請參考下方的說明。

## 協助改善文件與翻譯

如果你發現文件有錯字、說明不夠清楚，或內容已經過時，歡迎協助修正。

如果你熟悉其他語言，也歡迎幫忙翻譯或校對專案的介面與文件。我們希望不同語言的使用者都能輕鬆上手，也希望這個工具能幫助更多人看懂自己喜歡的作品。

## 回報問題

如果有哪個地方不好用、哪段說明讓你看不懂，或你覺得某個操作其實可以更簡單，都歡迎告訴我們。

你不需要先找出問題的原因，也不必想好解決方法才來回報。只要告訴我們遇到了什麼情況、當時使用的字幕，以及相關的操作方式，就能幫助我們了解問題。如果方便，也可以附上截圖或重現問題的步驟。

如果發現涉及隱私或安全的問題，請透過私下管道聯絡我們，避免公開可能被他人利用的漏洞細節或敏感資訊。

回報方式請參考[回報問題](../report-issue/zh-Hant.md)。

## 提出建議

如果你有什麼想法，歡迎和我們分享。

無論是希望增加某項功能、簡化操作，還是看到其他工具有值得參考的設計，都可以告訴我們。這些建議能幫助我們了解使用者的需求，找到值得改進的地方。

## 參與程式開發

本專案採用 MIT 授權條款開源。如果你熟悉程式設計，歡迎一起參與開發。無論是修復 Bug、改善效能，還是調整現有功能，都可以從自己感興趣的部分開始。

如果你還不熟悉這個專案，也沒關係。歡迎加入社群，一起交流。無論是遇到問題、不知道從哪裡開始，還是想先了解專案的運作方式，都可以來聊聊，我們很樂意協助。

你可以從 [GitHub 專案儲存庫](https://github.com/MontageSubs/subtitle-translator) 開始。

## 分享這個專案

如果你覺得這個工具好用，歡迎分享給有相同需求的人。無論是推薦給朋友、在相關社群介紹，還是分享自己的使用心得，都很有幫助。

我們不需要刻意宣傳。如實告訴別人這個工具能做什麼、有哪些不足，就很好。也許剛好有人需要這樣的工具，而你的分享能讓他們找到合適的解決方式。

## 成為社群志工

如果你願意幫忙處理社群裡的大小事，也歡迎加入。

你可以協助回答其他使用者的問題、整理問題回報、維護社群文件，或參與其他日常工作。能投入多少時間、想參與哪些事情，都可以依照自己的時間和興趣決定。

## 關於 DeepL API 贊助

DeepL 是我們希望能提供給大家使用的翻譯引擎之一。我們已經完成相關的技術串接，但經過成本評估，目前還沒有足夠的資源，讓所有人都能免費使用這項服務。

我們希望每個人都能免費使用這個工具，不因經濟條件不同而受到限制。因此，在考慮導入新的翻譯引擎時，除了翻譯品質，也必須考量長期的使用與維護成本。

如果你有充足的 DeepL API 額度，願意提供給專案使用，歡迎與我們聯絡。這能讓我們有機會提供更好的翻譯品質，也讓更多使用者受益。

## 關於 AI（LLM）資源贊助

我們也希望未來能提供使用大型語言模型（LLM）的 AI 字幕翻譯服務。不過，根據目前的評估，以預期的使用量來看，這類服務的成本可能是現有神經機器翻譯（NMT）方案的約 50 倍，短期內還難以免費開放給所有人使用。

如果你來自提供 LLM 或 NMT 服務的公司或機構，並能提供足以支援每天翻譯數萬至數十萬條字幕的 API 額度或運算資源，非常歡迎與我們聯絡。這能幫助我們為更多使用者提供更好的翻譯服務。

此外，我們在開發過程中也會使用 AI 輔助開發。如果你能提供相關的 API 額度、技術資源，或其他能協助我們使用 AI 工具開發專案的支持，也歡迎與我們交流。

## 提供其他資源

除了翻譯引擎和 AI 相關資源，如果你能提供專案實際需要的主機、基礎設施、技術服務、軟體服務或設備，也歡迎與我們聯絡。

如果你手邊剛好有適合這個專案的資源，或有其他支持專案的想法，都可以來聊聊。我們可以一起看看這些資源能不能派上用場，讓服務維持穩定，也讓開發和維護工作更順利。

## 參與社群交流

參與這個社群，不一定要寫程式或負責什麼工作。

如果這個工具對你有幫助，歡迎分享使用心得、交流想法，或單純來社群聊聊天。我們也很珍惜透過這個專案認識更多喜歡字幕、翻譯與開源軟體的朋友。

不論你想參與專案，還是單純來和大家交流，都歡迎你。
