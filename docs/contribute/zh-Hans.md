# 参与贡献

**Subtitle Translator** 是一个完全开源、由志愿者社区驱动的项目。我们欢迎所有对字幕制作、翻译质量优化、前端工程与体验设计抱有热忱的伙伴加入我们！

---

## 如何参与贡献？

你可以通过多种方式为本项目做出贡献：

1. **改进翻译质量与术语库**：
   - 提交行业专有名词、影视俚语或特定领域的双语对照术语。
   - 优化机器翻译后的后处理规则与排版断句逻辑。
2. **提交功能与代码改进**：
   - 在 [GitHub 仓库](https://github.com/MontageSubs/subtitle-translator) 提交 Pull Request，帮助我们完善功能、提升性能或修复缺陷。
3. **反馈问题与使用建议**：
   - 在实际使用中遇到翻译异常、格式不兼容或界面问题时，欢迎前往 [反馈问题](../docs/report-issue) 或提交 [GitHub Issue](https://github.com/MontageSubs/subtitle-translator/issues)。
4. **完善多语言文档**：
   - 协助翻译或润色不同语言的帮助文档、隐私说明与使用手册。

---

## 贡献者致谢

感谢每一位为本项目贡献智慧与热忱的朋友——无论是代码编写、文档润色、翻译校对还是社区建设，你们的付出让字幕翻译变得更加美好！
