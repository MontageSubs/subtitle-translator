# 如何贡献

蒙太奇字幕翻译器是一个由字幕和影视爱好者共同打造、维护的社区开源项目。如果你觉得这个工具对你有帮助，也欢迎参与进来，和我们一起把它做得更好。

## 关于捐款

我们目前不接受现金捐款。

我们开发这个项目，是因为喜欢字幕和影视作品，也希望更多人能够看懂自己喜欢的作品。我们希望始终保有这份热情，自由地探索和尝试，不让金钱决定项目的发展方向。

我们也希望蒙太奇字幕翻译器能一直免费向所有人开放。大家不需要付费、自己准备 API 配额，也不必花时间折腾复杂的设置，就能通过这个工具跨越语言障碍，看懂自己喜欢的作品。

如果你原本打算通过捐款支持我们，谢谢你的这份心意。虽然我们不接受现金捐款，但如果你选择将这份心意用于其他非营利组织，支持那些致力于改善人们生活、消除贫困、促进教育、保障人权、保护环境或帮助其他生命的团体，我们同样会由衷感谢。这些团体所做的事，也与我们认同的价值相通。

如果你仍然希望直接支持项目，也欢迎提供项目实际需要的技术或其他资源。具体可以怎样参与，以及项目目前需要哪些帮助，请参考下方的说明。

## 改善文档与翻译

如果你发现文档里有错别字、说明不够清楚，或者内容已经过时，欢迎帮忙修改。

如果你熟悉其他语言，也欢迎帮忙翻译和校对项目的界面与文档。我们希望不同语言的用户都能轻松上手，也希望这个工具能帮助更多人看懂自己喜欢的作品。

## 反馈问题

如果某个地方不好用、某段说明让你看不懂，或者你觉得某项操作其实可以更简单，都欢迎告诉我们。

你不需要先弄清楚问题的原因，也不必想好解决办法才来反馈。只要告诉我们遇到了什么情况、当时使用的字幕，以及相关的操作方式，就能帮助我们了解问题。如果方便，也可以附上截图或复现问题的步骤。

如果发现涉及隐私或安全的问题，请通过私下渠道联系我们，避免公开可能被他人利用的漏洞细节或敏感信息。

具体反馈方式请参考[反馈问题](../report-issue/zh-Hans.md)。

## 提出建议

如果你有新的想法，欢迎告诉我们。

无论是希望增加某项功能、简化操作，还是发现其他工具有值得借鉴的设计，都可以和我们分享。这些建议能帮助我们了解用户的实际需求，找到值得改进的地方。

## 参与代码开发

本项目采用 MIT 许可证开源。如果你熟悉编程，欢迎参与开发。无论是修复 Bug、优化性能，还是改进现有功能，都可以从自己感兴趣的部分开始。

如果你还不熟悉项目，也没关系。欢迎加入我们的社区，一起交流。无论是遇到问题、不知道从哪里开始，还是想先了解项目的运作方式，都可以来聊聊，我们很乐意帮忙。

你可以从 [GitHub 代码仓库](https://github.com/MontageSubs/subtitle-translator) 开始。

## 分享这个项目

如果你觉得这个工具好用，欢迎分享给有同样需求的人。无论是推荐给朋友、在相关社区介绍，还是分享自己的使用体验，都很有帮助。

我们不需要刻意宣传。如实告诉别人这个工具能做什么、有哪些不足，就很好。也许刚好有人需要这样的工具，而你的分享能帮助他们找到合适的解决办法。

## 成为社区志愿者

如果你愿意帮忙处理社区里的日常事务，也欢迎加入。

你可以帮助其他用户解答问题、整理问题反馈、维护社区文档，或者参与其他日常工作。可以投入多少时间、想参与哪些事情，都可以根据自己的时间和兴趣决定。

## 关于 DeepL API 赞助

DeepL 是我们希望能够提供给大家使用的翻译引擎之一。我们已经完成了相关的技术对接，但经过成本评估，目前还没有足够的资源，让所有人都能免费使用这项服务。

我们希望每个人都能免费使用这个工具，不因经济条件不同而受到限制。此外，在考虑接入新的翻译引擎时，除了翻译质量，也必须考虑长期的使用和维护成本。

如果你有充足的 DeepL API 配额，并愿意提供给项目使用，欢迎与我们联系。这能让我们有机会提供更好的翻译质量，也让更多用户受益。

## 关于 AI（LLM）资源赞助

我们也希望未来能提供基于大型语言模型（LLM）的 AI 字幕翻译服务。不过，根据目前的评估，按照预期的使用量，这类服务的成本可能是现有神经机器翻译（NMT）方案的约 50 倍，短期内还难以免费向所有人开放。

如果你来自提供 LLM 或 NMT 服务的公司或机构，并且能够提供足以支持每天翻译数万至数十万条字幕的 API 配额或算力资源，非常欢迎与我们联系。这能帮助我们为更多用户提供更好的翻译服务。

此外，我们在开发过程中也会使用 AI 辅助开发。如果你能提供相关的 API 配额、技术资源，或其他有助于我们使用 AI 工具开发项目的支持，也欢迎与我们交流。

## 提供其他资源

除了翻译引擎和 AI 相关资源，如果你能提供项目实际需要的主机、基础设施、技术服务、软件服务或设备，也欢迎与我们联系。

如果你手头正好有适合项目使用的资源，或者有其他支持项目的想法，都欢迎来聊聊。我们可以一起看看这些资源能不能派上用场，让服务保持稳定，也让开发和维护工作更加顺利。

无论你想参与项目，还是单纯来和大家交流，都欢迎你。
