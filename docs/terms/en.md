# Terms of Service

**MontageSubs is a passion-driven, open-source subtitle community. These Terms of Service govern the online subtitle translation tool and are maintained under the same community-first spirit.**

We strive to provide subtitle enthusiasts, creators, and translators with a free neural machine translation service that understands subtitle structures, maintains glossary consistency, recognizes scene boundaries, and aligns with community subtitle standards.

## 1. Community Philosophy & Operations
This service is maintained and powered by passionate community volunteers. The operational costs for translation services and infrastructure are covered by contributors' personal sponsorships, free-tier API quotas, and community contributions.

*   **Non-Profit Commitment**: We will never sell your data, track user profiles for commercial profit, or monetize through advertisements.
*   **Appreciation of Resources**: Operating a free public service requires real computational and human resources. We love subtitles, we love the subtitle community, and we are dedicated to crafting an exceptional experience for creators and viewers alike.

## 2. Funding, Donations & Contributions
*   **No Monetary Donations**: We **do not accept financial donations**. Accepting money turns personal passion into an obligation with external pressure, which restricts the freedom and spirit that drives this project. All expenditures (time, effort, and funds) are volunteered by maintainers. Please remain vigilant against unauthorized parties soliciting donations under our name.
*   **Non-Monetary Contributions Welcome**: We warmly welcome passionate contributions, including submitting code improvements, reporting bugs and suggestions, sharing this tool with fellow subtitle enthusiasts, or donating unused API quotas to the public pool.

## 3. Acceptable Use & Ownership
*   **Web-Based Access**: This service is intended exclusively for legitimate end users translating subtitles via our official web interface.
*   **Subtitle Ownership**: You retain full ownership and intellectual property rights to the subtitle files and text you process. We claim no ownership over your content.
*   **Open Source**: The source code is licensed under the MIT License and hosted publicly on [GitHub](https://github.com/MontageSubs/subtitle-translator).

## 4. Prohibited Conduct
To safeguard the availability and sustainability of this public utility for everyone, the following actions are strictly prohibited:

### 4.1 API & Backend Abuse
*   Reverse engineering APIs, exploiting vulnerabilities to bypass the frontend interface, calling backend endpoints directly, or extracting/exposing internal credentials and configurations is prohibited.
*   Such abuse rapidly drains public API quotas, causing service outages for everyone. If you have legitimate integration requirements, please open a discussion on GitHub Issues or Discussions. We encourage examining our source code to discover vulnerabilities and help improve security.

### 4.2 Automated Scripts & Bots
*   Using automated scripts, bots, scrapers, headless browsers, or any automated tools to batch-process requests outside the web interface is forbidden. Automated traffic depletes API quotas instantly and risks rate-limiting from upstream providers.

### 4.3 Violations of Upstream Provider Policies
*   Submitting content strictly prohibited by upstream translation providers is forbidden, including but not limited to illegal activities, harassment, hate speech, explicit content, malware, and fraudulent text.
*   **Core Principle**: If you suspect content may be unlawful or harmful, do not use this service to translate it. Policy violations risk provider-level suspensions that affect the entire community.

### 4.4 Attacking Infrastructure
*   Conducting Denial of Service (DoS/DDoS) attacks, exploiting known vulnerabilities, transmitting malformed payloads, or scanning/probing server ports is prohibited.
*   Attacking or disrupting any supporting infrastructure (including but not limited to GitHub Pages, Cloudflare Workers, Turso, js.org, or Google Neural Machine Translation) is strictly forbidden.

## 5. Responsible Security Disclosure
If you discover a security vulnerability, please report it privately via GitHub Discussions, Telegram, Discord, or official community channels. Please do not disclose unpatched vulnerability details publicly.

## 6. Enforcement & Appeals
Depending on severity, we reserve the right to issue warnings, apply temporary or permanent IP rate-limits/access restrictions, or pursue legal remedies in cases of malicious attacks. If you believe your access was restricted in error, you may submit an appeal via our community channels.
