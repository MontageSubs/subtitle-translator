# 服務條款

蒙太奇字幕翻譯器是由 **蒙太奇字幕社群** 開發及維護的開源、免費字幕翻譯公共服務。

蒙太奇字幕社群是由影視愛好者、字幕製作者、影視工作者與開發者共同組成的非營利字幕社群。我們因為對影視與字幕的熱愛而聚集在一起，希望透過開源的方式，將製作經驗與技術分享給每一個人，促進跨語言理解與文化交流，共同打造一個開放且蓬勃發展的字幕生態系。

我們深知，「免費」並不代表沒有成本。蒙太奇字幕翻譯器凝聚了社群成員投入的大量開發心力，整合了字幕知識、格式規範、排版經驗與自然語言處理技術。我們希望為每一位愛好者提供穩定且高效的免費公共服務。

為了確保這項服務能長期嘉惠所有使用者，我們希望與大家建立一份使用共識，明確界定我們共同維護的原則，以及為了社群健全發展而無法接受的行為。

## 1. 服務理念與運作模式

本服務由社群成員自發投入時間與心力維護。翻譯服務與基礎設施的營運成本，主要由貢獻者個人贊助、API 免費額度及社群志願資源共同支應。

我們希望透過開源精神與免費公共服務，讓不同身分的使用者都能從中受益：

**對於字幕製作者**：你可以利用術語表、上下文感知、場景識別、SDH、粗體樣式及 ASS 樣式設定等進階功能，搭配本機模型的最佳化處理，取得高品質的機器翻譯初稿。同時，內建的本機編輯器、對照預覽及自動錯誤識別功能，也能大幅提升你的校對效率。我們非常歡迎你[加入社群](../community/zh-Hant.md)，與大家交流製作經驗、分享專業知識。

**對於影視愛好者**：你可以在短短十幾秒內取得一份排版完善、時間軸準確、品質可靠的譯本，幫助你快速理解外語影視內容，也能透過雙語字幕輔助語言學習。我們希望這項工具能讓你感受到字幕藝術的魅力，並啟發你踏出字幕製作的第一步。

**對於開發者**：你可以探索原始碼，研究字幕排版與格式如何透過程式碼實現，了解字幕規範如何轉化為高效的程式邏輯。我們歡迎你[加入社群](../community/zh-Hant.md)，一起探索更多有趣的專案，將優秀的想法付諸實現。

**對於影視創作者**：我們希望透過社群協作，為獨立影視創作者提供語言交流與字幕製作方面的協助，讓更多優秀作品有機會跨越語言隔閡，被不同地區的觀眾看見。

我們希望每一位使用者都能從中受益，並與我們一起推動蒙太奇字幕社群的發展。如果你認同我們的理念，歡迎前往[貢獻](../contribute/zh-Hant.md)頁面，透過提供建議、參與開發或成為社群志工，與我們一起打造這個生態系。

## 2. 使用許可與資源維護

**網頁工具**：我們支持使用者在免登入、免註冊、無廣告且無追蹤的環境下使用本工具。我們採用嚴謹的隱私保護措施，盡可能保障你的隱私，詳情請參閱[隱私權政策](../privacy/zh-Hant.md)。

**原始碼**：本專案的原始碼採用 MIT 授權條款開源，包含字幕處理邏輯、最佳化演算法等專業技術在內的所有內容，皆向公眾開放，歡迎你參與貢獻與改進，讓更多人受益。

**關於公共資源的使用**：我們鼓勵開發者以開源程式碼為基礎進行創作。不過，需要特別說明的是，本社群的公共後端資源與 API 額度是由所有成員共同維護的有限資源。為了確保資源分配公平，並維持服務的穩定性，目前我們僅透過官方網頁版提供公共服務，暫不開放第三方客戶端直接介接公共 API，以避免無法控管的資源消耗影響其他使用者的正常使用。

如果你有正當的整合需求，歡迎透過 [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues/) 或 [Discussions](https://github.com/MontageSubs/subtitle-translator/discussions/) 與我們聯繫。我們願意在不影響公共資源公平分配的前提下，與你共同討論合適的解決方案。

### 內容授權與責任共識

作為使用者，請確保自己擁有翻譯相關材料所需的權利。你對透過本工具處理的字幕檔案與文字內容，仍保有原本享有的全部權利；我們不主張也不擁有你的內容，且基於隱私保護設計，我們無法檢視你提交的內容。

**關於責任的說明**：你應對自己提交的內容，以及使用本服務所產生的行為負起相應責任。特別提醒，擁有字幕檔案並不代表同時擁有翻譯該字幕的權利。本工具提供的是翻譯技術，但這並不代表使用者可以提交自己無權翻譯的內容。請務必在遵守著作權法規的前提下使用本服務。

## 3. 永續使用共識（使用規範）

為了確保公共服務能夠永續運作，並保障所有使用者的公平權益，我們希望每位使用者都能共同遵守以下約定：

**1. 翻譯合法合規的內容**

請勿使用本服務翻譯任何可能危害公共服務正常運作的內容，包括但不限於違法、侵權或惡意內容。由於本服務整合了多家翻譯供應商（包括本機引擎與上游引擎），使用時請務必遵守所有相關供應商的使用條款。即使某些內容在你所在的司法管轄區內合法，只要違反服務供應商所在地的法律或使用條款，也請勿使用本服務處理。

**基本原則**：如果你認為某些內容可能涉及法律風險或具有潛在危害，即使只是猜測，也請不要使用本服務處理。違規內容可能導致整體服務遭到停用，或被迫採取更嚴格的使用限制，進而影響所有社群成員的權益。

**2. 尊重服務資源與使用額度**
*   **關於速率限制**：我們設有動態配額管理機制，以兼顧所有使用者的公平使用權益。考量到字幕製作通常需要連續處理，為了確保正在進行的任務能夠順利完成，當使用者首次觸及速率限制時，我們會提供額外的緩衝額度。但請勿嘗試繞過配額限制，包括利用系統漏洞或濫用緩衝機制。如果你已達到使用上限，請稍作休息，相關限制通常會在一段時間後自動解除。

**3. 杜絕資源濫用**

我們希望使用者都是真正熱愛字幕與影視文化的愛好者。我們支持使用者透過合理的瀏覽器輔助工具或無障礙工具提升效率，但嚴禁未經授權的自動化大量請求、無人值守的呼叫，以及任何形式的資源濫用。這類行為會迅速消耗公共資源，嚴重影響所有人的使用體驗；此外，自動化程式也缺乏人類對語言細節的理解，無法真正參與知識交流與服務改進等社群活動。

**4. 共同維護友善的社群環境**
*   **基礎設施安全**：請勿對我們的基礎設施、服務介面或服務供應商進行任何未經授權的攻擊或探測。我們非常歡迎善意的安全研究，如果你在研究過程中發現潛在的安全漏洞，請參閱[安全漏洞回報指南](../security/zh-Hant.md)，向我們通報，一起維護社群安全。
*   **尊重社群成員**：請勿騷擾或人身攻擊社群成員及貢獻者。我們遵循[行為準則](../code-of-conduct/zh-Hant.md)，維持友善、互助的交流氛圍。

為了保障大多數使用者的權益，對於違反上述共識的行為，我們將依照違規情節的嚴重程度，採取以下措施：
1. 發出善意提醒或警告；
2. 暫時或永久限制使用者使用本服務的權利；
3. 如涉及惡意攻擊或重大違法情形，將依法追究相關責任。

**申訴管道**：我們了解，自動化限制機制偶爾可能發生誤判。如果你認為自己的使用權限遭到錯誤限制，歡迎透過[社群群組](../community/zh-Hant.md)或討論區與我們聯繫，我們將協助你釐清原因並處理申訴。

**關於翻譯品質**：最終翻譯效果取決於你的設定、所選用的翻譯引擎、處理邏輯及上游引擎的能力。我們會持續改善服務，也誠摯邀請你透過[回饋](../feedback/zh-Hant.md)頁面提供意見，與我們一起讓工具變得更好。
