# 服务条款

蒙太奇字幕翻译器是由蒙太奇字幕社区开发、维护的开源且免费的字幕翻译公共服务。

蒙太奇字幕社区是一个由影视爱好者、字幕制作者、影视工作者和开发者组成的非营利字幕社区。我们在这里分享对影视与字幕的热爱，希望把制作经验与技能以开源的方式传递给每一个人，促进跨语言的理解与文化传播，共同构建开放、繁荣的字幕生态。

我们深知，“免费”的背后并非没有成本。蒙太奇字幕翻译器凝聚了社区成员大量的开发投入，融合了字幕知识、格式规范、排版经验与自然语言处理技术。我们希望为每一位爱好者提供稳定、高效的免费公共服务。

为了让这项服务能长期造福所有使用者，我们需要就使用方式达成共识，明确共同守护的底线，以及为了社区健康而无法接受的行为。

## 1. 服务理念与运营模式

本服务由社区成员用爱驱动，用心维护。翻译服务与基础设施的运行成本，由贡献者个人赞助、API 免费额度及社区志愿资源共同覆盖。

我们希望通过开源的精神与免费的公共服务，让不同身份的使用者都能从中获益：

**对于字幕制作者**：你可以利用术语表、上下文感知、场景识别、SDH、加粗样式及 ASS 样式配置等高级功能，结合本地模型的优化处理，获得高质量的机器翻译初稿。同时，内置的本地编辑器、对比预览及自动错误识别功能，也能大幅提升你的校对效率。欢迎你加入社区，与我们交流制作经验。

**对于影视爱好者**：你可以在十几秒内获得一份排版专业、时间轴准确、质量可靠的译本，帮助你快速理解异国影视内容，并通过双语选项辅助语言学习。我们希望这个工具能带你领略字幕艺术的魅力，并启发你尝试自己制作字幕。

**对于开发者**：你可以通过源代码了解字幕排版与格式是如何用代码实现的，看看字幕规范怎样转化为高效的逻辑。欢迎你加入社区，一起探索更多有趣的项目，把好想法变为现实。

**对于影视制作者**：我们希望通过社区协作，为独立影视创作者提供语言交流与字幕制作方面的支持，让更多优秀作品有机会跨越语言障碍，被不同地区的观众看见。

我们希望每一位使用者都能从中受益，并与我们一起推动蒙太奇字幕社区的发展。如果你认同我们的理念，欢迎访问[贡献](../contribute/zh-Hans.md)页面，通过反馈建议、参与开发或成为社区成员，与我们一同建设这个生态。

## 2. 使用许可与资源守护

**网页工具**：我们支持用户在免登录、免注册、无广告、无追踪的环境下使用本工具。我们采用严格的隐私设计，尽可能保护你的隐私，详见[隐私政策](../privacy/zh-Hans.md)。

**源代码**：本项目源代码遵循 MIT 许可协议开源，包括字幕处理逻辑、优化算法在内的所有内容均对公众开放，欢迎你使用、修改并参与改进，让更多人受益。

**关于公共资源的使用**：我们鼓励开发者基于开源代码进行创造。但需要说明的是，本社区的公共后端资源与 API 配额是所有成员共同守护的有限资源。为了确保资源公平分配、维持服务稳定，目前公共服务仅面向官方网页端，暂不支持第三方客户端直接接入公共接口，以免不可控的资源消耗影响其他用户的正常使用。

如果你有正当的集成需求，欢迎通过 [GitHub Issues](https://github.com/MontageSubs/subtitle-translator/issues/) 或 [Discussions](https://github.com/MontageSubs/subtitle-translator/discussions/) 与我们沟通。我们愿意在不影响公共资源公平分配的前提下，共同探讨合理的方案。

### 内容授权与责任共识

作为使用者，请确保你拥有翻译材料的必要权利。你保留对通过本工具处理的字幕文件与文本内容所享有的全部权利；我们不主张也不拥有你的内容，且基于隐私设计，我们也无法审查这些内容。

**关于责任的说明**：你应对自己提交的内容及使用本服务所产生的行为承担相应责任。请注意，拥有字幕文件并不等同于拥有翻译该字幕的权利。本工具只提供翻译的技术能力，并不代表你可以提交自己无权翻译的内容。请在遵守版权法律的前提下使用本服务。

## 3. 可持续使用共识（行为准则）

为保障公共服务的可持续性与全体用户的公平权益，我们希望每位用户共同遵守以下约定：

**1. 翻译合规内容**
请勿翻译任何可能危害本公共服务运行的内容，包括但不限于非法、侵权或恶意内容。由于本服务使用了多种翻译供应商（包括本地引擎与上游引擎），你还需要遵守这些供应商的相关协议。即使某些内容在你所在的司法管辖区合法，只要违反了服务提供商所在地的法律或协议，也请勿使用本服务处理。

**基本原则**：若你认为某些内容可能存在法律风险或有害（即使仅是猜测），请不要使用本服务。违规内容可能导致服务被整体关停或实施更严格的限制，这将影响所有社区成员的利益。

**2. 尊重服务资源与配额**
*   **关于速率限制**：我们配置了公平的动态配额系统。字幕制作往往需要连续处理多个片段，中途触限会打断工作，因此我们为首次触限的用户提供了额外的配额缓冲，帮助完成手头的任务。但我们禁止任何试图绕过配额限制的行为，包括利用漏洞或滥用该缓冲机制。如果你触发了限制，请稍作休息，限制通常会在一段时间后自动解除。

**3. 拒绝资源滥用**
我们希望使用者是热爱字幕和影视的真人爱好者。我们允许使用合理的浏览器辅助工具或无障碍工具来提升效率，但严禁未经授权的自动化批量请求、无人值守调用以及任何形式的资源滥用。这类行为会快速消耗公共资源，严重影响所有人的使用；而且自动化程序缺乏人类对语言细微之处的判断，也无法参与知识共建与服务改进。

**4. 守护社区环境**
*   **基础设施安全**：请勿对我们的基础设施、服务接口或服务提供商进行任何形式的未经授权的攻击或探测。我们非常欢迎善意的安全研究，如果你在调研中发现了潜在的安全漏洞，请参考[安全漏洞报告指南](../feedback/zh-Hans.md)向我们报告，一起守护社区安全。
*   **成员尊重**：请勿对社区成员、贡献者进行骚扰或人身攻击。我们遵循[社区贡献者公约](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)，维持友善、互助的交流氛围。

## 4. 违规处理与申诉

为了保护大多数用户的权益，对违反上述约定的行为，我们会视严重程度采取以下措施：
1. 发出友好的提醒或警告；
2. 临时或永久限制使用服务的权利；
3. 在面临恶意攻击或严重违法情形下，依法追究责任。

**申诉通道**：自动化限制偶尔可能出现误判。如果你认为自己的访问被误限制，欢迎通过社区群组或讨论区联系我们，我们会协助排查并处理你的申诉。

## 5. 服务可用性与局限性说明

代码和服务均按“现状”提供。作为一项由社区驱动的非营利开源公共服务，我们虽会尽力保障翻译质量与可用性，但无法保证服务不间断，也无法提供绝对的稳定性承诺。

**关于局限性的说明**：基于社区项目的公益性质，对于因服务中断、上游供应商变更、引擎输出错误、不可抗力或其他非本社区故意造成的技术故障所带来的损失，本服务在适用法律允许的范围内不承担相应的法律责任，还请理解。

**共同治理与状态公开**：我们坚持状态透明，也希望由社区共同参与治理。通过页面底部的“状态”链接，你可以进入独立的状态页面，查看服务的实时可用性。这也是一扇窗口，让你看到社区成员为保持服务稳定所做的努力，同时督促我们不断提升可用性。

**服务变动说明**：服务可能因日常维护、上游供应商调整、恶意滥用或维护者精力变动而暂停或终止。

**关于翻译质量**：最终效果取决于你的配置、所选引擎、处理逻辑及上游引擎能力。我们会持续改进，也欢迎你通过[反馈](../feedback/zh-Hans.md)页面告诉我们，一起把它做得更好。
