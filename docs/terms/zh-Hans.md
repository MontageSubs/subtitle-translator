# 服务条款

**MontageSubs 是一个用爱发电的开源字幕社区。本服务条款适用于在线字幕翻译工具服务，并基于相同的社区理念维护与运营。**

我们希望为热爱字幕的你提供一个理解字幕结构、具备术语表一致性与场景识别能力、契合字幕格式规范的免费神经机器翻译服务。

## 1. 服务理念与运营模式
本服务由社区贡献者用心维护和用爱驱动。翻译服务与基础设施的运行成本由贡献者个人赞助、API 免费额度及社区志愿资源覆盖。

*   **非营利承诺**：我们绝不会销售你的数据或通过追踪用户信息获利，亦不计划进行任何商业牟利（包括但不限于投放广告）。
*   **资源投入理解**：维持免费公共服务需要实际的算力与人力投入。我们爱字幕、爱字幕社区，并热忱地为字幕创作者与观众打造出色的工具体验。

## 2. 资金、捐助与社区贡献
*   **不接受金钱捐款**：我们当前**不接受任何形式的金钱捐赠**。接受金钱可能会将个人的纯粹热爱转变为具有压力与责任的负担，从而限制我们自由发挥热情去提供服务的初衷。所有成本均由贡献者的热情驱动并尽可能长期维持。请注意防范冒充社区名义索取捐款的欺诈行为。
*   **欢迎基于热爱的贡献**：欢迎以非金钱形式参与共建，包括但不限于提交代码改进、反馈缺陷与建议、向字幕爱好者推广本工具，或贡献你闲置的 API 配额。

## 3. 许可使用与范围
*   **网页端合法访问**：本服务仅面向通过官方网页界面进行字幕翻译的合法终端用户。
*   **用户内容所有权**：你保留通过本工具处理的字幕文件与文本内容的全部知识产权。我们不会主张你翻译内容的任何所有权。
*   **开源代码**：本项目代码均在 [GitHub](https://github.com/MontageSubs/subtitle-translator) 上基于 MIT 许可证开源。

## 4. 禁止行为
为保障公共服务的可持续性与全体用户的公平权益，严禁以下行为：

### 4.1 服务接口滥用
*   禁止对后端接口进行逆向工程、利用代码漏洞直接绕过前端调用后端 API，或非法获取/泄露源代码中的凭据与配置。
*   此类行为会迅速耗尽公共配额，导致所有正常用户无法使用。如有正当的集成需求，请通过 GitHub Issues 或 Discussions 与我们沟通。我们同时欢迎你审计开源代码并协助报告安全漏洞。

### 4.2 自动化脚本与机器人
*   禁止使用爬虫、自动化脚本、机器人、无头浏览器或任何绕过交互界面的工具批量发送请求。自动化滥用将瞬间挤占公共算力，触发上游提供商限制，影响整个社区。

### 4.3 违反翻译提供商合规政策
*   严禁提交上游翻译提供商明确禁止的内容，包括但不限于非法活动、骚扰、仇恨言论、色情、恶意软件与诈骗信息。
*   **基本原则**：若你认为某些内容可能违法或有害，请勿使用本服务进行翻译。违规内容可能导致上游接口被封禁，危及整个服务的存续。

### 4.4 攻击基础设施
*   严禁进行 DDoS/DoS 攻击、利用已知漏洞实施恶意破坏、发送畸形请求或超大数据包，以及未授权扫描/探测服务器漏洞。
*   严禁攻击支持本项目的任何基础设施与服务提供商（包括但不限于 GitHub Pages、Cloudflare Workers、Turso、js.org 以及 Google 神经翻译等服务）。

## 5. 安全漏洞协同披露
如发现系统安全问题，请私下通过 GitHub Discussions、Telegram、Discord 或其他官方社群渠道与维护团队联系。请勿在公开场合披露未修复的漏洞细节。

## 6. 违规处理
根据违规行为的严重程度，我们保留采取以下措施的权利：
1. 发出合规警告；
2. 临时或永久限制 IP 地址/访问权限；
3. 在面临恶意攻击或严重违法情形下，依法追究法律责任。
如认为访问受到误限，可通过社群渠道提出申诉。

## 7. 免责声明与条款更新
*   **按现状提供**：本服务按“现状”（As is）和“现有”（As available）基础提供，不承诺完全无故障或具备特定的可用性保障。
*   **服务中断与变动**：服务可能因日常维护、上游提供商调整、恶意滥用或维护者精力变动而暂停或终止。翻译质量取决于上游引擎能力。
*   **条款修订**：我们保留根据社区发展需要更新本服务条款的权利。更新后的条款将发布于本页面。
