# 服务条款

蒙太奇字幕翻译器是由蒙太奇字幕社区开发、维护的开源且免费的字幕翻译公共服务。

蒙太奇字幕社区是一个由影视爱好者、字幕制作者、影视工作者和开发者组成的非营利字幕社区。我们在这里分享对影视与字幕的热爱，致力于将制作经验与技能以开源的方式传递给每一个人，旨在促进跨语言的理解与文化传播，共同构建一个开放、繁荣的字幕生态。

我们深知，“免费”的背后并非没有成本。蒙太奇字幕翻译器的诞生，凝聚了社区成员大量的开发资源，并将专业的字幕知识、格式规范、排版经验以及自然语言处理技术有机地融合在一起。我们致力于为每一位爱好者提供一个稳定、高效的免费公共服务。

为了确保这项服务能够长期地造福所有使用者，我们需要就服务的使用方式达成一份共识，明确我们共同守护的底线，以及为了社区健康而无法接受的行为。

## 1. 服务理念与运营模式

本服务由社区成员用爱驱动，用心维护。翻译服务与基础设施的运行成本，由贡献者个人赞助、API 免费额度及社区志愿资源共同覆盖。

我们希望通过开源的精神与免费的公共服务，让不同身份的使用者都能从中获益：

**对于字幕制作者**：你可以利用术语表、上下文感知、场景识别、SDH、加粗样式及 ASS 样式配置等高级功能，结合本地模型的优化处理，获得高质量的机器翻译初稿。同时，内置的本地编辑器、对比预览及自动错误识别功能，将极大提升你的校对效率。我们热烈欢迎你加入社区，与我们共同交流制作经验，深化专业知识。

**对于影视爱好者**：你可以在十几秒内获得一份排版专业、时间轴准确、质量可靠的译本，帮助你快速理解异国影视内容，并通过双语选项辅助语言学习。我们希望这个工具能带你领略字幕艺术的魅力，并启发你尝试开启自己的字幕制作之旅。

**对于开发者**：你可以探索源代码，研究字幕排版与格式如何通过代码实现，观察字幕规范如何转化为高效的逻辑。我们欢迎你加入社区，一同探索更多有趣的项目，将优秀的想法变为现实。

**对于影视制作者**：我们希望通过社区协作，为独立影视创作者提供语言交流与字幕制作方面的支持，让更多优秀作品有机会跨越语言障碍，被不同地区的观众看见。

我们希望每一位使用者都能从中受益，并与我们共同推动蒙太奇字幕社区的发展。如果你认同我们的理念，欢迎访问 [贡献] 页面，通过反馈建议、参与开发或成为一名社区成员，与我们一同建设这个生态。

## 2. 使用许可与资源守护

**网页工具**：我们支持用户在免登录、免注册、无广告、无追踪的环境下使用本工具。我们建立了严格的隐私架构，旨在最大限度保护你的隐私，详见 [隐私政策]。

**源代码**：本项目源代码遵循 MIT 许可协议开源，包括字幕处理逻辑、优化算法等专业知识在内的所有内容均对公众开放，欢迎你的贡献与改进，让更多人受益。

**关于公共资源的使用**：我们鼓励开发者基于开源代码进行创造。但需要说明的是，本社区的公共后端资源与 API 配额是所有成员共同守护的有限资产。为了确保资源的公平分配并维持服务的稳定性，我们目前仅将公共服务支持集中在官方网页端。我们暂不支持第三方客户端直接接入公共接口，以避免不可控的资源损耗影响广大用户的正常使用。

如果你有正当的集成需求，欢迎通过 GitHub Issues 或 Discussions 与我们沟通。我们愿意在不影响公共资源公平分配的前提下，共同探讨合理的方案。

### 内容授权与责任共识
作为使用者，请确保你拥有翻译材料的必要权利。你保留通过本工具处理的字幕文件与文本内容的全部权利；我们不主张也不拥有你的内容，且基于隐私设计，我们无法审查你的内容。

**关于责任的说明**：你应对自己提交的内容及使用本服务所产生的行为承担相应责任。这里特别提醒，拥有字幕文件并不等同于拥有翻译该字幕的权利。本工具提供了翻译的技术能力，但这并不意味着用户应当提交无权翻译的内容。请在遵守版权法律的前提下使用本服务。

## 3. 可持续使用共识（行为准则）

为保障公共服务的可持续性与全体用户的公平权益，我们希望每位用户共同遵守以下约定：

**1. 翻译合规内容**
请勿翻译任何可能危害本公共服务运行的内容，包括但不限于非法、侵权或恶意内容。由于我们的服务涉及多种翻译供应商（包括本地模型与上游模型），请在翻译时遵守所有相关供应商的协议。即使某些内容在你所在的司法管辖区合法，但若违反了服务提供商所在地的法律或协议，亦请勿使用本服务处理。

**基本原则**：若你认为某些内容可能存在法律风险或有害（即使仅是猜测），请不要使用本服务。违规内容可能导致服务被整体关停或实施更严格的限制，这将影响所有社区成员的利益。

**2. 尊重服务资源与配额**
*   **关于速率限制**：我们配置了公平的动态配额系统。考虑到字幕制作的连续性，为了确保正在进行的任务能够顺利完成，我们为首次触限的用户提供了额外的配额缓冲。但我们禁止任何试图绕过配额限制的行为（包括利用漏洞或滥用该缓冲机制）。如果你触发了限制，请稍作休息，限制通常会在一段时间后自动解除。

**3. 拒绝资源滥用**
我们希望使用者是热爱字幕生态和影视的真人爱好者。我们支持用户使用合理的浏览器辅助工具或无障碍自动化功能来提升效率，但我们严禁未经授权的自动化批量请求、无人值守调用以及任何形式的资源滥用。这类行为会快速消耗公共资源，严重降低所有人的使用体验；且自动化程序缺乏人类对语言细微之处的感知，无法参与到知识共建与服务改进的社区活动中。

**4. 守护社区环境**
*   **基础设施安全**：请勿对我们的基础设施、服务接口或服务提供商进行任何形式的未经授权的攻击或探测。我们非常欢迎善意的安全研究，如果你在调研中发现了潜在的安全漏洞，请参考 [安全漏洞报告指南] 向我们告知，共同守护社区的安全。
*   **成员尊重**：请勿对社区成员、贡献者进行骚扰或人身攻击。我们共同遵守 [社区贡献者公约]，维持友善、互助的交流氛围。

## 4. 违规处理与申诉

为了保护大多数人的利益，针对违反上述共识的行为，我们将根据严重程度采取以下措施：
1. 发出友好的提醒或警告；
2. 临时或永久限制使用服务的权利；
3. 在面临恶意攻击或严重违法情形下，依法追究法律责任。

**申诉通道**：我们深知自动化限制偶尔可能会出现误判。如果你认为自己的访问受到了误限，欢迎通过社区群组和讨论区联系我们，我们将协助你进行排查与申诉。

## 5. 服务可用性与局限性说明

代码和服务均按“现状”提供。作为一项由社区驱动的非营利开源公共服务，我们虽尽全力确保翻译质量与可用性，但无法提供绝对的稳定性保证与服务承诺。

**关于局限性的说明**：基于社区项目的公益性质，对于因服务中断、上游供应商变更、模型输出错误、不可抗力或其他非本社区故意导致的技术故障而造成的损失，我们希望得到你的理解，本服务不承担相应的法律责任。

**共同治理与状态公开**：我们致力于状态透明与社区共同治理。通过页面底部的“状态”链接，你可以进入独立的状态页面查看服务的实时可用性。这个窗口展现了社区成员致力于使服务尽可能保持可用的共同努力，也激励我们协作推进，追求更高的可用性。

**服务变动说明**：服务可能因日常维护、上游供应商调整、恶意滥用或维护者精力变动而暂停或终止。

**关于翻译质量**：最终效果取决于你的配置、所选引擎、处理逻辑及上游模型能力。我们致力于不断完善，并诚邀你通过 [反馈] 页面与我们一起改进。
