# 工具

我们构建的大部分工具，都源自于自己的字幕制作实践。每当工作流中出现痛点，或者面对重复繁琐的步骤时，我们就会尝试寻找更好的解决方式，有时是一个简单的脚本，有时则演变成了一个完整的工具。

很多工具的起点其实很简单。比如蒙太奇字幕翻译器，最初只是我们内部几个用于样式占位与时间轴参考的 Python 脚本。正是因为在内部使用中发现了它对字幕生态的价值，才将其演变为现在的公共服务。我们分享以下工具的初衷也一样：如果能让你的字幕制作变得轻松一点，那对我们就很有意义。

## 工具详情

### SVG 转 ASS 绘图指令工具
ASS 字幕支持自定义字体和绘图指令，这给了字幕制作者极大的发挥空间，能够打造出视觉效果出色的作品。但在实际制作过程中，一个很麻烦的痛点是 ASS 的绘图指令格式比较私有，且没有被广泛兼容，这意味着现代设计软件中常用的 SVG 矢量图形无法直接转换成字幕支持的格式。

为了解决这个问题，我们开发了这款工具，帮你把 SVG 直接转换为 ASS 绘图指令。这样一来，你可以在自己熟悉的专业设计软件中绘制精美的图形，然后轻松地将其应用到字幕中，让排版过程变得简单且高效。该工具的所有计算都在你的浏览器本地完成，没有任何数据会被发送到服务器。

**贡献者**：NickCollect, 小p

**相关链接**：[在线工具](https://subs.js.org/svg-to-ass/) | [源代码](https://github.com/MontageSubs/svg-to-ass)

### ASS 转 SVG 矢量还原工具
这是上述转换工具的对称补充。当你需要修改他人制作的字幕，或者想把自己的旧作中的绘图指令重新导入到现代矢量设计软件中进行编辑时，这个工具就派上用场了。它可以将封闭的绘图指令还原为可编辑的 SVG 矢量图形，让作品的二次创作变得更加方便。

该工具同样遵循纯本地计算原则，完全在浏览器中离线运行，确保你的工作内容始终留在本地。

**贡献者**：NickCollect

**相关链接**：[在线工具](https://subs.js.org/ass-to-svg/) | [源代码](https://github.com/MontageSubs/ass-to-svg)

### ASS 子集化与字体嵌入工具
自定义字体是 ASS 字幕的强大之处，它让字幕能够拥有极具个性化的风格。但分发字体一直是个难题：很难保证每一位观众的设备上都安装了相同的字体。如果缺失，播放器会回退到默认字体，导致原本精心设计的视觉效果在观众端完全失真。

虽然 ASS 格式本身支持内嵌字体，但一直缺乏便捷的编辑工具。我们开发了这款基于浏览器的字体嵌入与管理工具，让你无需安装软件即可完成内嵌操作。此外，它还支持字体子集化（仅保留字幕中用到的字符）以及将图形指令转换为字体嵌入，在保证视觉效果不变的前提下，尽量减少字幕文件的体积。

该工具同样离线运行在你的浏览器中，包括字幕和字体在内的所有内容都不会被发送到服务器。

**贡献者**：小p, NickCollect, JULIANLEEEEE

**相关链接**：[在线工具](https://subs.js.org/ass-subset/) | [源代码](https://github.com/MontageSubs/ass-subset/)
