# 工具

我們開發的許多工具，其實都是在製作字幕的過程中慢慢「長」出來的。工作流程中遇到不順手的地方，或是有些步驟總得一再重複，我們就會試著找更好的解決方式。有時只是寫個小腳本，有時做著做著，就成了一個可以獨立使用的工具。

蒙太奇字幕翻譯器也是如此。最初，它只是幾個供內部使用的 Python 腳本，用來預留樣式位置、參考時間軸。後來，我們發現這些腳本不只對自己的工作有幫助，也能讓其他字幕製作者受益，便逐步將它發展成現在開放給大家使用的服務。我們分享其他工具也是出於同樣的想法：如果能讓你的字幕製作輕鬆一點，那就值得了。

## 工具介紹

### SVG 轉 ASS 繪圖指令工具

ASS 字幕支援自訂字型和繪圖指令，讓字幕製作者能在特效與排版上有更多發揮空間。不過，ASS 使用的繪圖指令有自己的格式，無法直接套用一般向量繪圖軟體使用的 SVG 圖形。也就是說，即使你已經在 Illustrator 或 Inkscape 裡做好素材，還是得先解決格式轉換的問題。

這個工具可以直接將 SVG 轉換成 ASS 繪圖指令。你可以繼續使用熟悉的繪圖軟體製作素材，再將成品轉換後放進字幕，不必為了格式不同而重新繪製。所有轉換都在瀏覽器本機完成，檔案不會上傳到伺服器。

**貢獻者：** NickCollect、小p

**相關連結：** [線上工具](https://subs.js.org/svg-to-ass/) | [原始碼](https://github.com/MontageSubs/svg-to-ass)

### ASS 轉 SVG 向量還原工具

如果你想修改別人製作的字幕，或是重新編輯自己以前做過的圖形，卻只剩下 ASS 檔案裡的繪圖指令，就可以用這個工具將它們轉回可編輯的 SVG 向量圖形，再放進熟悉的繪圖軟體中繼續修改，不必從頭重畫。

所有轉換同樣都在瀏覽器本機完成，不需要上傳檔案。

**貢獻者：** NickCollect

**相關連結：** [線上工具](https://subs.js.org/ass-to-svg/) | [原始碼](https://github.com/MontageSubs/ass-to-svg)

### ASS 字型子集化與嵌入工具

字型對 ASS 字幕的視覺效果影響很大，尤其是經過精心設計的特效字幕。但要讓每位觀眾都能看到預期的效果並不容易，畢竟不是每台裝置都安裝了字幕使用的字型。一旦字型缺失，播放器就可能改用其他字型，讓原本設計好的字形與排版走樣。

ASS 格式本身支援嵌入字型，但如果直接把完整的字型檔案放進字幕，檔案可能會變得很大。這個工具讓你可以直接在瀏覽器中嵌入字型，也支援字型子集化，只保留字幕實際用到的字元，減少不必要的檔案大小。此外，它還能將 ASS 繪圖指令轉換成字型，方便以字型的形式嵌入字幕。

所有處理都在瀏覽器本機完成，字幕檔案和字型檔案都不會上傳到伺服器。

**貢獻者：** 小p、NickCollect, JULIANLEEEEE

**相關連結：** [線上工具](https://subs.js.org/ass-subset/) | [原始碼](https://github.com/MontageSubs/ass-subset/)
