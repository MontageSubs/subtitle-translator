# 字幕编辑器使用指南

字幕翻译完成后，可以打开内置的离线字幕编辑器，逐条查看译文，修改不满意的地方，还能调整每条字幕在画面上的位置。页面加载完成后，编辑器完全在浏览器中运行，你输入的内容不会发送到任何地方。

本指南依次介绍编辑器的各项功能、快捷键，以及目前做不到的事。

## 打开编辑器

字幕文件翻译完成后，点击 **预览与编辑**，编辑器会以窗口的形式盖在页面上。想要更大的空间，可以点 **最大化**，窗口大小在你离开页面前都会记住。点 **关闭** 退出；如果还有没应用的修改，会先问你是否确定。

修改只有点了 **应用修改**，才会进入下载的文件。没有改动时这个按钮是灰的。应用之后，**原文** 和 **译文** 两个标签页会同步刷新，按钮旁边的“编辑于”会显示上次应用的时间。

## 标签页一览

窗口顶部的标签页依次是 **编辑器**、**术语表**、**背景说明**、**原文**、**译文** 和 **对照**。大部分时间你都会待在编辑器里，其余几个在后面各有一节。

## 看懂编辑器页面

每一条字幕是一张卡片。卡片顶部是条目编号和时间，比如 `#12 · 00:01:02,345 → 00:01:04,100`；下面是原文（只读）和译文（可以修改）。没有译文的条目，会显示 **缺少译文** 的占位提示。

卡片按场景分组，分隔处标着 **场景 1**、**场景 2** 这样的标题。这和翻译时用来保持上下文连贯的场景划分是同一套，看它就大致知道一段对话从哪里开始、到哪里结束。

要修改，直接点译文，然后输入就行。粘贴进来的内容一律按纯文本处理。按 Enter 换行，按 Esc 或 Ctrl+Enter 结束编辑。如果是用 Tab 键移动到某张卡片上，按 Enter 即可开始编辑。

## 高亮与标记

每张卡片靠起始一侧有一道彩色的竖条，加上其他几种提示，让你一眼看出状态：

- **主题色竖条：** 这条译文在翻译完成后被你改过。
- **红色竖条加淡红底色：** 缺少译文，或者疑似残留了原文。
- **橙色竖条加淡橙底色：** 单行过长，或者语速偏快。部分双语排版下，过长提示的底色会更淡。
- **淡底色，匹配的文字被标出：** 这一条符合你的搜索。当前所在的匹配项底色更深，并带有主题色竖条。
- **虚线边框：** 这一条已被选中，准备批量修改。
- **列表旁的细长标记条：** 相当于整个文件的缩略图，标出搜索匹配项和你打开的问题类型，点一下就跳到对应的条目。

红色和橙色只会出现在你打开的问题类型上，具体见下一节。

## 问题检查

编辑器发现问题时，列表上方会出现一排按钮，每个按钮后面都带数量：**缺少译文**、**疑似残留原文**、**单行过长** 和 **语速偏快（CPS）**。CPS 是每秒字符数，数值越高，观众的阅读时间越紧张。判断标准会随目标语言而不同。

点一下按钮，对应的条目就会高亮，并以小标签列出编号，点标签可以逐个跳转；再点一下就关掉。输入时会即时重新检查，改好的条目马上就不再标记。如果开着 **仅显示匹配项**，搜索框又是空的，打开某个问题类型后，列表只剩下有这类问题的条目。

## 搜索

搜索框会同时查找原文和译文，不区分大小写。搜索框旁边的箭头可以展开 **更多查找工具**，里面有匹配数量（比如 3/12）、**仅显示匹配项**、**上一个匹配项**、**下一个匹配项**、**撤销**、**重做** 和 **查找替换**。

可以用三种方式搜索：

- **文本：** 输入任意词语或句子，匹配的文字会在卡片里标出来。
- **时间码：** 输入 `01:02:03`、`1:02` 或 `90s` 这样的时间点，或者 `00:10-00:20` 这样的范围，会定位到那一刻正在显示的字幕，没有的话就找最接近的一条。
- **编号：** 输入 `#42`，直接找到第 42 条。

关闭 **仅显示匹配项** 时，所有条目都留在原位，匹配项会高亮，列表自动滚动到第一个匹配项。打开之后，列表只剩下匹配的条目。想集中处理某一类字幕，比如所有带音符的歌词，这样最方便。这个选项会一直记住，直到你刷新页面。

用 **下一个匹配项**、**上一个匹配项** 或下文的快捷键，就可以在结果之间逐个跳转。

## 查找替换

点 **查找替换**，或者按 Ctrl+H，会多出一行，里面有 **替换为** 输入框。**替换** 只改当前的匹配项，**全部替换** 则改掉所有匹配项。

替换只会改动译文，不会碰原文，而且要和你输入的文字完全一致，包括大小写。每次替换后，会有一行提示告诉你改了几条，又有几条因为匹配内容在原文里而被跳过。一次替换算作一步，可以整体撤销。

## 撤销与重做

**撤销** 和 **重做** 针对的是你的编辑、替换和位置调整。在同一张卡片里连续输入的内容，算作一步。记录会保留到关闭编辑器为止，背景说明和术语表的改动不在其中。

## 快捷键

macOS 上请用 Cmd 代替 Ctrl。快捷键在编辑器标签页下、且编辑器窗口位于最上层时有效。

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+F | 定位到搜索框 |
| Ctrl+H | 打开查找替换 |
| 在搜索框中按 Enter 或 ↓ | 跳到下一个匹配项 |
| 在搜索框中按 Shift+Enter 或 ↑ | 跳到上一个匹配项 |
| Ctrl+Z | 撤销 |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做 |
| 在选中的卡片上按 Enter | 开始编辑 |
| 编辑时按 Enter | 换行 |
| 编辑时按 Esc 或 Ctrl+Enter | 结束编辑 |
| 按住 Shift 点击卡片 | 选中一个范围内的条目 |
| Esc | 收起替换栏；替换栏已收起时，则关闭窗口 |

光标在搜索框或替换框里时，Ctrl+Z 和 Ctrl+Y 作用于输入框内的文字，而不是字幕的修改。

## 选中多条字幕

点一下卡片上没有文字的空白处，就能选中它；再点一下取消。按住 Shift 再点另一张卡片，两者之间的所有条目都会被选中，已锁定的条目会自动跳过。

选择的范围取决于列表当前显示的内容。打开 **仅显示匹配项** 搜索之后，只要选中第一个和最后一个匹配项，就能一次选中所有匹配的条目。

多选主要用来批量修改字幕位置，见下一节。

## 调整字幕位置

每张卡片顶部靠结束一侧有一个小小的位置图标，位置不是默认值时会高亮。点它会打开 **字幕位置** 窗口，里面是九宫格，从左上到右下共九个位置，点一个，这条字幕就会移过去。

想一次移动很多条，先按上面的方法选中它们，再点其中任意一条的位置图标。这时窗口标题会带上条数，你选的位置会应用到所有选中的条目。歌词和画面文字，是最常见的使用场景。

位置会以 ASS 对齐、WebVTT 的 cue 设置或 SRT 标签的形式写进文件。不同播放器对位置的支持程度不一，SRT 尤其如此。

## 关于「支持本项目」署名

如果开启了 **支持本项目**，最后一条字幕之后会加上一条简短的署名，显示几秒钟。在编辑器里，它是最后一张卡片，标着 **保留原文**，不能编辑，也不能移动。它不属于译文，是根据开关设置自动生成的，而不是你的字幕内容。

想去掉它，请关闭编辑器，在翻译页的 **输出** 里展开 **更多选项**，把 **支持本项目** 关掉。下次打开编辑器，这张卡片就不在了。这个选项默认开启，是因为署名是大家认识这个工具的途径之一。关于它的用意，以及我们为什么希望你保留它，请参考[如何贡献](../contribute/zh-Hans.md#support-this-project)。

## 背景说明与术语表

这两个标签页里的内容，和翻译前能设置的是同一份。**术语表** 是一张词条表，每个词条对应你想要的译法。**背景说明** 是一小段背景介绍，带字数统计，用来帮助翻译引擎理解故事。**从历史记录导入** 可以把之前任务里的背景说明直接带过来。有些翻译引擎不支持背景说明，此时这个标签页是锁定的。

点 **应用修改** 保存。它们会在这个文件下次翻译时生效，不会改动你现在看到的条目。

## 原文、译文与对照

**原文** 以文本形式显示源字幕文件，**译文** 显示翻译后的文件，内容就是你下载到的样子，两边都有 **下载** 按钮。译文标签页要点了 **应用修改** 才会更新。

**对照** 把两个文件并排放在一起，逐行对齐，底部标明各自的语言，两边的横向滚动是联动的。它是只读的，适合在定稿前对着真实文件做最后检查。

## 使用限制

- 原文不能编辑，只有译文可以修改。
- 署名那一条是锁定的，原因见上文。
- 选择 **分开** 排版时，位置九宫格只提供译文自己的那一行和中间一行。另一种语言占用的区域是固定的，无法更改它的位置。另外，分开排版只对双语输出生效，SRT 会自动改用叠放。
- 关闭编辑器后，撤销记录就没有了，背景说明和术语表的改动也不在记录里。
- 按时间码或编号搜索只会选中条目，不会标出文字。

## 从右向左的语言

使用从右向左的界面语言时，整个编辑器会镜像显示：标签页、搜索工具、每张卡片的竖条和位置图标都会换到对侧，撤销和重做的图标也会反向。所以这篇指南说的是“起始一侧”和“结束一侧”，而不是左边右边。卡片里的字幕文字，则按各自语言的书写方向显示。

## 反馈问题

编辑器窗口底部的 **使用说明** 链接会带你来到这篇指南。如果编辑器的表现与这里的说明不一致，欢迎告诉我们，具体方式请参考[关于反馈与建议](../feedback/zh-Hans.md)。

反馈时如果能附上条目编号（比如 `#12`）、出问题前的操作，以及页面底部显示的版本号，会有助于我们定位问题。关于编辑器在键盘和辅助技术方面的支持，可以看[无障碍声明](../accessibility/zh-Hans.md)。
