# 字幕編輯器使用指南

字幕翻譯完成後，可以開啟內建的離線字幕編輯器，逐句檢視譯文，覺得哪裡讀起來不順就直接修改，也能調整每句字幕在畫面上的位置。頁面載入完成後，編輯器完全在瀏覽器裡運作，你輸入的內容不會傳送到任何地方。

這份指南會把編輯器的各項功能、快速鍵，以及它做不到的事一併說明。

## 開啟編輯器

字幕檔翻譯完成後，點選 **預覽與編輯**，編輯器會以視窗的形式疊在頁面上。想要更大的空間，可以點選 **最大化**，視窗大小在你離開頁面前都會記住。點選 **關閉** 即可離開；如果還有尚未套用的修改，會先詢問你是否確定。

修改要按下 **套用修改**，才會進入下載的檔案。沒有任何變動時，這個按鈕是反灰的。套用之後，**原文** 與 **譯文** 兩個分頁會同步更新，按鈕旁的「編輯於」會顯示上次套用的時間。

## 分頁總覽

視窗頂端的分頁依序是 **編輯器**、**詞彙表**、**背景說明**、**原文**、**譯文** 與 **對照**。多數時候你都會待在編輯器，其餘幾個分頁在後面各有一節說明。

## 認識編輯器分頁

每一句字幕是一張卡片。卡片上方是句子編號與時間，例如 `#12 · 00:01:02,345 → 00:01:04,100`；下方是原文（唯讀）和譯文（可以修改）。沒有譯文的句子，會顯示 **缺少譯文** 的提示。

卡片會依場景分組，分隔處標有 **場景 1**、**場景 2** 這樣的標題。這和翻譯時用來維持上下文連貫的場景劃分是同一套，看它就大致能知道一段對話從哪裡開始、到哪裡結束。

要修改的話，直接點選譯文然後輸入即可。貼上的內容一律以純文字處理。按 Enter 換行，按 Esc 或 Ctrl+Enter 結束編輯。如果是用 Tab 鍵移到某張卡片上，按 Enter 就能開始編輯。

## 醒目標示與標記

每張卡片靠起始側有一條彩色直條，再搭配其他幾種提示，讓你一眼看出狀態：

- **主題色直條：** 這句譯文在翻譯完成後被你改過。
- **紅色直條加淡紅底色：** 缺少譯文，或疑似殘留了原文。
- **橘色直條加淡橘底色：** 單行長度過長，或語速偏快。部分雙語版面下，過長提示的底色會更淡。
- **淡底色，相符的文字被標出：** 這一句符合你的搜尋。目前所在的相符項目底色較深，並帶有主題色直條。
- **虛線外框：** 這一句已被選取，準備批次修改。
- **清單旁的細長標記條：** 相當於整個檔案的縮圖，標出搜尋相符的項目，以及你開啟的問題類型，點一下就會跳到對應的句子。

紅色與橘色只會出現在你開啟的問題類型上，詳見下一節。

## 問題檢查

編輯器發現問題時，清單上方會出現一排按鈕，每個按鈕後面都附有數量：**缺少譯文**、**疑似殘留原文**、**單行長度過長** 與 **語速偏快（CPS）**。CPS 是每秒字元數，數值越高，觀眾的閱讀時間就越緊迫。判斷標準會依目標語言而不同。

點選按鈕後，對應的句子會醒目標示，並以小標籤列出編號，點選標籤就能逐一跳轉；再點一次就會關閉。輸入時會即時重新檢查，修好的句子馬上就不再被標記。如果開著 **僅顯示相符項目**，而搜尋欄是空的，開啟某個問題類型後，清單就只會留下有這類問題的句子。

## 搜尋

搜尋欄會同時尋找原文與譯文，不分大小寫。搜尋欄旁的箭頭可以展開 **更多尋找工具**，裡面有相符數量（例如 3/12）、**僅顯示相符項目**、**上一個相符項目**、**下一個相符項目**、**復原**、**重做** 與 **尋找與取代**。

可以用三種方式搜尋：

- **文字：** 輸入任何字詞或句子，相符的文字會在卡片中標出來。
- **時間碼：** 輸入 `01:02:03`、`1:02` 或 `90s` 這類時間點，或是 `00:10-00:20` 這樣的範圍，會定位到當下正在顯示的字幕，沒有的話就找最接近的一句。
- **編號：** 輸入 `#42`，直接找到第 42 句。

關閉 **僅顯示相符項目** 時，所有句子都留在原位，相符項目會醒目標示，清單自動捲動到第一個相符項目。開啟之後，清單只會剩下相符的句子。想集中處理某一類字幕，例如所有帶音符的歌詞，這樣最方便。這個選項會一直記住，直到你重新整理頁面。

用 **下一個相符項目**、**上一個相符項目** 或下文的快速鍵，就能在結果之間逐一跳轉。

## 尋找與取代

點選 **尋找與取代**，或按 Ctrl+H，會多出一列，裡面有 **取代為** 輸入欄。**取代** 只改目前的相符項目，**全部取代** 則會改掉所有相符項目。

取代只會更動譯文，不會碰到原文，而且必須和你輸入的文字完全相同，包括大小寫。每次取代後，會有一行提示告訴你改了幾句，又有幾句因為符合的內容在原文而被略過。一次取代算作一個步驟，可以整體復原。

## 復原與重做

**復原** 與 **重做** 針對的是你的編輯、取代與位置調整。在同一張卡片裡連續輸入的內容，算作一個步驟。紀錄會保留到關閉編輯器為止，背景說明與詞彙表的變動不在其中。

## 快速鍵

macOS 上請以 Cmd 取代 Ctrl。快速鍵在編輯器分頁下，且編輯器視窗位於最上層時有效。

| 快速鍵 | 作用 |
| --- | --- |
| Ctrl+F | 移到搜尋欄 |
| Ctrl+H | 開啟尋找與取代 |
| 在搜尋欄中按 Enter 或 ↓ | 跳到下一個相符項目 |
| 在搜尋欄中按 Shift+Enter 或 ↑ | 跳到上一個相符項目 |
| Ctrl+Z | 復原 |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做 |
| 在選取的卡片上按 Enter | 開始編輯 |
| 編輯時按 Enter | 換行 |
| 編輯時按 Esc 或 Ctrl+Enter | 結束編輯 |
| 按住 Shift 點選卡片 | 選取一個範圍內的句子 |
| Esc | 收起取代列；取代列已收起時，則關閉視窗 |

游標在搜尋欄或取代欄時，Ctrl+Z 與 Ctrl+Y 作用於輸入欄內的文字，而不是字幕的修改。

## 一次選取多句字幕

點一下卡片上沒有文字的空白處，就能選取它；再點一次取消。按住 Shift 再點另一張卡片，兩者之間的所有句子都會被選取，已鎖定的句子會自動略過。

選取的範圍取決於清單目前顯示的內容。開啟 **僅顯示相符項目** 搜尋之後，只要選取第一個和最後一個相符項目，就能一次選取所有相符的句子。

多選主要用來批次調整字幕位置，詳見下一節。

## 調整字幕位置

每張卡片上方靠結束側有一個小小的位置圖示，位置不是預設值時會醒目顯示。點選它會開啟 **字幕位置** 視窗，裡面是九宮格，從左上到右下共有九個位置，點選其中一個，這句字幕就會移過去。

想一次移動很多句，先照上面的方式選取它們，再點選其中任一句的位置圖示。這時視窗標題會帶上句數，你選的位置會套用到所有選取的句子。歌詞與畫面文字，是最常見的使用情境。

位置會以 ASS 對齊、WebVTT 的 cue 設定或 SRT 標籤的形式寫進檔案。不同播放器對位置的支援程度不一，SRT 尤其如此。

## 關於「支持本專案」署名

如果開啟了 **支持本專案**，最後一句字幕之後會加上一行簡短的署名，顯示幾秒鐘。在編輯器裡，它是最後一張卡片，標示為 **保留原文**，不能編輯，也不能移動。它不屬於譯文，是依照開關設定自動產生的，而不是你的字幕內容。

想拿掉它，請先關閉編輯器，到翻譯頁的 **輸出** 展開 **更多選項**，把 **支持本專案** 關掉。下次開啟編輯器，這張卡片就不在了。這個選項預設開啟，是因為署名是大家認識這個工具的管道。想了解它的用意，以及為什麼我們希望你分享字幕時盡量保留，可以參考[如何貢獻](../contribute/zh-Hant.md#support-this-project)。

## 背景說明與詞彙表

這兩個分頁裡的內容，和翻譯前可以設定的是同一份。**詞彙表** 是一張詞條表，每個詞條對應你想要的譯法。**背景說明** 是一小段背景介紹，附有字數統計，用來幫助翻譯引擎理解故事。**從歷史紀錄匯入** 可以把先前任務裡的背景說明直接帶過來。有些翻譯引擎不支援背景說明，這時這個分頁會是鎖定的。

按下 **套用修改** 儲存。它們會在這個檔案下次翻譯時生效，不會更動你現在看到的句子。

## 原文、譯文與對照

**原文** 以文字形式顯示來源字幕檔，**譯文** 顯示翻譯後的檔案，內容就是你下載到的樣子，兩邊都有 **下載** 按鈕。譯文分頁要按下 **套用修改** 才會更新。

**對照** 把兩個檔案並排在一起，逐行對齊，底部標明各自的語言，兩邊的橫向捲動是連動的。它是唯讀的，適合在定稿前對著真實檔案做最後檢查。

## 使用限制

- 原文無法編輯，只有譯文可以修改。
- 署名那一句是鎖定的，原因見上文。
- 選擇 **分開** 版面時，位置九宮格只提供譯文自己的那一列與中間一列。另一種語言佔用的區域是固定的，無法更動它的位置。此外，分開版面只對雙語輸出有效，SRT 會自動改用疊放。
- 關閉編輯器後，復原紀錄就沒有了，背景說明與詞彙表的變動也不在紀錄裡。
- 依時間碼或編號搜尋只會選取句子，不會標出文字。

## 由右至左的語言

使用由右至左的介面語言時，整個編輯器會鏡射顯示：分頁、搜尋工具、每張卡片的直條與位置圖示都會換到另一側，復原與重做的圖示也會反向。所以這份指南說的是「起始側」與「結束側」，而不是左邊右邊。卡片裡的字幕文字，則依各自語言的書寫方向顯示。

## 回報問題

如果編輯器的表現和這裡說的不一樣，歡迎告訴我們。視窗底部的 **回報問題** 連結會帶你來到這份指南，接著照[關於問題回報與建議](../feedback/zh-Hant.md)的方式送出即可。

回報時如果能附上句子編號（例如 `#12`）、出問題前做了什麼，以及頁面底部顯示的版本號，我們查起來會快很多。關於編輯器在鍵盤與輔助技術方面的支援，可以參考[無障礙聲明](../accessibility/zh-Hant.md)。
