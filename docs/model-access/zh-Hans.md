# 关于请求新的翻译模型

DeepL 和通用 LLM 翻译目前在翻译器里显示为不可用，这是成本问题，不是技术问题：DeepL 的 API 和 LLM 推理成本远高于我们目前免费提供的 NMT 引擎，我们也不愿意让一部分用户能用、另一部分用户因为负担不起而用不了。

一旦某个模型可用，它就会对所有人可用——不会有单独的付费档，也不会有优先通道。所以增加一个模型，本质是要找到一种能长期支撑所有用户使用的资金方式，而不是只满足第一个提出需求的人。

如果你能帮助让某个模型以可持续的方式对所有人开放——无论是 API 额度、赞助还是基础设施支持——可以看看[如何贡献](../../contribute)。如果你想请求某个具体的模型或服务商，欢迎发起一个讨论，方便我们跟踪需求、评估可行性。

这篇文档目前是占位内容，具体政策成型后会补充完善。
