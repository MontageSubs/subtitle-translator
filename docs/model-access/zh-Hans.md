# 翻译引擎与模型支持

蒙太奇字幕翻译器致力于提供高质量、自然流畅的字幕翻译体验。我们通过深度适配翻译引擎、优化处理流程，结合神经网络、人工智能与字幕专业技术，不断提升翻译质量。

## 我们如何改进翻译质量？

我们的翻译系统主要采用基于 Transformer 架构的神经网络机器翻译（Neural Machine Translation，NMT）引擎，并结合多种自然语言处理技术，提升译文的准确性和连贯性。

针对字幕翻译的特点，我们还结合字幕文件处理技术与字幕专业知识，运用术语和专有名称识别、句子预测，以及针对不同语言优化的断句和分词技术，同时兼顾字幕格式、时间轴与上下文，让译文更符合实际的字幕使用场景。

除了接入现有翻译引擎，我们也会针对不同引擎和技术进行专门适配，并结合其他神经网络与自然语言处理技术，进一步提升翻译效果。

## 我们如何选择新的模型？

我们持续关注和评估新的翻译技术，包括可在浏览器中运行的本地 NMT 引擎、大语言模型（Large Language Model，LLM），以及 DeepL 等第三方翻译服务。

我们希望每个人都能免费使用尽可能好的翻译技术，不因经济条件而受到限制。因此，用户不应该为了使用某项服务而额外付费、自备 API 密钥或承担复杂的配置成本。

与此同时，作为一项由社区维护的公共服务，我们也需要确保新技术能够长期稳定地提供给用户。API 费用、计算资源和后续维护成本，都是引入新引擎或模型时需要考虑的因素。

我们会综合评估翻译质量、使用门槛与长期运行成本，在尽可能提升翻译体验的同时，确保服务能够持续向所有用户开放。

## 如何参与？

如果你有希望我们支持的 NMT 引擎、LLM 或其他翻译服务，欢迎加入[社区](../community/zh-Hans.md)与我们交流。

无论是技术建议、开发贡献，还是 API 和计算资源支持，都欢迎参与。你也可以阅读[贡献指南](../contribute/zh-Hans.md)，了解如何加入项目。

我们期待与社区一起，让更多人免费使用先进的翻译技术，让字幕翻译变得更加简单。

希望蒙太奇字幕翻译器能帮助你翻译出更好的字幕！
