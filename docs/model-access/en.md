# Requesting a Translation Engine or Model

Some options — DeepL (a translation engine) and general LLM translation (a translation model) — are shown as unavailable in the translator. This is a cost problem, not a technical one: DeepL's API and LLM inference cost far more than the NMT engines we currently run for free, and we're not willing to make an engine or model available to some users but not others based on who can afford it.

If an engine or model becomes available, it becomes available to everyone using this tool — no separate paid tier, no priority access. That means adding one is a question of finding a sustainable way to fund it for every user, not just the first one to ask.

If you can help make an engine or model sustainably available to everyone — through API credits, sponsorship, or infrastructure — see [how to contribute](../contribute/). If you'd like to request a specific engine, model or provider, open a discussion so we can track interest and evaluate feasibility.

This page is a placeholder and will be expanded as this policy takes shape.
