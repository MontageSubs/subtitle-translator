# 翻譯引擎與模型支援

蒙太奇字幕翻譯器希望讓每個人都能輕鬆使用優質的字幕翻譯技術。我們持續整合不同的翻譯引擎與模型，改善字幕處理流程，並結合神經網路、人工智慧及字幕相關技術，讓翻譯成果更加自然、準確。

## 我們如何提升翻譯品質？

我們的翻譯系統主要採用以 Transformer 架構為基礎的神經機器翻譯（Neural Machine Translation，NMT）引擎，並搭配多種自然語言處理技術，提升譯文的準確度與流暢度。

字幕翻譯不只是將文字從一種語言轉換成另一種語言，還需要考量字幕格式、時間軸，以及前後文的連貫性。因此，我們也針對字幕的特性進行最佳化，包含術語與專有名稱辨識、句子預測，以及依照不同語言特性調整斷句與分詞方式，讓翻譯結果更符合字幕閱讀習慣，也能在保留原意的同時，兼顧字幕的呈現方式。

除了整合現有的翻譯引擎與模型，我們也會依照不同技術的特性進行調整，搭配其他神經網路與自然語言處理技術，持續改善整體翻譯品質。

## 我們如何選擇新的模型？

我們持續關注並評估新的翻譯技術，包括可直接在瀏覽器中執行的本機 NMT 引擎、大型語言模型（Large Language Model，LLM），以及 DeepL 等第三方翻譯服務，尋找適合整合至專案的技術。

我們希望每個人都能免費使用盡可能優質的翻譯技術，不因經濟條件而有所限制。因此，使用者不應為了使用特定的翻譯服務而額外付費、自行準備 API 金鑰，或承擔繁複的設定與使用成本。我們希望透過專案的整合與維護，讓更多人都能直接使用這些優質的翻譯技術。

另一方面，蒙太奇字幕翻譯器是一項由社群共同維護的免費服務。要讓這樣的服務長久運作，除了仰賴社群的參與與支持，也必須妥善考量各項資源的運用。API 費用、運算資源，以及後續的開發與維護成本，都是導入新引擎或模型時需要審慎評估的因素。

因此，我們會綜合考量翻譯品質、使用便利性與長期維運成本，選擇適合專案的技術。我們希望透過社群的共同投入，讓先進的翻譯技術不只是少數服務的附加價值，而是人人都能使用、共同受益的成果，並讓這份服務持續開放下去。

## 如何參與？

如果你有推薦的 NMT 引擎、LLM，或其他值得導入的翻譯服務，歡迎加入[社群](../community/zh-Hant.md)，與我們分享想法、交流經驗。

無論是提出技術建議、參與程式開發，或協助提供 API 與運算資源，都能成為專案持續進步的一份力量。如果想進一步了解如何參與，也歡迎閱讀[貢獻指南](../contribute/zh-Hant.md)，看看有哪些方式可以一起投入。

我們相信，技術的價值不只在於它能做到什麼，也在於它能為多少人所用。透過社群的共同參與與分享，我們希望讓更多人都能接觸到優質的翻譯技術，讓字幕翻譯變得更加簡單，也讓這份成果能持續惠及更多人。

希望蒙太奇字幕翻譯器能成為你製作字幕時的好幫手，讓每一份字幕都能有更好的翻譯品質！
